# 第 77 期 关于真理和正义的战役

- 来源：`transcript-site/episodes/ep-77.html`

## 内容摘要

本期从 Adobe 联合创始人 John Warnock 去世谈起，回顾 PostScript、PDF、Illustrator 和贝塞尔曲线等基础技术，讨论为什么上一代计算机科学家做出的软件可以稳定使用几十年，而今天的软件更像短期产品。节目随后聊到特朗普重新活跃在 X 上，以及政治人物、媒体人和平台如何把对立转化为传播力和流量。

软件话题继续延伸到跳过手机开屏广告的工具和 `CCIDE` 争议。节目一方面分析开屏广告作为合法商业模式与用户体验之间的冲突，以及开源工具可能面对的法律和分发风险；另一方面批评把基于 VS Code 等开源项目的二次开发包装成“自主创新”，认为自主可控可以建立在诚实使用开源成果和保有持续维护能力的基础上。

节目主体讨论福岛核处理水排海。主持人明确反对当前的排海方案，重点质疑东电和日本政府在事故处理、方案选择、数据公开、独立采样和国际沟通上的做法，并分析舆论宣传、媒体结构和国际组织信息来源如何影响不同国家的认知。节目强调，争议的关键不只是“理论上是否安全”，而是方案是否经过充分证明、数据是否能被独立验证，以及把国内事故变成全球风险的一方是否尽到了说明责任。

最后回到高校面对大模型的焦虑：大学在算力、显卡和研究方向上陷入竞争，但不应只把购买 GPU 当成进步。节目建议高校发挥教师、课程和高质量领域内容的优势，与拥有算力和算法能力的企业合作，探索 AI 助教、教育内容生成、领域知识库和低算力预处理等更具体的落地路径。

## 时间线

### 00:00-09:34：John Warnock 与长寿命的软件基础

- Adobe 联合创始人 John Warnock 去世，节目从 Photoshop 的致谢信息谈到他在 PostScript、PDF 和 Illustrator 相关技术中的贡献。
- PostScript 是向打印机发送指令的图灵完备语言，PDF 则可以理解为在虚拟打印机中执行这类指令后形成的跨平台文件格式，能够在不同设备上保持显示和打印效果。
- Illustrator 代表的向量绘图依靠数学描述曲线和图形，贝塞尔曲线用控制点决定曲线的弯曲方式，成为向量图形的重要基础。
- 主持人感慨，过去个人或小团队可以创造影响几十年的通用技术；现在软件规模、需求和变化速度都更大，产品往往从一开始就被当作几个月或几年的短期使用品。

### 09:34-17:34：特朗普回归与社交媒体流量

- 特朗普在被推特封禁、解禁后长期没有发言，重新回到 X 的第一条内容是自己被捕时的登记照，迅速获得巨大转发和关注。
- 节目以他自首、保释、发布内容和离开的流程为例，讨论政治事件如何同时成为竞选宣传和高性价比的媒体事件。
- 共和党其他候选人在支持率和传播影响力上明显落后，特朗普即使不参加党内辩论，也能成为辩论现场无法回避的中心；塔克·卡尔森在 X 上对他的长时间专访同样获得极高观看量。
- 主持人认为，马斯克擅长把美国社会的对立转化为 X 的讨论和流量；特朗普的政治影响力、卡尔森的媒体能力与平台传播机制叠加，形成了相互放大的效果。

### 17:34-26:53：跳过开屏广告的工具与法律边界

- 一批安卓工具可以自动跳过手机 App 的开屏广告，随后收到大型互联网公司的律师函，被指违反反不正当竞争法；工具开发者普遍停止更新并撤下下载页面，小团队很难与大公司承担同等的诉讼风险。
- 节目分析，争议焦点不一定在工具是否收费，而在开屏广告是否属于受法律保护的合法商业模式，以及工具是否干扰、破坏了这种模式。最终是否违法仍应由法院根据事实判断。
- 只发布源代码、不提供二进制文件，或把针对具体 App 的配置文件分开传播，可能改变法律定性，但也会大幅提高普通用户的使用门槛；即使大公司未必最终胜诉，发函也可能已经达成压缩工具生态的目的。
- 开屏广告虽然转化率不高，却依靠巨大的覆盖量和较低的价格持续存在。节目认为，免费软件把广告收益与用户的烦扰绑定在一起，导致商业上合法的东西不一定是用户愿意接受的好东西。

### 26:53-30:22：开屏广告的“守序与善良”困境

- 主持人借《龙与地下城》的阵营九宫格比喻开屏广告和跳过工具：开屏广告可能属于合法的“守序”商业模式，跳过广告的工具则像不完全遵守规则、但试图改善用户体验的“混乱善良”。
- “摇一摇”广告被认为尤其恶劣，因为用户只要手持手机发生轻微晃动，就可能在来不及点击跳过前被带入广告页面。
- 工信部门曾要求 App 整改此类广告，但节目观察到主 App 与用户较少的国际版、轻量版之间可能存在执行差异，形成“上有政策、下有对策”。
- 对特别影响使用体验的广告，主持人建议投诉；如果服务并非不可替代，也可以直接停止使用，而不应期待单个用户长期在每个页面与诱导设计斗智斗勇。

### 30:22-47:53：CCIDE 争议与“自主创新”

- 节目讨论 `CCIDE` 项目：它被宣传为国产、自主创新的开发工具，但网友发现其前端明显基于 VS Code，项目规模还涉及数亿元级别的数字化建设，因此引发强烈质疑。
- 后续解释称，项目除了基于 VS Code 的前端，还包括权限、项目管理、需求管理、任务协同、知识共享和组件库等后端及配套能力；节目认为其中一部分说明可以成立，但不能把使用开源底座本身说成自主创新。
- 主持人区分“自主可控”和“自主创新”：拥有源代码、能够维护、必要时可以分支继续开发，足以构成可控能力；在开源代码之上诚实地说明二次开发内容，反而是正常且可持续的工程路径。
- 节目将争议放到利益链条和指标压力中理解：领导需要“自主可控”和“创新”的项目，关系企业熟悉管理系统，却难以在基础工具上做出真正创新，于是容易把换皮、包装和开源底座当成政绩。
- 真正的改进不只是网络嘲讽，还包括让决策者理解开源、许可证、自主创新和自主可控的区别，并由具备专业知识的人参与评审、验收和教育。

### 47:53-01:00:39：福岛排海争议与舆论传播

- 节目把围绕福岛核处理水排海的网络观点分成反对政策、嘲讽焦虑、给反对者扣帽子，以及以数据和“专业身份”包装的科普等类型，提醒听众不要把情绪、嘲讽和可靠证据混为一谈。
- 节目认为，日本政府和日本驻外机构长期重视国际形象建设，并在此次事件中投入大量预算影响中文互联网舆论；主持人把这种做法放进更长期的认知作战和国际传播背景中理解。
- 对“我只抵制存货”等自称理性客观的说法，节目警惕其可能演变成“与我观点一致才算理性，不一致就是不纯粹”的网络话术。
- 节目明确表示，不能因为网络上出现伪装成数据流的内容，就反过来把所有担忧都视为无知；判断仍应回到原始资料、数据来源和可重复的专业分析。

### 01:00:39-01:10:39：事故处理、方案选择与数据证明

- 主持人回顾福岛事故后反应堆融毁和污染水扩散的过程，并以切尔诺贝利的处理方式作对比，认为日本当时没有在最关键阶段采取足够果断的控制措施，留下了持续的污染源。
- 节目称，东电、中国和俄罗斯科学家曾提出多种后续处理方案，排海只是其中之一，而且是成本较低、把风险扩散到海洋和其他国家的方案；因此日本政府需要对全世界充分说明选择它的理由。
- 节目强调，排海方案在理论上可能成立，并不等于现实执行已经安全。国际原子能机构调查使用的样品和数据主要由东电提供，其他国家难以独立采集，不能把这种报告简单宣传为对排海方案的批准。
- 主持人还质疑东电用少量样本、有限检测项目和不充分的核素信息说明数百万吨废水的做法，认为这种证明方式不足以消除周边国家的合理担忧。

### 01:10:39-01:20:42：媒体结构与国际认知差异

- 节目认为，日本在舆情宣传上的投入远高于排海处理方案本身的投入；如果把相同资源用于更封闭、更安全的处理方式，可能有机会减少跨国争议。
- 对日本国内反对声音不够大的问题，主持人从政府右翼化、媒体结构、公众顺从以及长期接受的福岛地方污染现实等因素解释，并指出渔业群体可能并不知道政府到底做了多少国际沟通。
- 对英语国家，节目认为日本长期经营的正面国家形象、英语媒体的信息优势以及国际机构的组织结构，使不少普通人根本不知道排海争议的具体内容。
- 节目同时指出，中国并非唯一担忧的一方：日本国内民调仍有相当比例的反对者，韩国民众也普遍表示担忧；西方严肃媒体的报道虽然较冷淡，但可作为补充材料帮助读者区分科学争议和意识形态宣传。

### 01:20:42-01:30:23：科学不确定性与应对建议

- 节目引用英文媒体和《国家地理》对不同科学观点的整理，认为当前争议的关键不是简单宣布“绝对危险”或“绝对安全”，而是日本在方案可行性和安全性尚未被充分证明前就开始执行。
- “相信我们会处理好”不能替代公开数据、独立采样和可重复验证；如果长期、广泛的风险判断最后出错，后果也不是单个国家可以独自承担的。
- 国家层面可以推动更多国家在排放点附近独立采样、长期监测并公开数据，同时持续进行国际沟通，保留与风险相称的经济措施。
- 国内还需要保护相关渔业和餐饮产业；个人层面则可以根据自己的风险判断减少日本水产品消费，辨别信息来源，并关注主管部门发布的沿海水情监测信息。

### 01:30:23-01:40:03：高校的算力焦虑

- 大模型兴起后，高校同时面临科研和教学冲击：学校争抢显卡、建设算力中心、尝试训练垂直模型，也在考虑把大模型原理和使用纳入计算机、人工智能及跨学科课程。
- 节目认为，高校不是商业公司，不应把大量经费全部投入 GPU 竞赛；但设备确实决定某些研究能否开展，完全没有算力也会限制学校做出独有成果。
- 更重要的问题是找到高校与企业的分工：企业可能拥有更多算力和算法人才，学校则有教师、学科积累和高质量教学内容。双方应围绕各自擅长的部分合作，而不是只比较购买了多少显卡。
- 算力依赖也可能是阶段性现象。随着 GPU 国产替代、软件兼容和硬件成本改善，算力会逐步普及；在等待基础设施发展的同时，高校仍应先明确自己的真实研究和教学问题。

### 01:40:03-01:50:44：教育大模型的落地路径

- 节目认为，大模型跨过重要技术门槛后，下一步瓶颈不只是继续堆算力，而是把已有成果消化到具体行业和应用场景中；教育领域尤其需要面向真实教学工作的定制。
- AI 助教可以承担答疑、解释和个别指导等较难规模化的环节；AI 也可以根据知识库生成名词解释、概念关系图和辅助教学的小视频，但核心课程内容和质量判断仍需要教师负责。
- 教育 AI 缺少的往往不是概念，而是高质量原始内容、可靠数据和懂得判断内容优劣的领域专家。学校可以整理教师经验和课程资源，企业则提供模型、算法和工程能力。
- 领域专家在实际答疑中持续校正 AI 的回答，有机会逐步形成更熟练的领域助教；人工标注、分类和预处理还可能降低后续训练的算力需求，但不同领域需要分别积累，不能期待一个通用方案解决所有问题。
- 节目把这条路线视为高校与工业界共同推进的方向：算力竞赛会继续，但更值得投入的是高质量数据、领域知识、应用验证和长期合作。

## 核心观点

1. 真正有生命力的软件往往解决了底层、通用且长期存在的问题；产品如果只围绕短期需求和快速迭代设计，就很难留下同样持久的技术价值。
2. 合法的商业模式不等于好的用户体验。开屏广告和跳过工具之间的冲突，说明法律判断、商业收益和用户感受需要分别讨论，不能用其中一个替代另外两个。
3. 自主可控不必排斥开源，关键在于是否拥有源代码、维护能力和真实的二次开发成果；把开源底座包装成完全自主创新，只会掩盖基础能力和利益分配问题。
4. 涉及跨国和长期风险的科学方案，必须以充分说明、独立数据和可重复验证建立信任；“相信我会处理好”不是对外部风险负责的证明方式。
5. AI 落地的竞争不只有算力竞争。高校可以利用领域专家、课程和高质量数据，与企业的模型和工程能力结合，把技术转化为可验证的教育产品。
