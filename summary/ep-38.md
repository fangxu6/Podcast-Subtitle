# 第 38 期 编程语言排行榜

## 内容摘要

节目先从一名在线课堂教师遭遇有组织网络辱骂、最终突发心脏病去世的事件谈起，讨论网络空间中的“爆破组”、未成年人对线上力量的误用，以及现实法律、学校教育和平台治理的滞后。节目借《女神异闻录 5》中怪盗团被公众追捧、又因他人利用其行动造成死亡而反思责任的情节，强调网络围观和集体伸张正义同样可能失控。在线课堂需要密码、身份认证、访问控制、教师培训和平台侧的自动化干预，责任不能只推给老师“学会使用工具”。

随后节目谈到 Twitter 裁员引发的互联网企业收缩，以及股市更适合被理解为市场情绪和预期的指标，而不是宏观经济的直接结果。编程语言部分以 TIOBE 排行榜为中心，讨论 Python 因机器学习和 NumPy 生态上升、Rust 以更严格的编译期约束换取可靠性、Delphi 和 Ruby 等老语言为何仍有用户，以及排行榜衡量的是使用、关注、学习和厂商支持，而不是语言本身的优劣。

读书环节先介绍《教育未来简史》对 2038 年学习场景、数字原住民和教育工作者角色的设想，同时指出这类未来图景容易忽略技术带来的负面影响。接着从《菲利普二世》和查理五世的传记引出《无敌舰队》，推荐其把人物、战争、物资和组织细节结合起来的历史叙事。最后介绍乔治·波利亚的《怎样解题》，将理解问题、拟定计划、实行计划、回顾延伸概括为可迁移到算法和科学思考中的解题框架。

## 时间线

### 00:00-08:03：网络暴力与《女神异闻录 5》的隐喻

- 节目讨论“爆破组”有组织地闯入在线课堂、辱骂教师的现象，并以一名教师遭遇线上辱骂后突发心脏病去世的事件说明其严重性。
- 主播认为，这已经不只是个体因一时愤怒发泄，而是借群体行动获得现实中不会轻易拥有的破坏力量。
- 《女神异闻录 5》中的怪盗团通过“改心”让坏人悔过，后来却被更大的恶利用并造成死亡；这个转折揭示了集体正义、围观心理和责任委托可能失控。
- 节目还提到，人们不愿自己承担判断和决策责任时，容易把“惩罚坏人”的任务交给别人，最终又把后果归咎于行动者。

### 08:03-19:51：未成年人、平台责任与在线课堂治理

- 节目认为，小学高年级到高中阶段的未成年人更容易被线上即时快感和“我竟然能做到”诱惑；教育与越界后的惩罚都不能缺位。
- 现实中冲进教室打扰教师会受到约束，线上空间却可能因为取证困难、法律定义滞后而被误认为只是开玩笑，节目主张认真讨论虚拟空间暴力的责任边界。
- 学校把腾讯会议或腾讯课堂链接集中登记在开放共享文档中、教师又很少设置密码，会让陌生人轻易获得课堂入口；线上教学还缺少系统性的安全培训。
- 平台应提供易用的密码和身份认证、陌生账号识别、异常发言监测和一键禁言等能力，让教师在突发干扰时能快速恢复课堂秩序，而不是只要求教师自行学习。

### 19:51-29:24：互联网企业收缩与股市信号

- Twitter 收购后的快速裁员被节目视为行业收缩的信号，Facebook 的元宇宙投入、亚马逊的市值下跌，以及国内互联网企业的收缩也被放在同一背景下讨论。
- 节目提醒，股市是复杂经济因素中的一个影响因素，更直接反映交易者对未来的乐观或悲观，不能简单当作宏观经济和政治决策的结果。
- Apple 被描述为全球供应链的重要节点，上游连接大量零部件和制造商，因此不能只按普通互联网公司看待；供应链波动也会直接影响其经营。
- 主播判断，虚拟概念和高估值独角兽会面临更大压力，粮食、能源和工业制造品等“过日子必须用”的实物经济可能比概念资产更能经受收缩期考验。

### 29:24-39:33：TIOBE、Python 与 Rust

- TIOBE 编程语言排行榜长期保持相对稳定的前十名，Python 的上升主要受机器学习、科研使用习惯和 NumPy 等基础库推动，生态会通过使用者和框架形成滚雪球效应。
- C 语言与 Unix 及操作系统发展相伴而生；Go 和 Rust 则被讨论为试图在部分场景替代 C 或 C++ 的较新语言。
- Rust 的性能接近 C，同时把生命周期、引用和内存关系更多交给编译期检查；代价是学习和编码时必须理解这些底层约束，不能像垃圾回收语言那样完全交给运行时处理。
- 节目认为，Rust 更适合有较强工程能力、培训能力和长期投入的大型技术团队；对资源有限、人员基础一般的团队，学习成本可能超过短期收益。

### 39:33-51:20：Pascal、Visual Basic 与 Delphi 的生命力

- 主播回顾 Pascal 作为教学语言的规则性和结构化编程价值，以及 Turbo Pascal、Visual Basic 等工具在早期快速开发中的影响。
- Delphi 在 Turbo Pascal 基础上加入 Object Pascal、可视化表单和面向对象继承，让界面本身成为可复用、可扩展的类；它还能够编译出原生程序，必要时嵌入汇编代码。
- Delphi 曾长期领先 Visual Basic，后来受微软生态和市场竞争影响而衰落，但节目注意到它仍在排行榜中上升，并继续用于管理信息系统和内部定制系统。
- Delphi 社区还在维护 Free Pascal 和 Lazarus，后者提供类似 Delphi 的 IDE 和跨平台编译能力，说明成熟工具即使退离主流视野也可能保留稳定的实际需求。

### 51:20-54:53：Ruby 生态与排行榜的含义

- 节目援引开源软件安全报告，称 RubyGems 中接近八成的软件包已经不再活跃，以此表达对 Ruby 生态持续衰退的担忧。
- TIOBE 明确强调排行榜不是语言质量排名，而是综合使用人数、关注度、学习情况和厂商支持等信号。
- Delphi、Ruby 等语言即使缺少网络声量，仍可能因为企业历史系统和迁移成本而被持续使用；榜单反映的是生态和存量，不等于开发者偏好的简单投票。

### 54:53-01:05:07：《教育未来简史》与数字化学习

- 《教育未来简史》以 2038 年的学习场景设想教育变化，讨论数字化、互联网、终身学习和教师与学生之间不断扩大的数字鸿沟。
- 书中总结的数字化一代特征包括通过多种数字渠道获取信息、并行处理任务、优先处理图像和视频、多人协作、快速阅读、即时学习和奖励，以及在虚拟与现实世界之间切换，并偏好有用又有趣的内容。
- 未来学习被描述为更终身化、以学习者为中心、个性化和自适应；教师则应成为终身学习者、学生的引导者和思维水平的评价者，并拥抱探索式学习与技术工具。
- 节目认为这套图景较为理想化，较少讨论数字技术带来的干扰、风险和解决方案；教育面临的真正挑战，是如何在技术改变学习方式时同步建立新的制度和能力。

### 01:05:07-01:18:21：从菲利普二世到《无敌舰队》

- 主播先介绍查理五世和其子菲利普二世的传记：查理五世统治的领地分散在欧洲、美洲和非洲，菲利普二世则延续了西班牙哈布斯堡王朝的扩张。
- 菲利普二世的传记涉及 1588 年西班牙无敌舰队进攻英国，但对海战本身展开不足，于是主播进一步推荐马丁利的《无敌舰队》。
- 《无敌舰队》获得普利策奖，节目称赞它以严谨史料为基础，把菲利普二世的宗教动机、德雷克等人物，以及海军筹备、造船、补给、疾病和战场组织写得具体而生动。
- 节目借西班牙、英国和美国之间的霸权转移讨论帝国交接：共同的宗教、民族和制度背景可能带来较和平的过渡，差异更大时则可能通过冲突完成转换。

### 01:18:21-01:31:15：《怎样解题》与可迁移的思维方法

- 乔治·波利亚既是数学家，也是长期研究数学教育的教育者；《怎样解题》与《数学与猜想》《数学发现》共同探索数学思维是否存在可传授的普遍规律。
- 波利亚将解题分为了解问题、拟定计划、实行计划、回顾延伸四步，节目特别强调开头的分析与问题转化，以及做完之后的复盘和推广。
- 书中还整理了类比、辅助元素、泛化、归纳、特殊化、分解、逆向推理和图式等启发式方法，例如先把四面体重心问题类比为更熟悉的三角形重心问题。
- 这些例子虽然来自数学，但节目认为它们同样适用于科学思考和算法教学；真正有价值的不是机械做出一道题，而是总结解决问题的模式。

## 核心观点

1. 线上空间的伤害不能因为缺少实体接触就被降格为玩笑，平台、学校、教育和法律需要共同承担治理责任。
2. 编程语言排行榜反映的是使用和生态信号，而不是绝对质量；语言选择要结合问题场景、团队能力、学习成本和长期维护。
3. 技术对教育的影响不会只有效率提升，数字鸿沟、注意力、课堂安全和制度准备同样决定未来教育能否落地。
4. 历史和技术讨论都需要把宏大结论放回具体的人物、组织、资源和行动细节中，才能避免只剩下抽象标签。
5. 把问题理解清楚、拆分、类比、执行并回顾推广，是可以跨越数学、算法和其他科学领域的通用思考框架。
