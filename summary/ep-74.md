# 第 74 期 常温超导大事件的背后

- 来源：`transcript-site/episodes/ep-74.html`

- SRT 条目：377
- 阅读段落：116

## 内容摘要

本期先简短缅怀 Vim 作者，并讨论 Vim 模态编辑的影响力。节目主体回顾韩国团队宣称发现室温超导材料后引发的舆论热潮，分析公众期待、媒体叙事和平台流量如何共同放大一个尚未被充分验证的研究结果；随后从抗磁性、迈斯纳效应、零电阻、高温超导理论和材料制备等方面解释，为什么“出现异常现象”“理论上可能成立”和“已经证实超导”不能混为一谈。

节目进一步讨论科研团队、预印本和媒体传播中的责任边界，认为自然科学研究必须以可验证的证据为底线，也不能因为一次事件就强化对某个国家或地区的刻板印象。之后话题转向 AI 时代的外语学习：机器翻译已经能显著帮助读写，但听说仍需要针对具体场景进行高强度练习，真正有价值的产品应结合领域资料、角色扮演和及时反馈。

读书环节推荐钱穆的《中国史学名著》、米歇尔·雷斯尼克的《终身幼儿园》，以及《是，大臣》《是，首相》。三组内容分别从中国史学传统、以 Scratch 为代表的创造力学习、英国政治与文官体系展开，最后落到历史积累、动手创造和理解组织运行机制的长期价值。

## 时间线

### 00:00-05:44：Vim 作者与模态编辑

- 节目开场提到 Vim 作者去世，并回顾 Vim 在程序员群体中的深远影响；“怎么退出 Vim”之所以成为经典段子，正是因为它在服务器和类 Unix 系统中常见，却不符合普通编辑器的直觉。
- 主播分享了把 Vim 当作服务器端快速文本编辑器的使用方式，也提到少数重度用户会通过大量配置把几乎所有工作都放进 Vim。
- Vim 的插入模式与命令模式被认为是一种高效、先进但有学习门槛的编辑模型，因此 Emacs、VS Code 和 JetBrains 等工具都提供了 Vim 兼容模式。

### 05:44-18:52：室温超导事件与舆论放大

- 节目原本只打算简短回顾室温超导事件，但一周内出现的大量直播、短视频、论文和新闻，让这个尚未定论的研究结果变成了高度喧闹的舆论事件。
- 公众希望突破真的成立，媒体希望参与创造新闻，平台则通过热搜和推荐持续推高相关内容；三者形成正反馈，吸引更多普通用户和科研人员进入讨论。
- B 站账号“关山口男子技师”发布的视频没有提供超出韩国论文的可靠证据，却用“首次验证复现”“渴望实现完整磁悬浮”等带有强烈引导性的表述包装一个半支撑、半悬浮的现象。
- 节目将这一现象与真正超导材料的稳定、完整磁悬浮作对比，指出后者的悬浮高度稳定，受到扰动后也表现出明显不同的物理特征。
- 平台还推送了东华大学等团队的相关结果，即使论文数据存在疑点，标题和热搜位置仍可能先于严谨核验塑造公众印象。

### 18:52-30:35：从抗磁性到超导证据

- 抗磁性可以解释材料出现一定的半悬浮现象，但它不等于超导所要求的完全抗磁性，也不能替代迈斯纳效应、零电阻等更严格的验证。
- 信息流会优先迎合用户已经期待的结论，通过正反馈强化观点；如果用户确实想获得知识，就必须警惕媒体和算法对信息的筛选与放大。
- 超导研究通常区分低温超导和高温超导，约 50 开尔文是讨论中的分界线。低温超导已有成熟理论，而高温超导即使远高于这一温度，也仍缺少完整、普遍接受的理论解释。
- 计算机模拟只能说明在某个模型和算法下没有发现明显矛盾，不能直接证明理论可行，更不能证明材料已经实现室温超导。
- 材料制备过程虽然看似简单，但铜原子的掺杂分布、配比、纯度和加工时间都可能改变结果；每轮制备和验证都可能需要数十小时，重复复现本身就是困难的工程工作。

### 30:35-36:35：科研传播、责任与刻板印象

- 预印本可以用于快速交流、占据研究方向或报告中间结果，但研究者仍应遵守科学共同体的基本规则，说明已经做到什么、尚未做到什么，以及乐观判断的依据。
- 冒险研究可以有回报，也必须有失败和错误的代价；如果只传播半成品和乐观预估，却不承担错误后果，就会激励炒作而削弱长期、扎实的研究。
- 自然科学的表达不能靠语气词和媒体化暗示诱导读者把可能性当成事实，实证和可验证性是研究者不能放弃的底线。
- 节目提醒听众不要因这次事件强化“某个国籍的人更容易造假”之类的地域刻板印象；面对新闻应坚持实事求是，而不是先按来源给出结论。

### 36:35-50:34：AI 时代的应急外语设想

- 一位主播因受邀参加日内瓦的全球开源峰会而产生外语焦虑：旅游时的简单求助和需要听懂讨论、表达观点的国际会议，是难度完全不同的两类场景。
- 节目设想一种面向具体任务的 AI 外语训练工具：用户先说明将要见到的人、讨论的领域和对方可能提出的问题，再由 AI 生成场景对话、扮演不同角色并指出更好的表达方式。
- 机器翻译已经能较好地辅助读写，未来还可能实现双方各自使用母语的跨语言聊天；但这并不意味着所有外语学习都可以取消，至少要保留能够理解和参与实际交流的基础能力。
- 外语学习的听、说与读、写不同。一个人可以在脑中听过大量标准发音，却在真正开口时无法顺畅复现；听写等训练之所以有效，也正因为听力和口语需要持续练习。

### 50:34-01:04:35：听说训练与领域定制

- 节目认为当前 AI 在文本理解、翻译和改写方面能帮很多忙，但实时听说要求快速反应和即时组织句子，同声传译仍不是可以轻易解决的问题。
- 出国旅游时，翻译软件、文字输入和共享汉字等工具已经能解决大量临时求助；参加学术论坛、做上市路演等场景，则需要提前熟悉自己要表达的内容和目标听众的表达习惯。
- 对这种高要求的场景，AI 可以代替陪练者提供角色模拟和反馈，却代替不了使用者自己的高强度练习。节目估计，两到四周、每天数小时的定向训练更现实，时间太短难以形成能力。
- 常见生活场景的口语练习适合由 AI 大量承担，真正困难的是专业领域：系统需要快速灌入相关语料，理解前沿议题，并准确指出用户在听说过程中的问题。

### 01:04:35-01:17:01：《中国史学名著》与历史信仰

- 推荐的钱穆《中国史学名著》是主播进入历史阅读的入门书，内容来自钱穆在台湾带博士班时讲授中国历代史学名著的课堂录音，读起来像一份深入浅出的传统史学导游图。
- 这本书不仅介绍历史著作，也梳理中国史学史：不同历史学家如何记录和理解过去，以及中国人重视历史、通过后世评价确立身后名的传统。
- 节目把历史称为中国人的信仰，并将史学家看作这种信仰背后的“祭司”；主播同时提醒，孔子笔下的春秋有避讳，司马迁则借助互文等写法，在压力下尽量保留历史的完整性。
- 钱穆从基层教书经历一路成为重要历史学家和教育家，这本课堂式作品也体现了他把复杂史学问题讲得清楚、易于入门的能力。

### 01:17:01-01:30:33：《终身幼儿园》与创造力学习

- 《终身幼儿园》来自 MIT 媒体实验室教授米歇尔·雷斯尼克及其团队的长期实践，Scratch 正是这套创新教育理念的重要产物。
- 书中把创新看作不断尝试的循环：想象、创造、游戏、分享、反思，再进入新的想象。单纯把积分、卡通或闯关叠加到教学上，并不能自动激发思考和创新。
- 团队总结出培养创造力的四个关键词：项目、热情、同伴和游戏。项目提供具体目标，兴趣推动投入，同伴带来分享与协作，游戏则意味着实验、冒险和挑战边界。
- Scratch 不只是编程工具，也是能够分享、协作和相互反馈的线上社区；类似理念还延伸到可编程机器人和项目式学习。节目担心国内把“创造力学习”简单包装成“少儿编程”，从而忽略了背后的学习方式。

### 01:30:33-01:40:58：《是，大臣》《是，首相》与文官体系

- 《是，大臣》和《是，首相》原本是 20 世纪 80 年代播出的英国情景喜剧，后来由编剧改写成以大臣吉姆·哈克日记形式呈现的政治讽刺小说。
- 作品围绕三角关系展开：民选、会随选举更替的大臣哈克，长期留在政府部门的常务文官汉弗瑞，以及同时连接政治主人和文官体系的私人秘书伯纳德。
- 哈克试图推动节约和改革，汉弗瑞则从既得利益、组织惯性和“不必要的麻烦”等角度阻拦；作品既展示文官体系积累的经验，也讽刺其形成的利益集团和自我保护机制。
- 节目推荐其中关于官方否认、政治双重标准、分裂欧洲和应对危机四部曲的经典对话，认为这些观察在四十年后仍能帮助读者理解政府运作与政治话语。

## 核心观点

1. 面对重大科技突破，必须把公众期待、尚未解释的现象和可重复的实验证据分开；一个有传播力的标题不能替代零电阻、完全抗磁性和独立复现。
2. 科研传播可以报告中间结果，但研究者必须说明证据边界并承担错误的代价；平台和媒体的放大，不应改变实事求是的底线。
3. AI 会重新分配外语学习的时间，尤其能降低读写和常见场景练习的成本，但听说能力仍依赖真实的即时互动和持续训练。
4. 教育工具的价值不在于增加游戏化包装，而在于是否让学习者围绕具体项目动手创造、分享、协作和反思。
5. 技术、历史和政治作品都需要长期积累才能真正理解；工具可以加速获取和练习，却不能替代人的判断、实践与责任。
