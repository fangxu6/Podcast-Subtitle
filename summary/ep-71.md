# 第 71 期 读书会与颜宁之问

## 内容摘要

本期先讨论生成式人工智能管理办法正式版本删去“代码”适用范围的变化，以及代码生成在版权和监管上的特殊难题。节目随后从开源模型和基准测试谈到听友自发组织的读书会，比较线下分享、GitHub 协作、付费主题读书会、出版社读书群和长期共读等形式，认为好的读书会既要围绕共同兴趣，也要产生高质量交流。

中段由国际数学奥林匹克和颜宁面试博士生时提出的“十年后你想探索什么科学问题”展开，重点讨论中国教育和科研体系如何选拔、培养真正能够开辟新方向的顶尖人才。节目认为，以积点、论文数量等可量化指标为主的评价体系有利于普遍性教育的公平和效率，却可能压缩精英人才的思考时间与试错空间；更高层次的培养需要同行评价、导师发现、物质基础和制度试验。

后半段推荐阎学通的《世界权力的转移：政治领导与战略竞争》，介绍“道义现实主义”及其以较长历史尺度理解大国崛起的尝试；又推荐《数学要素》和《矩阵力量》，讨论可视化、可运行代码与交互式数字教材如何帮助学习抽象数学。最后通过《合作的进化》和《超级合作者》讲解囚徒困境、公地悲剧、重复博弈与合作演化，落脚到人与人、企业以及国家之间如何在竞争中建立合作。

## 时间线

### 00:00-07:50：生成式 AI 监管与开放模型

- 生成式人工智能管理办法从征求意见稿变成正式版本，文本、图像、声音等适用范围仍在，但“程序代码”被删去；节目围绕这一变化讨论代码究竟是可执行的文本，还是需要单独处理的对象。
- 主播推测，代码的版权定义和司法实践还不够成熟，可能增加监管的实施复杂度；删去代码未必意味着代码生成不重要，更可能是暂时难以落地管理。
- 节目认为代码生成的能力已经比许多其他生成任务更强，但国内当时还没有看到同等成熟的竞品；真正开放、任何人都能较自由使用的模型，对科研、行业定制和缺少大厂资源的公司很有价值。
- 各类基准测试和排行榜尚未形成公认标准。节目判断，开放模型若想突出重围，除了模型能力，还要依靠广泛可用性和社区反馈。

### 07:50-17:46：读书会的组织方式

- 节目介绍 KCC 上海的人类学与开源读书会，以及听友在 GitHub 上用仓库和 issue 组织的线上读书分享；后者让每本书成为一个可持续讨论的主题。
- 其他形式还包括按月投票、要求交书评的“强读会”，按年度主题选书并邀请专家答疑的付费读书会，出版社组织的新书群，以及用每日小节和阶段性总结共读《正义论》的小群。

### 17:46-25:54：读书会的交流价值

- 读书会不应只是没有边界的闲聊，也不应只是为了完成阅读任务。节目认为它的两个核心作用是促进阅读和促进交流，其中后者需要围绕书籍与共同兴趣形成有质量的讨论。
- 开源社区的读书会还可以服务于翻译、术语统一、校对和传播：成员先共同理解原书，再把内容翻译、审核并制作成可回看的分享材料。
- 读书只是聚合共同语言和兴趣的载体，影视、游戏、历史或其他学科也可以用同样方式形成社群；关键是主题是否能带来真正的交流。

### 25:54-34:02：数学竞赛与“颜宁之问”

- 节目从当年的国际数学奥林匹克谈起：比赛只有六道题，题目集中在初等数学，最后一道平面几何题极难，绝大多数选手无法得分。
- 主播认为，奥数成绩既不能被简单包装成教育全面成功，也不应因为中国队没有产生足够多的菲尔兹奖得主，就反过来否定竞赛本身；竞赛考察的是特定的数学能力。
- 颜宁在博士推免面试中提出一个开放问题：如果十年后拥有优秀团队、充足经费和顶级设备，最想探索的科学问题是什么？二十多名候选人的回答没有让她眼前一亮。
- 这个问题把讨论从竞赛成绩引向精英培养：会考试、会跟随既有课题，并不等于能够发现值得长期投入的新问题。

### 34:02-43:50：从“为什么没有诺奖”到科研创新

- 节目反对把“为什么没有诺贝尔奖、菲尔兹奖”直接归结为中国文化、社会或教育制度的单一缺陷，认为一个后起者在不同领域发展不均衡是正常现象。
- 中国过去几十年更重视应用科学和与民生相关的实践，实践中形成的经济成就还没有充分被提炼成具有解释力的理论，这也是实践领先与理论总结滞后的例子。
- 顶尖科研不仅需要按部就班的技术能力，还需要想象力、灵感、胆识、魄力和运气。节目担心现有培养方式更擅长训练“跟着别人做事并在局部超越”，却不够擅长培养开辟方向、带领团队的人。
- 主播将“dream big and aim high”视为顶尖科研人才的特殊要求，而不是对所有学生的普遍要求；问题在于这样的目标意识在最顶尖的学生中是否足够多。

### 43:50-52:37：积点评价与跟随式培养

- 当前研究生保送和选拔很大程度依赖本科积点，积点本质上是多门课程考试成绩的汇总；即使学校拥有一定自主权，实际操作仍常回到可量化排名。
- 学生会按照评价指标分配时间：本科阶段围绕考试和积点竞争，博士阶段则可能围绕论文数量和档次竞争。被评价什么，往往就会努力做什么。
- 国外博士申请通常也看成绩，但更强调推荐信、代表性成果、导师和同行的综合判断，积点更多像门槛而非单一排序依据；这种体系也依赖成熟的学术共同体。
- 节目认为，机械指标降低了评价成本，却容易让学生过拟合既定目标，缺少探索新问题、试错和形成独立研究兴趣的时间。

### 52:37-01:07:07：精英教育的公平、自由与制度试验

- 普及性教育可以更强调可比较、可量化的公平；但如果目标是选拔极少数顶尖人才，节目认为完全依靠统一考试可能不够，需要导师发现、推荐和同行评价，也意味着要接受一定程度的非标准化。
- 顶尖人才需要的不只是实验设备，还包括财务和时间上的自由。没有生存压力、事务负担较少，才更有可能长期思考尚未被定义的问题；这并不意味着贫困环境不能产生伟大成果，而是制度不能把困难当作培养方式。
- 硕士阶段可能是从“聪明、会学习”转变为“适合做研究”的关键阶段，导师能否识别潜力并把学生推荐给下一阶段的导师，会影响培养结果。
- 代表作评价、博士毕业不再硬性要求论文，以及清华姚班、丘班等跳出现行选拔体系的试验，都被视为可能探索新路径的局部改革；但真正依赖全球同行评议时，也要防止把评价变成导师关系和学术圈子的放水。
- 节目认为，制度变化需要时间和反复评估。科技竞争最终比拼的是金字塔尖的创新能力，而不仅是博士数量或一般教育的平均水平。

### 01:07:07-01:08:23：顶尖人才与科技竞争

- 节目把精英科研培养与近期的芯片和人工智能竞争联系起来，认为限制高端芯片的目的之一，是延缓对手在 AI 顶层能力上的进展。
- 因此，教育讨论不能只停留在普通人的升学和就业层面，也要考虑如何让少数真正能够引领方向的人获得更好的成长条件。

### 01:08:23-01:17:24：《世界权力的转移》与道义现实主义

- 节目推荐阎学通的《世界权力的转移：政治领导与战略竞争》，介绍其从先秦思想和中国历史资源出发，构建“道义现实主义”的尝试。
- 现实主义通常强调国家实力和利益最大化；“道义现实主义”则认为，短期依靠压制的霸道路线可能有效，但长期治理成本高、不稳定，重视道义的王道路线反而可能更有持久性。

### 01:17:54-01:27:22：理论构建与新的国际秩序

- 主播特别认可这套理论对适用范围的限定：它主要解释大国崛起的成败，并不声称能够解释所有国家和所有现象。建立理论还应立足事实、保持概念清晰，并在事实不支持时修改自己的假设。
- 节目把二战后的核武器、知识经济和全球化视为不同于传统霸权更迭的新条件。全面战争不再是大国竞争的常规手段，知识可以成为不依赖领土占领的增长来源，全球化也让非传统安全问题和共同利益更突出。
- 书中提出把传统的仁、义、礼等观念现代化为国际公平、国际正义和文明间相互尊重，并将其作为新时代大国崛起的“王道”方案；主播也将其与“人类命运共同体”的提出联系起来，但明确这是自己的判断。

### 01:27:23-01:39:32：《数学要素》《矩阵力量》与数字教材

- 《数学要素》和《矩阵力量》分别覆盖从基础数学到微积分、以及以矩阵和线性代数为核心的内容，节目推荐它们的主要原因不是知识新颖，而是表达方式具有强烈的可视化特点。
- 大量图形、具体例子和习题可以帮助读者理解抽象符号；书中的图形还用 Python 等代码生成，相关代码和内容放在 GitHub 上，读者可以下载、运行并修改参数。
- 节目认为，数学教材可以从纸面阅读发展为在线的交互式数字课本：读者不仅能看到公式和图形，还能拖动、缩放、旋转对象，改变参数并即时观察结果。
- 编程与教学结合后，教师可以制作帮助学生理解概念的交互工具。数字教材的价值不只是视觉上更漂亮，更在于把阅读、实验和反馈放在同一个学习过程中。
- 纸书仍然适合保存和阅读，但这类教材最理想的形态可能是代码可运行、图表可互动的网页；人工智能和机器学习对数学基础的需求，也会推动这种教材形态继续发展。

### 01:39:32-01:56:45：囚徒困境与合作的进化

- 《合作的进化》和《超级合作者》以博弈论为入口。囚徒困境说明，即使两个人都知道共同沉默对双方更有利，在单次博弈中，出卖对方仍可能成为各自的理性选择，结果反而让双方都受损。
- 公地悲剧把同样的逻辑放到公共资源上：每个人都觉得自己多放牧一些不会改变结果，所有人的短期理性选择最终会耗尽共同草地。
- 在重复博弈中，参与者会考虑未来的合作关系。“一报还一报”先对陌生合作者选择合作，遭遇背叛后再作出对应回应；计算机模拟和现实中的案例都被用来说明，这种有善意、能惩罚背叛、也能恢复合作的策略具有竞争力。
- 《超级合作者》进一步讨论合作的五种机制：直接互惠、间接互惠、空间博弈、群体选择和亲缘选择。合作不仅发生在人与人之间，也可以从细胞、动物群体和社会组织等不同层面观察。
- 节目的落点不是否认竞争，而是认为合作也是进化和社会进步的重要动力。对个人、企业和国家而言，先释放合作意愿，再对背叛作出有限且可逆的回应，可能比从一开始就互相猜疑更有利于长期关系。

## 核心观点

1. 生成式 AI 的能力发展会不断先于现有定义和监管边界，代码生成尤其同时涉及可执行性、版权和责任问题；暂时删去一个对象不等于问题已经解决。
2. 读书会的价值不在于把人强行聚在一起完成阅读，而在于围绕共同兴趣形成共同语言、持续输出和高质量讨论；书籍只是组织社群的一种载体。
3. 普遍性教育适合使用透明、可比较的指标，但顶尖人才培养不能只追求可量化的公平，还需要导师判断、同行评价、自由时间和允许试错的制度空间。
4. 理论应当从事实出发，明确适用范围，并在现实不支持时修改假设；用短期力量解释长期秩序，往往会忽略治理成本和合作关系。
5. 合作不是竞争的反面，而是能够在重复互动、声誉、空间结构和亲缘关系中稳定演化的策略；面对合作与背叛，关键是同时保留善意、回应和重新合作的可能。
