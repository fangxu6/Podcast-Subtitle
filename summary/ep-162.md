## 内容摘要

本期先补充上一期“AI 时代的 IDE 战争”的后续，讨论微软对 VS Code 第三方克隆和专有插件的限制，以及 Cursor、JetBrains 等开发工具厂商在 AI 时代面临的生态、授权和产品定位问题。节目也对即将发布的鸿蒙电脑提出疑问，认为它能否区别于带键盘的平板，关键取决于桌面应用和整体生态，而不只是硬件形态。

随后节目分析中美高级别官员在瑞士接触的性质，认为这更像摸底和试探，并非已经达成正式协议；同时从金砖、中欧和东盟加三的动向，讨论亚洲为美元体系准备替代结算和融资机制的意义。节目还围绕印巴冲突中的空战报道，重点解释超视距作战、预警机、数据链、导弹和整套作战体系如何共同决定战果。

后半段回顾中国从 1990 年代开始的军事建设和改革，串联海湾战争、银河号事件、南联盟使馆被炸、南海撞机等历史节点，以及歼-10、辽宁舰、歼-20、052D 和新军改的进展。最后介绍人社部新增职业和工种，认为职业分类既能反映产业变化，也能为就业统计、职业教育和 AI 相关新岗位提供制度接口。

## 时间线

### 00:00-18:16：VS Code 生态限制与 IDE 厂商的困境

- 微软的 VS Code 平台虽然开源，但部分关键插件并未开源。第三方克隆如 Cursor 不能直接使用 Remote Explorer、C/C++ 工具链和 VS Debug 等专有组件；Python 的 Pylance 则已有 Pyright、BasedPyright 等替代方案。
- 节目讨论 Cursor 继续打包微软 C/C++ 组件和调试动态库所引发的授权争议，认为问题不只是修改许可证，而是是否获得了继续分发相关二进制文件的权利。
- 微软从开源平台、开源和闭源插件，到 AI 服务建立了完整链条，因此比单独依靠提示词和用户先发优势的产品更有护城河。节目认为 Cursor 的估值很高，但提示词容易被观察和复制，后台模型能力也会同时惠及竞争对手。
- JetBrains 的 AI 插件被批评为随 IDE 强制安装、难以彻底删除，并因删除一星评价而引发开发者不满。节目认为 JetBrains 原本擅长细致的语法分析、环境管理和开发体验，但在 AI 方向上可能正在以短击长。
- JetBrains 可以先接入成熟的开源工具，再寻找自己的定位；但它也担心依赖既有用户基础的优势被竞争者抢走，因而选择强推自研方案。

### 18:16-28:20：鸿蒙电脑与平板的边界

- 鸿蒙 PC 的早期评测让节目产生疑问：如果运行的是鸿蒙系统和平板版应用，它与“带键盘的鸿蒙平板”到底有什么本质区别。
- PC 和平板的关键差异不在屏幕和输入设备，而在应用版本和能力。Office、WPS 等软件的平板版本可以覆盖日常场景，但复杂功能仍可能只有桌面版本才支持。
- 节目推测鸿蒙电脑可能瞄准信创、政府和事业单位采购，完整覆盖服务器、PC、平板的产品线或许能带来统一采购和定制应用的机会；但政府采购通常会分包，也未必愿意把风险集中在一家厂商。
- 鸿蒙电脑最终能否成立，仍取决于专业办公软件、信息安全厂商和其他应用生态的合作。节目以 Windows 版 Surface 为对比，认为能否运行成熟的桌面软件，决定了它是不是普通笔记本的替代品。

### 28:20-40:00：中美贸易接触的性质

- 中国和美国高级别官员在瑞士接触后，市场反应较积极，但节目认为这不是正式谈判或一次性解决争端，而是双方先摸底、了解对方底牌和条件。
- 美国宣布的对英贸易成果被节目认为更接近意向和宣传，英国本来就是美国少数的货物贸易顺差对象，双方贸易规模有限，正式协议和具体细节都不充分。
- 节目把中国商务部门的表述理解为：美国新政府的单边关税措施冲击中美经贸关系，也扰乱全球贸易秩序；美方主动释放谈判信号后，中方综合全球期待、中国利益以及美国企业和消费者诉求，决定进行接触。
- 中方的接触并不意味着放弃原则。节目认为，如果美国一边谈一边继续胁迫，中方不会以牺牲国际公平正义换取协议，也不会与美国私下合作来收割其他国家。
- 节目用 1945 年重庆谈判和抗美援朝期间边打边谈作类比，认为谈判可以用于回应国际期待和摸清局势，贸易战则会是一场需要长期应对的持久战。

### 40:00-52:35：亚洲的第二套结算准备

- 节目认为，美国在关税战第一个月拿出的“美英协议”实际成果有限，而中国方面出现了金砖国家声明、中欧制裁相互取消等更多外交和经贸动向。
- 东盟加中日韩的财长和央行行长会议重新强化了清迈倡议多边化机制，并提出以人民币等可自由使用货币出资的快速融资工具。
- 清迈倡议源于亚洲金融危机后的货币互换安排，允许相关国家用本币或互换得到的货币进行结算，降低对美元的依赖。节目将人民币进入这一网络视为人民币国际化从亚洲区域开始落地的一种方式。
- 节目把这些安排理解为亚洲经济体在美元信用和美国国债偿付能力面临不确定性时准备的第二套方案：不一定立即替代美元，但可以在美元体系失灵时提供结算和融资选择。
- 节目反对“速胜论”，认为中美贸易冲突不会很快分出结果；谈判与对抗并行，才是更现实的长期状态。

### 52:35-01:09:59：印巴空战与现代作战体系

- 印控克什米尔发生恐怖袭击后，印度认定巴基斯坦应负责并展开打击，巴方否认主使并要求调查。节目依据当时公开报道和巴方信息，讨论了印度空袭、巴基斯坦反击以及双方损失的争议。
- 节目认为，这次冲突受到关注，不只是因为“击落多少架飞机”的数字，而是冷战后少见的较大规模现代战斗机空战。相比近几十年常见的单方面空袭，它展示了空军之间直接交战的复杂性。
- 现代空战通常发生在超视距距离，飞机更像导弹发射平台。预警机、地面雷达、数据链、战斗机和空空导弹需要连成一体，才能完成发现、锁定、指挥、导航和末段主动雷达制导。
- 节目推测，巴基斯坦装备的歼-10、ZDK-03 预警机和霹雳-15导弹形成了较完整的中国式作战体系；印度的雷达、防空导弹、预警机和战斗机来自不同国家，系统整合和数据链能力相对受限，只能更多依靠语音通报。
- 这一分析中的具体战果、锁定过程和装备表现仍受公开信息不完整的限制，但节目借此强调：现代战争比单件武器性能更依赖体系化协同。

### 01:09:59-01:19:28：中国军事建设的转折

- 新中国成立后军队规模一度达到数百万人，朝鲜战争期间还继续扩张；到 1950 年代和 1980 年代，国家先后通过裁军降低人员和财政负担，1980 年代至 1995 年又从约 400 万人裁减到约 250 万人。
- 1995 年提出军队建设从数量规模转向质量效能、从人力密集转向科技密集。节目认为，这一转向既受到第一次海湾战争展示出的装备和体系代差影响，也受到银河号事件、南联盟使馆被炸和南海撞机等事件的刺激。
- 银河号事件让中国认识到导航和信息能力可能受制于人，后来推动了北斗等自主系统；其他“憋屈”的国际事件则强化了必须建设自主军事能力的判断。
- 2000 年代是长期投入和研发逐渐转化为成果的阶段。歼-10、辽宁舰、歼-20 和 052D 等项目，都经历了多年研发、改进或改装，不能用短期新闻的热度衡量其形成过程。

### 01:19:28-01:23:40：军改与装备成果

- 2012 年后启动的深化国防和军事改革，将军区改为战区、集团军和部队编制重新调整，并强调合成化和实战化；2016 至 2017 年完成主要组织调整，2024 年信息支援部队成立，被节目视为这一轮大军改基本收官的标志。
- 节目把近 30 年概括为“十年卧薪尝胆、十年初见成果、十年百花齐放”：早期是在有限条件下积累，之后逐步形成国产主力装备和完整体系，近年则呈现更快的迭代节奏。
- 这次印巴冲突引发国际军迷重新评估中国出口装备和体系能力。节目认为，实战信息能补充过去只看参数、缺少战场验证的评价，但仍应避免把一次冲突简单等同于全部军事实力。
- 军事建设往往比公众能看到的事件更早开始。海湾战争和 1990 年代的多次受挫是重要刺激，但最终成果来自长期战略判断、研发投入和组织改革的共同作用。

### 01:23:40-01:30:37：新增职业与产业变化

- 人社部今年公布新增职业和工种，节目先区分两者的从属关系，并介绍《中华人民共和国职业分类大典》如何把社会中出现的职业逐步纳入国家分类体系。
- 新增项目包括跨境电商运营管理师、无人机群飞行规划员、电子电路设计师、装修管家、黄金鉴定估价师、旅拍定制师、智慧仓运维员、睡眠健康管理师、服务犬驯养师和生成式人工智能系统测试员等。
- 无人机群飞行规划员说明无人机表演和群体应用已经形成新的分工；工伤预防咨询师则反映工伤保险、事故预防和风险咨询周围正在形成更完整的服务链。
- 这些名称未必都代表成熟的大规模行业，但能够进入职业分类，通常说明已经出现一定社会需求。职业目录还会影响就业统计、职业教育、技能标准和相关证书。

### 01:30:37-01:36:25：职业教育如何跟上新岗位

- 人社部的职业分类与就业统计和职业教育直接相连，新增职业既是对产业变化的记录，也是培训机构、高校和技工院校调整方向的信号。
- 节目担心职业教育和产业变化之间存在时间差。全国技工院校拥有较大在校生规模，但数字化、无人机、电商和生成式 AI 等新岗位变化很快，现有培养体系是否足够仍需观察。
- 一些新增工种看似早已存在，例如牛肉拉面制作师；另一些则直接体现技术变迁，例如生成式人工智能动画制作员。职业被正式细分，可能意味着技能标准和行业规范正在形成。
- 通过职业分类文件观察社会，比单纯依靠身边经验更容易看到产业结构的变化。节目认为，教育、职业培训和就业部门需要更早衔接，才能把新职业真正转化为稳定的就业机会。

## 核心观点

1. 平台竞争不仅是单个产品的功能竞争，也是开源平台、专有插件、服务和生态控制权的竞争；开发工具的授权边界会直接影响竞争格局。
2. 新硬件的定位不能只看外形。鸿蒙电脑能否成立，取决于它是否拥有足以区别于平板的桌面应用、专业软件和服务生态。
3. 中美贸易战应放在全球贸易和金融秩序中观察。谈判、对抗和区域合作会长期并行，亚洲经济体建立本币结算和融资工具，是对不确定性的制度性准备。
4. 现代军事能力是体系能力。单架飞机或单枚导弹的参数不能替代预警、数据链、指挥、训练和组织协同，公开战果也需要结合不完整信息谨慎判断。
5. 军事现代化和产业升级都不是突然发生的。长期投入、组织改革、职业标准和教育培训，决定技术成果能否持续转化为真实能力与就业机会。
