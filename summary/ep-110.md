# 第110期 编程与游戏人生

- 来源：`transcript-site/episodes/ep-110.html`

- SRT 条目：376
- 阅读段落：115

## 内容摘要

本期先讨论美国参议院通过 TikTok 相关法案，以及巴以冲突引发的美国大学抗议。节目从第一、第五修正案、针对特定实体立法和国家安全例外等角度分析 TikTok 后续的法律战，也观察哥伦比亚大学等学校在学生、校方、国会和游说力量之间承受的压力。主播认为，这场学生运动短期难以产生明确成果，但可能反映美国社会权力结构和舆论控制的长期变化。

随后节目从一位云服务创业者对 Go 语言的强烈评价谈起，区分个人偏好、语言生态和可以验证的技术优势。Go 的标准库、并发能力和服务器端生态有明确强项，但把它说成现代编程语言的唯一转折点，或把其他语言的影响强行归到 Go 身上，就混淆了粉丝情绪与事实判断。

节目还分享了贵州之行：从地方饮食谈到云上贵州、数据中心、低价电力、气候、水冷和 AI 算力布局，认为基础设施长期积累后才会形成承载新应用的规模优势。最后用《魔兽世界》展开“游戏人生”主题，说明大型多人在线游戏中的公会、团队副本、分工、资源分配和冲突处理，曾经构成一种真实的线上共同生活，也给主播带来了管理经验和长期友谊。

## 时间线

### 00:00-10:18：TikTok 法案与美国的法律战

- 美国参议院通过 TikTok 相关法案，法案将 TikTok 的处置与乌克兰、以色列军事援助等事项捆绑，并把原本的宽限期限延长了六个月。
- 节目认为，法案通过本身几乎是必然的，真正复杂的是后续法律战，以及 TikTok 如果无法继续在美国运营，如何退出并保留未来机会。
- TikTok 可以从第一修正案的言论自由、第五修正案以及“针对特定实体立法”违反一般立法精神等角度提出挑战。
- 美国法律和司法实践通常为国家安全保留特殊通道，因此如果政府能够证明或让法官相信 TikTok 构成国家安全风险，法律争议仍可能对 TikTok 不利。
- 选举也会影响政客的表达：TikTok 的年轻用户和少数族裔用户较多，禁令对民主党票仓的影响，成为两党计算的一部分。

### 10:18-20:58：校园抗议、言论自由与权力压力

- 伴随加沙人道危机和社交媒体上的现场影像传播，美国大学在四月出现抗议活动，纽约大学、哥伦比亚大学等学校的学生搭帐篷、举旗并表达立场。
- 哥伦比亚大学校方报警、让警察进入校园处理学生，使原本规模有限的抗议获得更大的传播效应；一些教师则站出来保护学生，也受到相应压力。
- 学生强调自己反对的是以色列政府的具体行为，而不是针对犹太人的迫害；节目指出，美国政治讨论常试图把两者直接等同，再迫使校长在“反犹”与否之间给出二选一答案。
- 哥伦比亚大学校长同时面对国会听证会、校友捐赠、学校传统和不同政治阵营的压力，学校理事会后来又批评报警处理破坏了学校的自由传统。
- 节目把这一矛盾概括为掌权者与无权者之间的冲突，并认为当前学生缺少清晰的政治纲领和组织路线，短期很难获得实质成果。

### 20:58-25:34：从《美国反对美国》看运动的长期影响

- 节目引用《美国反对美国》中的一段观察：当资本主义国家长期发展较好时，主张改变制度的组织很难获得广泛影响；当不同社会的发展水平逐渐接近时，原先被忽略的思想可能重新出现。
- 主播据此联想到今天的美国大学运动，认为它可能很难立刻改变政策，但会让更多人开始意识到美国内部的权力和表达并不平等。
- 占领华尔街等运动曾因缺少持续的组织条件而不了了之，但失败不等于完全没有留下影响；当前抗议的后续还会与美国大选、媒体控制和 TikTok 法律战交织在一起。
- 节目将“美国人也可能感受到信息被过滤”视为一种反作用：一个长期批评他国封闭的社会，也可能在自身加强媒体控制后遭遇类似问题。

### 25:34-35:09：Go 语言的历史地位争论

- 节目讨论云服务创业者徐世伟关于 Go 的强烈评价，包括 Go 开启现代编程语言发展、带来新一轮语言繁荣，以及 Rust 受到 Go 影响等说法。
- 主播认为，评价一个人是否真正喜欢某种技术，可以看他是否尊重事实；带有个人滤镜很正常，但不能把主观体验包装成客观历史结论。
- Go 之前并不只有“过时的静态语言”。Python、PHP、Ruby 等动态语言是完整的通用语言，不应因为常被用于脚本就被一概归类为低级脚本语言。
- Go 的“活泼”和“一周学会”更多是使用者的感受；有经验的程序员学会一门语言的语法可能很快，但真正掌握语言、生态和工程实践是另一回事。

### 35:09-43:11：Go 的优势、来源与工程短板

- 现代静态语言通过类型推断、复合类型和更好的抽象能力减少了传统静态语言的繁琐，Go 并不是这些思路的唯一来源；OCaml、Haskell 和 Lisp 等语言对编程语言设计也有重要影响。
- Rust 的主要思想来源并不只是 Go，Go 官方列出的影响中也没有把 Go 作为关键来源；强行把 Rust 的流行与 Go 的影响联系起来，是对事实的过度延伸。
- Go 的客观优势包括成熟标准库、并发支持，以及在服务器端、DevOps、资源分配和节点调度中的适用性；Docker、Kubernetes 等云计算生态也帮助它获得市场位置。
- Go 的包管理曾允许直接使用 commit ID，版本比较和依赖治理不够严谨；在企业内部做开源软件治理时，这会增加维护和审计难度。
- 节目最后把“喜欢某种语法”和“语言具有客观优势”分开，认为 Go 有适合的场景，但不需要被神化成其他语言都应让位的答案。

### 43:11-50:50：贵州见闻与地方数字基础设施

- 三位主播到贵阳开会并考察数字化、数字教育和基础设施；贵州菜、长旺面、羊肉粉、花溪米粉和折耳根等地方饮食，成为这次回访贵州的生活见闻。
- 节目认为贵州许多特色饮食没有像川菜、湘菜那样传播到全国，反而说明不同地区的地方经验和消费场景仍然值得亲自探索。
- 贵州过去十多年较集中地发展数字基础设施，苹果在中国的 iCloud 服务由“云上贵州”提供，就是较有代表性的合作项目。
- 这个项目需要处理数据在中国境内存储、与美国同步程序更新、容量、速度、可靠性、安全性以及中美用户跨境使用等问题，节目认为整体运行得较成功。
- 主播还设想把贵州的气候、生态、数字基础设施与数字素养教育和研学活动结合起来，形成上海与贵州之间更长期的合作。

### 50:50-01:00:19：数据中心、冷却与 AI 算力

- 贵州的数据中心从早期机房逐渐扩展到互联网机房、数据存储和 AI 算力等综合型基础设施，长期建设积累了设计、供电、冷却、网络链路和多线备份等能力。
- 既有供应商和工程团队已经为移动、苹果、华为等企业建设过机房，新项目可以复用这些经验，从而形成地方的规模化优势。
- 腾讯在山体隧道中建设大型节点，华为则利用湖水冷却机房，再把升温后的水用于园区供暖，形成较直观的水冷和热能循环。
- 贵州电力成本较低、气候凉爽，也有水冷条件和相关政策，能够降低算力中心的运营成本；以茅台作为算力采购奖励的趣闻，则体现了地方政策的本土化表达。
- 节目认为，AI 算力中心的价值不只在于把设备放在那里，更在于未来可以把算力出售或用于开发教育、大数据和其他应用。

### 01:00:19-01:02:31：东数西算与数字研学

- 大模型训练等任务对实时性要求不高，数据和计算可以在不同地点完成，再同步结果，因此算力的地域布局会从愿景逐渐变成现实需求。
- 阿里、腾讯、网易等企业也在贵州建设数据中心，说明这里可能形成面向算力和数据服务的产业聚集。
- 贵州的气候、生态、村超等文旅资源，为数字素养教育、科技研学和上海与贵州之间的交流提供了结合点。
- 节目计划在暑期尝试相关活动，但强调要先形成具体成果，再向听众分享。

### 01:02:31-01:12:40：从《魔兽争霸》到大型多人在线游戏

- 《魔兽世界》建立在《魔兽争霸》的世界观上，后者本质上是多人即时战略游戏；玩家使用地图编辑器制作的 RPG 地图，则催生了 Dota 等独立玩法。
- Dota、英雄联盟和王者荣耀存在共同的 Warcraft III 生态渊源，但王者荣耀是面向手机时代重新优化的竞技游戏，并不是《魔兽世界》的直接延续。
- MMORPG 与单机或少数人联机游戏不同，它需要一个有足够真人玩家的持续世界；玩家既可以组队对抗环境，也可以参与玩家之间的阵营和团队对抗。
- 《魔兽世界》早期的普通任务可以单人完成，地下城通常需要五人组队，而高等级副本曾经要求四十人协作；大型团队由坦克、治疗和输出等角色组成。
- 仇恨机制、限时狂暴、小怪处理、站位和节奏控制，使团队副本不能依靠临时拼凑，而需要固定成员长期训练和“开荒”。

### 01:12:40-01:23:57：公会管理、团队协作与自建系统

- 四十人副本需要清晰的指挥、分工和节奏，输出过高会导致仇恨超过坦克，治疗过度也可能吸引敌人攻击；任何环节失控都可能造成团灭。
- 一个能够持续攻坚的公会通常需要五十到一百名活跃成员，安排固定时间训练、积累装备并挑战新的副本；强大公会还会争夺新 Boss 的全球首杀。
- 主播回忆每周三次、每次至少四小时的公会活动，并把会长和核心成员的目标协调、分工、资源分配、团队建设和冲突处理，与经营小公司相比较。
- 为了管理公会，主播自己搭建论坛和 DKP 系统，用屠龙点数记录成员活动并分配装备，还学习 Lua 编写游戏插件和数据展示工具。
- 在没有成熟语音和社交平台的年代，技术能力直接成为维持线上组织的基础设施；公会也因此连接了原本不会认识的朋友。

### 01:23:57-01:31:38：公会作为一种“第二人生”

- 《魔兽世界》的吸引力不只是获得装备，而是与一群人共同完成现实生活中不可能完成的史诗级挑战；装备的主要作用，是让玩家继续体验更高难度的内容。
- 公会成员可能从线上活动发展到线下聚会，长期共同游戏也会形成跨城市、跨年龄的友谊和家庭之间的传承。
- 这种大型多人在线游戏更像一套共同生活方式，而不是打开即玩、结束即走的轻量娱乐；公会规模、规则和活动安排使它具有小型组织的结构。
- 这种体验的代价也很高。成员毕业、工作、迁居或承担家庭责任后，通常无法继续保持原来的参与度，只能 AFK，公会管理权也会逐渐交给别人。
- 现在的手游更常见的是即时匹配、单排或短时游玩，社交关系更多转移到游戏外，因此很难复现早期 MMORPG 那种沉重而持续的共同生活。

### 01:31:38-01:35:56：家长、游戏与专注克制

- 节目借一次登山纪录片活动中的讨论指出，游戏里的任务和难题也可能是孩子愿意主动攀登的“山峰”，不能把所有游戏都简单视为负面事物。
- 对家长而言，完全禁止游戏并不现实；更重要的是教孩子专注和克制，让学习时专注学习，游戏时专注游戏，并有规律地安排时间。
- 电子游戏会提供其他媒介难以提供的世界体验，也长期推动人机交互和对人的运营方式；它可以成为机会和工具，但前提是人能够驾驭它，而不是被它支配。
- 游戏是否有价值，不只取决于游戏本身，也取决于玩家是否能从中获得体验、协作和能力，并控制沉迷风险。

## 核心观点

1. TikTok 法案、校园抗议和平台言论控制都不是单一法律条文可以解释的现象，理解它们需要同时观察法律、选举、学校治理、资本和权力关系。
2. 评价编程语言必须区分主观喜好、历史影响、生态优势和工程短板；尊重事实比把自己喜欢的语言包装成唯一正确答案更重要。
3. AI 算力的竞争不仅是芯片数量，还取决于电力、气候、冷却、网络、供应商和长期运维等基础设施能否形成规模化能力。
4. 大型多人在线游戏把娱乐转化为持续的组织协作，公会管理中的分工、激励、资源分配和冲突处理，确实可能成为现实管理经验的一部分。
5. 游戏无法被社会长期排除，教育重点应从简单禁止转向帮助人建立专注、克制和主动使用工具的能力。
