# 第181期 可控核聚变还有多远

- 来源：`transcript-site/episodes/ep-181.html`
- 时长：01:45:02
- SRT 条目：2131
- 阅读段落：156

## 内容摘要

本期先从日本旅行和以太坊开发者大会的见闻谈起，讨论中国开发者如何向海外介绍本国开源生态，以及中国开源叙事中的“自主可控”“竞争引领”和“普惠全球”三种定位。随后点评 DeepSeek R1 论文通过同行评审、GPT-5 Codex、华为算力路线图，以及 Oracle 裁剪 MySQL 团队后 PostgreSQL 和 MariaDB 的生态机会。

节目接着分析中美围绕 TikTok 的谈判，认为美国区运营权、全球业务和数据代码的分割是三个不同层次的问题，不能把美国媒体报道的“框架协议”直接当成最终结果。之后讨论罗永浩与西贝的预制菜争议，从现行定义、中央厨房、食品安全、口味价格和消费者知情权等方面说明餐饮工业化是一个需要权衡的过程。

最后回到九三阅兵后的国际格局和中国的国际责任。节目认为，一个国家要向世界提供公共产品，既需要足够的实力，也需要让国内发展与全球愿景相容，并在国际社会形成认同者和有效秩序；中国正在通过开源、AI、基础设施和多边倡议探索这种角色。节目以全球发展、安全、文明、治理四项倡议和多极化讨论收束，并把 2025 年视为中国从战略防御转向战略对抗的重要转折点。

## 时间线

### 00:00-15:36：日本以太坊大会与中国开源的三种定位

- 主播分享在日本参加以太坊开发者大会的见闻，把会务中极其认真、细致却效果有限的状态称为“日式精致草台”：设备、PPT 和演讲流程被反复确认，但分论坛实际到场人数很少。
- 维塔利克参加了介绍中国开发者和开源年度报告的演讲，之后的闭门交流却变成各位开发者向这位核心人物集中汇报协议、架构、项目和论文需求。节目借此指出，强调去中心化的技术社区仍然会在现实中围绕关键人物寻求决策。
- 节目认为，中国开源对外介绍可以概括为三种角色：以开源实现自主可控的防御性定位、先跟随再超越并争取引领的竞争性定位，以及把开源作为普惠全球愿景的公共产品定位。
- 主播认为第三种定位在国内仍是少数，但中国开发者应该更多出海交流，让海外开发者了解中国的开源项目、社区和思考。

### 15:36-24:12：DeepSeek、GPT-5 Codex 与华为算力路线

- DeepSeek R1 的论文完成预印本同行评审并登上 Nature，节目认为这使此前关于训练路线、合成数据和较低成本的讨论再次受到关注。
- 节目观察到，大模型竞争呈现轮流领先的节奏：DeepSeek 在年初受到关注，随后 Claude 相关产品和 OpenAI 先后发力，新的模型通常只能保持几个月的明显优势。
- GPT-5 Codex 被介绍为面向编码 Agent 优化的模型。节目认为它和其他 coding 工具相比更谨慎，不会一味迎合用户或擅自扩大任务范围，但会对需求提出自己的判断并说明完成方式。
- 关于 DeepSeek 近期缺少大版本更新，主播猜测算力不足可能促使其为国内可控算力建设兼容的底层技术栈，而不必把一切解释为行政强制。
- 节目转述华为的路线：单芯片性能未必达到 NVIDIA 同级产品，就通过加速器堆叠、共享内存和通信优化，把多个芯片组合成更大的算力节点；具体能否按路线实现仍需观察。

### 24:12-34:02：MySQL、PostgreSQL 与 AI 数据基础设施

- 节目讨论 Oracle 据称裁剪数十名 MySQL 核心开发人员的消息，回顾 MySQL 从互联网服务器数据库王者到市场份额下降、创新节奏变慢的过程。
- MySQL 被 Oracle 收购后，外部社区主要能提交 Bug 和 issue，却难以直接贡献并合并代码；MariaDB 作为分叉项目则持续获得开发者关注，PostgreSQL 也因社区活跃和新功能支持而更受欢迎。
- 对遗留系统而言，MariaDB 可能更容易直接替换 MySQL；对需要向量存储、图数据等新能力的新系统，节目认为 PostgreSQL 的架构和扩展生态更有吸引力。
- 节目把 AI Agent 的基础拆成模型、指令与提示词，以及知识库和信息系统。知识材料规范化、向量化和检索的需求，可能进一步提升 PostgreSQL 等开放型数据库的价值。

### 34:02-51:24：TikTok 谈判、美国区运营与全球业务边界

- 节目认为，中美谈判结束后双方公开表述差异很大：美方和美国媒体倾向于描述已经达成框架协议，甚至传出美国企业持有 TikTok Global 大部分股份的方案；中方表述则强调中国法律、知识产权和算法出口管制，以及企业平等谈判和公平营商环境。
- 主播提醒，谈判中的美国区运营权不等于全球 TikTok 业务的所有权。美国可以要求一个独立的美国服，但这不应自动变成接管世界服；字节跳动若要保留全球业务，必须把这两者区分开。
- 节目转述当时的“云上德州”模式：Oracle 等公司在德州建设数据中心，承载美国用户数据和相关代码，TikTok 在新加坡的团队远程维护。全球其他地区的数据是否完全分开，节目承认尚无公开信息确认。
- 主播判断，字节跳动可以考虑把美国区运营交给美国公司，但不应把欧洲、东南亚等其他地区的全球业务一并出售；美国用户数据落地美国也已经是重要的合规安排。
- 节目把特朗普再次延长相关禁令执行期限、以及随后推出高额 H-1B 签证费用的动作，解读为美国暂时没有拿出足够明确的谈判成果；这些判断仍取决于后续正式协议。

### 51:24-59:07：罗永浩、西贝与预制菜争议的起点

- 节目认为，罗永浩和西贝两方都不讨喜：罗永浩擅长制造争议，西贝则存在菜品品质下降、性价比不足和回应方式失当等问题；这场争论更像是“低情商老板”遇到“高段位找茬王”。
- 主播区分“东西不好吃”的消费者评价与“几乎都是预制菜”的事实指控：前者是个人体验，后者需要符合预制菜定义和足够证据，否则可能影响商誉并引发民事责任问题。
- 节目认为，西贝采用中央厨房并不当然等于现行规定中的预制菜。围绕预制菜的准确分类，应该先区分事实判断、法律或行业定义，以及消费者对价格和透明度的期待。
- 主播担心，舆论争议虽然可能推动科普，但这次也制造了“预制菜天然便宜”等不准确的认知，因此需要把餐饮行业的工业化过程讲清楚。

### 59:07-01:08:41：预制菜定义与餐饮需求的权衡

- 节目转述 2024 年相关管理办法对预制菜的界定：它应当是经过加热或熟制后才能食用的菜肴，净菜、方便食品以及中央厨房配送时已经可以食用的菜品不一定属于这一分类。
- 节目认为，餐饮消费至少包含食品安全、卫生、口味、营养、方便和价格几个维度，其中食品安全与卫生是底线，口味、营养、便利和价格则可以根据不同定位相互折中。
- 预制菜和中央厨房等工业化方式可能更容易保证卫生与便利，但不同食材的保存、加工和口味损耗不同，不能简单归结为绝对好或绝对坏。
- 城市餐饮要服务大量人口，就难以完全依靠现场手工制作。节目用未来食品的想象说明，餐饮工业化可能让普通人以较低成本获得稳定、方便且足够好的食物，但未必能同时满足所有维度的最高标准。

### 01:08:41-01:16:26：价格、知情权与餐饮工业化

- 节目认为，预制菜不天然意味着低价或低端。商家仍然要在口味、营养、便利和价格之间找到让消费者觉得物有所值、同时能够覆盖成本的平衡点。
- 主播不同意把“知情权”直接理解为消费者天然有权知道一份菜的全部生产过程，认为公民对公共部门的监督权与消费者对私营商家的信息要求不是同一概念；是否要求商家标注预制菜，应当通过具体法规讨论。
- 如果要求逐项标注原料来源、加工步骤和中央厨房环节，单个菜品可能涉及多种原料和多道工序，标识的范围、必要性和可操作性都很复杂。
- 节目认为，监管部门需要同时考虑标识的可行性、消费者真正需要的信息和餐饮行业的发展，过度严格或含义不清的标准都可能带来新的问题。

### 01:16:26-01:22:51：餐饮服务的现场价值与争议收束

- 节目用烤鸭现场切片、甜品现场制作和日本厨师发办等例子说明，餐饮消费不只有食物本身，还包括现场表演、透明感、仪式感和由此产生的心理价值。
- 这些额外服务最终会反映在价格、商誉和口碑中；消费者可以为此付费，也可以认为不划算而选择其他商家，市场会通过选择和竞争调整定位。
- 主播认为，餐饮工业化是很难回避的长期过程，商家需要科普自己的生产方式、把产品和价格定位讲清楚，消费者也需要理解不同餐饮模式之间的取舍。
- 节目推测，西贝准备上市和罗永浩提出推动预制菜透明化立法，可能共同影响了事件走向；但如何制定既透明、必要又不阻碍行业发展的规则，仍是监管难题。

### 01:22:51-01:31:30：中国应如何承担国际责任

- 节目把中国对外发展的角色分为防范被“卡脖子”、追求技术领先和向世界贡献公共产品三种取向，认为最值得追求的是第三种，而不是只把开源当作竞争工具。
- 开源社区存在“礼物文化”：贡献越有价值，贡献者在社区中的地位越高。节目据此提出，国家也可以通过提供 AI、通信、基础设施、开源项目和治理经验等公共产品，获得更自然的国际认同。
- 主播认为，大国责任需要三个前提：足够强的综合实力、国内发展与全球愿景之间的相容性，以及在国际社会形成支持者并把理念落实为有效秩序。
- 节目回顾巴黎和会和威尔逊和平倡议，认为理想主义若没有实力、国内发展基础和国际执行机制支撑，就很难转化为持续的国际方案。
- 节目比较美国曾经通过互联网、全球化和金融体系提供公共产品的路径，认为中国可能更倾向于从制造业、基础设施和普惠发展出发构建自己的国际角色。

### 01:31:30-01:40:20：四项全球倡议与多极化世界

- 节目把人类命运共同体进一步拆解为四项全球倡议：全球发展倡议强调发展优先、以人民为中心、普惠包容和人与自然和谐共生；全球安全倡议强调不可分割的共同安全。
- 全球文明倡议强调尊重文化多样性、求同存异，不以意识形态统一为合作前提；全球治理倡议则强调以联合国为核心、以多边机制替代单边行动。
- 关于未来国际格局，节目讨论“两超多强”与“多极化”的区别，认为中美相互制约、其他强国拥有议价能力时，没有任何一个国家能够单独决定全部规则，这本身也可以是多极化的一种形态。
- 主播认为，世界局势动荡、俄乌战争、中东冲突、关税战和历史翻案等因素，使中国即使尚未完全准备好，也必须开始更主动地提供公共产品和国际方案。

### 01:40:20-01:45:02：开源数字公共品与战略转折

- 节目补充杭州开源大会的见闻：活动设置了围绕开源支持 ESG 和数字公共品的联合国相关论坛，也邀请了国际开源基金会和开发者参与交流，并举办 Rust 社区十周年活动。
- 主播认为，中国在数字化、IT 和 AI 领域越来越有信心，正在邀请海外开发者和国际组织来中国讨论开源、可持续发展与数字公共品；相关国际框架仍有不少内容停留在概念层面，因此中国项目可能有参与和补充的空间。
- 节目判断，当一个人、公司或国家拥有足够实力后，就会承担更多展示实力和使用实力的责任。中国提供公共产品既是能力变化的结果，也是在国际环境压力下逐渐形成的主动选择。
- 节目最后把九三阅兵视为一个重要转折点，转述“中美竞争从战略防御转向战略对抗”的判断，并认为过去几年的遭遇和思考促使中国开始更明确地展示自身力量与国际责任。

## 核心观点

1. 去中心化的技术和社区仍然需要面对现实中的关键人物、组织和治理结构；理念与实际运作之间的张力值得持续观察。
2. AI 和数据库的竞争不只取决于单次模型性能，也取决于算力基础设施、底层技术栈、社区贡献和知识系统等长期条件。
3. TikTok 等跨国业务谈判必须区分美国区运营、用户数据、核心代码和全球业务，不能把一方希望达成的方案当成已经完成的交易。
4. 预制菜争议的核心不是“工业化一定好或坏”，而是如何在食品安全、口味、营养、便利、价格、服务体验和可执行监管之间做出平衡。
5. 大国国际责任需要实力、国内发展和国际认同共同支撑；提供开源、基础设施、AI 和治理方案，可能比单纯宣称领导地位更能形成长期影响。
