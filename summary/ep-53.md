# 第 53 期 又到每年两会时

- 来源：`transcript-site/episodes/ep-53.html`
- 时长：01:27:37
- SRT 条目：887
- 阅读段落：128

## 内容摘要

节目开头继续讨论 ChatGPT。主播认为，低价 API 可能通过吸引大量早期应用接入来积累数据、建立先发壁垒，因此国内限制访问既涉及产业保护，也涉及数字隐私和国家安全。对于国内出现的“ChatGPT 大跃进”，节目一方面警惕借热点骗资源、骗投资和包装旧产品，另一方面认为在公共资源投入可控的前提下，适度的市场试错可以用一定代价换取技术认知和发展时间。

随后节目围绕《数字中国建设整体布局规划》讨论“数字基础设施”究竟是什么。主播认为，基础设施不只是操作系统、芯片、代码托管平台或看得见的软件，更重要的是建设、维护、参与开源社区、制定数据标准和持续创新的能力。节目以同城结算系统为例，说明统一牵头、数据交换标准和长期工程实践，才能把分散的应用真正连接起来。

节目的后半段进入两会提案讨论，涉及减少教师被要求点赞转发、延长春节假期、网络暴力立法、直播治理、在线服务适老化，以及代表委员应更多提交专业提案等内容。主播区分了短期处理紧迫问题与长期建设数字世界法律体系的路径，也认为网络治理不能只依赖模糊的“口袋”罪名。

最后，几位主播提出各自的“代表提案”：建立提案有效性、可执行度、办结率和专业相关度指标，把开源贡献纳入教育评价，建立更清晰的游戏分级制度并限制抽卡类游戏。节目整体认为，两会热点不应只作为笑话消费，也可以借此观察公共治理、数字化建设和社会结构变化中的真实问题。

## 时间线

### 00:00-10:06：ChatGPT API、数据壁垒与数字隐私

- ChatGPT 推出低价且能力较强的 API 后，国内相关访问似乎很快受到限制。节目认为，这并不是普通网络服务的进出口问题，而可能影响未来大量应用的基础能力。
- 低价 API 被概括为“技术倾销”：先让大量早期应用接入，再通过应用使用产生的数据持续改进模型。后来者即使只晚几个月，也会少积累相应的数据，进而扩大先发壁垒。
- 限制 API 访问被节目解释为两条理由：为国内产业争取发展窗口，以及避免在风险尚未厘清时，让外部模型大规模采集本地用户的“数字人生”。用户画像、兴趣和行为数据的长期汇总，可能具有类似敏感生物信息的价值。
- 全球化合作并不是无条件的。政治矛盾加剧时，贸易和技术保护都会重新出现，因此国家和企业既要利用全球协作，也要保留在关键服务中自给自足的能力。
- 节目估计国内形成相近能力的时间窗口约为一到两年，并强调这只是对当时局势的判断，不代表对技术进展的确定预测。

### 10:06-15:31：ChatGPT 大跃进与技术泡沫

- 节目讨论“中国的 ChatGPT 大跃进”，认为热潮中可能同时存在骗取公共资源、吸引投资、给旧产品贴新概念以及小型创业公司借机融资等动机。
- 这种现象并非 AI 独有，大数据、区块链和元宇宙等技术热潮中也出现过类似炒作。投资人和项目方会用名校背景、团队履历和宏大叙事包装实际能力。
- 一位主播认为应谨慎控制国家资金和公共资源；另一位则认为，在技术方向尚未被充分验证时，大量市场参与者试错有其必要性，即使大多数项目失败，只要少数项目真正有效，也可能推动整体认知前进。
- 学术界和产业界都可以讨论 ChatGPT，但最终价值要看能否落地。节目把这种热潮理解为用一定代价换取时间、人才积累和对新技术的社会理解，而不是把每个项目都当成成功案例。

### 15:31-25:50：数字中国与基础设施的不同含义

- 《数字中国建设整体布局规划》覆盖范围很大，节目没有试图逐条解释，而是集中讨论数字基础设施的内涵，以及数字化应用已经普及后仍存在的数据孤岛、系统设计不佳和老年人使用困难等问题。
- 主播提醒，反卡脖子的能力建设与数字中国的创新建设是两条相关但不同的路线。前者要求在关键服务中随时具备替代能力，后者则要探索下一代技术和经济模式。
- 代码托管平台的价值不只是存放代码，更在于活跃的开源开发者和社区。国内如果只是重复建设多个平台，既不能自动吸引开发者，也可能分散本来就有限的力量。
- 数字中国可以像发展新能源车一样，借助产业链和政策支持提前投入下一代形态；但复制现有平台只能形成备份，真正有价值的是新能力、新社区和新的应用模式。
- 芯片领域也可以同时推进基础自给和技术创新：一般性需求先确保不被切断，高端和下一代体系则需要持续探索，不应把两种目标混成一个项目。

### 25:51-40:28：从“建平台”转向建设能力和数据标准

- 节目把数字基础设施的核心概括为建设能力：即使未来无法继续使用某个开源项目，也要能读懂已有代码、修改代码、长期维护并发展自己的项目。
- 参与成熟开源社区并不容易，很多项目的核心团队已经稳定；更现实的做法是尽早发现仍处于萌芽期的项目，通过持续贡献建立影响力，并在必要时具备独立延续项目的能力。
- 鸿蒙等具有产业链牵引力的项目，可以把操作系统、手机、大屏、汽车和物联网连接起来，同时带动代码托管、开源管理、社区运营和贡献者培养。节目认为，当前这类组织和规划仍不够清晰。
- 数据基础设施还包括网络、算力、数据和标准。数字化能力需要向更多地区和教育场景下沉，不能只让大城市和少数专业人员享受数字服务。
- 数据标准比单个应用更基础。底层机房、服务器和网络的通用标准已经相对稳定，下一阶段更关键的是应用之间如何互联互通，以及不同系统如何使用一致的数据定义。

### 40:28-50:34：同城结算系统与应用驱动的标准

- 节目以人民银行牵头建设的同城结算系统为例，回顾银行跨行结算从隔日到账逐步变成实时交易的过程。这个项目持续了近十年，也在过程中补齐了网络、硬件、专线、协议和数据交换标准。
- 人民银行的统一牵头解决了不同银行之间的组织问题，税务部门的加入则提供了从纳税场景切入的实际应用。企业可以在任意银行开户，再由结算中心完成跨行和入库流程。
- 金融系统必须考虑异常指令、超时和回退，每个正向操作都要有对应的逆向操作。节目以此说明，数字基础设施不是口号，而是由大量长期、细致的工程问题组成。
- 对数字中国而言，民生服务相关的数据在政府部门和商业机构之间互联互通，可能是更具里程碑意义的方向。前提是建立能被各方使用和信任的数据标准。
- 开源数据分析也可以寻找处于早期阶段的潜在项目，观察其活跃度、健康度和发展趋势；真正有效的标准应在具体应用中形成，而不是只停留在一份没人使用的标准文件里。

### 50:34-60:15：两会提案、网络暴力与数字世界治理

- 两会前后的提案讨论从减少教师参与网络点赞转发开始。节目认为，平台指标本身确实可能影响流量，但不应通过行政命令和工作考核强迫教师充当网络流量工人。
- 延长春节假期被认为既符合生活需求，也可能带动旅游、电影和消费。主播建议把法定假期延长到五天，再与周末和年假衔接成更完整的休息时间。
- 网络暴力立法被认为具有较强的现实必要性：问题已经严重，且现行法律在平台责任、参与者责任和造成严重后果的行为边界上存在不足。网络直播的内容、支付和利益分配问题，也需要同步治理。
- 节目讨论了建立“数字世界法律体系”的设想，但认为短期内更现实的方式是修改现有民法和刑法，并由行业规则处理部分直播和平台问题。
- 长期而言，法律需要定义网络身份、网络权利和网络责任，形成彼此衔接的“立法网络”，而不是每出现一个热点就孤立地增加一条规定。

### 60:15-70:01：网络处罚、适老化与专业提案

- 网络治理还需要明确不同处罚的层级：哪些行为由平台封禁处理，哪些行为需要行政处罚，哪些行为达到刑事责任。节目反对在没有清晰法律依据时随意进行全网封禁。
- 关于寻衅滋事罪，节目一方面承认“口袋”罪名在治理紧迫问题时可能被使用，另一方面认为不能让网络诽谤、网络暴力等新问题长期装在一个边界模糊的口袋里，应逐步建立专门、明确的法律规定。
- 在线服务适老化被视为数字中国建设无法回头后的必要工作。长期保留完全非数字化的平行方案并不现实，应用服务商应主动改善老人使用手机和在线服务时遇到的障碍。
- 齐向东关于代表委员应聚焦专业领域、提交更专业提案的建议，引发了关于为什么很多人不愿谈自己行业问题的讨论。主播认为，提案质量和专业相关度确实值得改善。
- 节目强调，数字化不能只追求平台数量和建设项目，还要把使用者权益、责任边界和实际治理效果纳入设计。

### 70:01-80:26：短视频、网络法律与“数字两会”

- 对“限制年轻人看短视频、增加全民阅读量”的提案，节目认为短视频、游戏和社交平台已经是年轻人的语言和生活方式。想推广阅读，应学会用年轻人熟悉的内容形式，而不是简单禁止。
- 节目再次讨论寻衅滋事罪的争议，认为网络意见、网络暴力、造谣和现实伤害之间的责任边界很难划分，但民众对相关后果的关注会迫使治理继续推进。
- 主播提出用一套指标观察两会提案，包括有效性、可执行度、办结率和专业相关度。指标不能代替判断，但可以帮助公众了解提案是否真正产生了结果。
- 如果能把提案数量、质量、执行情况和代表的专业背景做成数据看板，就可以形成所谓“数字两会”，也能让代表委员面对更清晰的公共评价。
- 教育领域可以把教师和学生参与开源社区的贡献纳入评价，增加传统考试和论文之外的能力证明；但也有人担心这会变成新的考核项目，扩大而不是减少“内卷”。

### 80:26-01:27:37：开源人才与游戏分级提案

- 开源贡献如果被纳入学校、学院或人才引进评价，需要先有可靠的指标和评价方法。节目认为，真正想推动的不只是开源本身，而是借此提升全民数字能力。
- 主播建议把开源贡献与上海等地的人才政策联系起来，通过实际贡献度识别和吸引开源人才；这也意味着开源参与者需要用真实影响力参与竞争。
- 节目提出建立有中国特色的游戏分级标准，以更清楚地区分未成年人保护、暴力和不适宜内容等问题，减少社会对游戏的笼统误解。
- 对手机游戏和抽卡、抽蛋类商业模式，主播希望从版号和平台等方面加强限制，同时支持更扎实的独立游戏和单机游戏，让行业依靠真正优秀的作品提升价值和素养。
- 游戏分级的难点在于目标容易达成共识，具体标准却牵涉很多利益和争论。节目认为可以先围绕最紧迫的未成年人保护问题建立规则，再在实践中逐步调整，而不应因为害怕争议就永远不做。

## 核心观点

1. 关键数字服务的竞争不只是模型能力竞争，也是数据积累、用户规模、工程经验和长期迭代能力的竞争。
2. 数字基础设施不应等同于看得见的平台和设备。真正重要的是建设、维护、参与社区、制定标准以及在断链时继续工作的能力。
3. 大型数字工程需要统一牵头、明确标准和持续验证。应用互联互通的核心，往往是数据定义、异常处理和责任边界，而不是单纯增加平台数量。
4. 网络治理既要处理眼前的网络暴力、直播和平台滥用，也要逐步建立适用于数字世界的权利、责任和处罚体系。
5. 两会提案和教育评价都需要从数量、口号和短期热度转向实际效果、可执行性、专业能力与长期贡献。
