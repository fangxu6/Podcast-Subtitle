# 第133期 数学有多重要

## 内容摘要

本期先补充讨论 IGN 针对《黑神话：悟空》年度游戏预投票争议发布的解释。节目认为，媒体把投票包装成试验性功能并不能消除玩家对数据和评奖标准的疑问；随着 Steam 评分、玩家社区、直播和攻略视频的影响力上升，传统游戏媒体的购买决策价值正在下降。

随后围绕 Winamp 发布 Windows 版源码，以及 WordPress 与 WP Engine 的商业冲突，讨论“源码公开”和严格意义上的开源有什么区别。节目认为，许可证没有要求时，用户并没有必须回馈社区的义务；商业竞争可以通过产品、法律或商标解决，但不应轻易被包装成道德审判，否则会损害社区对项目的信任。

节目中段介绍国庆档电影，重点评价电影版《只此青绿》如何用舞蹈、色彩、音乐和电影手法表现《千里江山图》及其背后的文化传承，也谈到《变形金刚》的 G1 造型。之后从以色列、伊朗及周边局势谈到美国大选、叙利亚和俄罗斯，内容主要是主播对地区升级逻辑和风险的分析。

最后回到数学教育。节目反对把信息技术差距简单归因于数学基础不足，但也不因此否定数学的重要性：计算机和人工智能需要按任务学习微积分、线性代数、统计概率等工具，同时数学还训练抽象、逻辑和形式化思维。更有效的学习方式，是先建立知识结构，在真正遇到问题时按需补齐所需工具。

## 时间线

### 00:00-08:27：IGN 投票争议与游戏媒体的变化

- IGN 在此前的年度游戏预投票争议后发布长文解释，称“Face Off”是开发团队新做的试验功能，编辑只是把话题放入系统，并否认人为影响投票数据。
- 节目认为，投票量在特定时间突然增长、部分对局结果异常等现象确实引发疑问，但“数据被修改”是主播根据截图、玩家抓取和整体胜负情况作出的推断，不是节目之外已经核实的事实。
- 另一家媒体公布年度游戏候选名单后，《黑神话：悟空》只进入视觉效果等单项提名。节目观察到，玩家更在意自己实际玩到的体验，开发者更在意销量和口碑，奖项本身的影响力正在减弱。
- Steam 评分、玩家社区、直播、攻略视频和内容创作者，正在替代传统媒体承担更多的购买参考和游戏体验传播功能。

### 08:27-15:53：Winamp 源码与“严格意义上的开源”

- Winamp 是 1990 年代流行的 MP3 播放器，除了播放和管理音乐，支持高度定制的皮肤也是它的重要记忆点。如今官方公开了 Windows 版本的完整源码，满足了一部分用户的怀旧期待。
- 随源码发布的许可证允许阅读、使用和修改，却限制修改后的代码分发和分叉；修改者要么自己使用，要么提交回官方，并把相关权利转让给官方。
- 节目区分“公开源代码”和严格意义上的“开源”：后者通常要遵循 OSI 批准的许可证及开源定义，不能只因为代码可见就使用同一个名称。
- 主播认为，Winamp 已经不是值得继续发展的主流技术，公开源码更像是让少数老用户自行修补的“临终关怀式开源”。这种做法本身没有问题，但不必把它包装成开放社区项目，也不必因为许可证不合预期就嘲讽怀旧用户。

### 15:53-25:34：WordPress、WP Engine 与开源社区信任

- WordPress 曾长期作为个人博客和小型网站的主流 CMS，围绕开源软件还形成了 WordPress.com、主题、插件和各种托管服务的商业模式。
- WordPress 背后的商业组织与竞争对手 WP Engine 都基于 WordPress 提供托管服务。节目讨论了 WordPress 创始人指责对方“只用不贡献”，以及限制 WP Engine 用户访问 WordPress.org 的做法。
- 节目认为，如果许可证没有明确要求，用户可以自行修改和使用软件，并没有必须向上游贡献的道德义务；“upstream first”更像社区惯例，而不是普遍适用的强制规则。
- 直接竞争时挥舞道德大棒，会让商业诉求看起来像社区正义。商标和法律手段虽然可以使用，但滥用项目基础设施或临时修改规则，可能使整个 WordPress 社区显得不可靠，并推动用户转向更开放的方案。

### 25:34-34:31：国庆档与电影版《只此青绿》

- 节目先提到《749局》等国庆档影片的口碑争议，认为一些创作者在作品表现不佳时责怪观众或攻击同行，是把商业和创作问题转化成道德指责的风潮。
- 主播观看了电影版《只此青绿》。这部作品由此前的舞剧发展而来，宣发很少、排片也不高，但电影中的音乐、色调、场景、服装、妆容和舞蹈共同形成了强烈的审美体验。
- “青绿”段落通过舞者的服装、动作、光影和音乐表现中国古典山水的色彩；雨中和水面上的独舞则把舞者的力量、身体线条与水的视觉效果结合起来。
- 节目认为，东方演艺集团的创作团队把中国武术和现代舞结合得很有辨识度，电影手法也让原本难以稳定呈现的舞台效果被完整记录下来。

### 34:31-45:45：《千里江山图》、文化传承与 G1 变形金刚

- 《只此青绿》的核心并不只是舞蹈，而是王希孟的《千里江山图》：一幅以矿物颜料设色、绘在绢上的长卷山水画。节目介绍了它的尺寸、青绿设色和细密的山水人物细节。
- 王希孟在 18 岁左右完成这幅传世作品，之后几乎没有留下更多人生记录。电影没有把他拍成完整的宫廷传记，而是用相对抽象的方式表现画作诞生所需要的绢、笔、颜料、收藏、修复和展陈等劳动与传承。
- 作品的重点是艺术如何经过许多人的劳动和一代代保护延续到今天，而不是传统电影式的完整情节。接受这种表达方式，就能把它当成一部以视觉和听觉为主的高级体验。
- 节目也谈到舞台版与电影版的差异，以及《变形金刚》中更符合童年记忆的 G1 造型，认为《只此青绿》和面向老粉丝的 G1 作品都是相对稳妥的选择。

### 45:45-56:45：以色列、伊朗与地区升级逻辑

- 节目把当时的中东局势放在美国大选前一个月的时间点上分析，认为以色列连续打击周边敌对势力领导人，并从空袭转向地面行动，可能是在推动局势升级。
- 主播的判断是，以色列希望把伊朗直接拉入冲突，从而增加美国介入的压力；如果冲突扩大并形成既成事实，领土控制和定居也可能进一步固化。
- 节目解释“抵抗之弧”涉及黎巴嫩真主党、哈马斯、叙利亚、伊拉克部分武装和也门胡塞武装等力量，但这些组织并不是简单同质的宗教共同体，更多是因为反对美国和以色列、以及接受伊朗支持而形成合作。
- 伊朗面临两难：直接反击可能陷入更大规模战争，不反击又可能损失对周边力量的影响力。节目将其组织分裂和内部协调能力视为局势中的关键变量。

### 56:45-01:03:05：伊朗内部、叙利亚与美国大选风险

- 节目认为伊朗内部存在民间、总统系统、最高领袖和革命卫队之间的复杂分歧，伊朗此前对以色列的弹道导弹报复也被描述为主要由最高领袖和革命卫队系统推动，总统后来才获知行动。
- 以色列若继续升级，可能诱发更大范围的战争；而抵抗阵营的组织力和团结程度不足，使伊朗很难稳定地控制局面。
- 叙利亚同时连接伊朗和俄罗斯，节目据此解释以色列打击叙利亚相关目标可能具有牵制和试探俄罗斯的意味，但判断俄罗斯很难在当前条件下大幅增加对中东的军事投入。
- 美国大选结果可能引发政治争议和一段权力真空，节目认为美国对以色列的实际控制力已经下降，因此未来一个月的地区风险存在较大不确定性。

### 01:03:05-01:10:11：数学重要，但不能成为万能归因

- 节目从一篇“中美信息技术差距源于不重视数学”的文章切入，讨论软件、芯片和操作系统的差距是否能够直接归因于数学底蕴不足。
- 主播反对从应用软件一路向下推到操作系统、计算机体系结构，再推到数学，最后把所有技术问题都解释为数学没学好。这种“越往底层越接近本质”的推论，可能只是把复杂的产业、商业和教育问题过度简化。
- 数学的重要性不能因此被否定。数据科学和人工智能专业如何设置数学课程，关键不是无差别增加高深课程，而是明确学生要解决什么问题、需要哪些知识。
- 节目指出，数学专业课程与数据科学、人工智能之间长期存在教学衔接的困难：懂数学的人未必了解应用，懂计算机的人又未必能把数学讲得严谨。

### 01:10:11-01:19:05：计算机和人工智能需要哪些数学

- 节目支持按需学习数学。数学从初等内容到研究前沿跨度很大，并不是某个专业需要把整门学科的所有分支都学完。
- 对计算机和人工智能而言，微积分确实有用，但重点通常是极限、导数、偏导数、链式法则等基础工具，而不是把所有复杂的数学分析技巧都当成必修。
- 线性代数中更常用的是向量、矩阵、行列向量以及与函数、偏微分和算法相关的概念。教学可以从计算机科学的算法和论文出发，整理出必学与可选的数学工具。
- 节目设想由计算机科学教师和数学教师合作，围绕真实技术提炼公式和工具，形成一套面向计算机科学、实用而不失严谨性的数学课程。

### 01:19:05-01:25:48：统计概率、抽象思维与应用型教材

- 统计与概率在当代人工智能和数据科学中非常重要，对法律、经济学、人类学、社会学等非计算机专业也有普遍价值。
- 学习统计概率不应停留在公式记忆，还要理解数据、阅读数据报告，并通过实际问题掌握常用算法和分析方法。这部分内容尤其适合应用驱动的教学。
- 数学教育中真正需要尽早掌握的是三段论、从特殊抽象出一般、把具体问题形式化等基本逻辑和抽象思维；这些能力会影响人们理解问题和识别误导的能力。
- 节目批评一些数学教材内容精简、应用案例不足，导致学生在学习时不知道用途，等到真正需要时又已经遗忘。面向数据科学和人工智能的课程应围绕目标裁剪内容，并改善数学与学科之间的协作。

### 01:25:48-01:33:25：知识结构与数学的两种作用

- 学习者需要建立结构化的知识工具箱：遇到问题时先判断它属于哪一类，再知道缺少什么能力、应该去哪里补课，而不是被各种“大牛”牵着去堆积知识。
- 大学教育需要更多能贯通知识上下游的通识内容，但抽象的方法论最好嵌入计算机、数据或人工智能等具体课程，用案例帮助学生理解，而不是孤立地讲成一门枯燥课程。
- 数学对其他学科有两种作用：一是提供可以封装和调用的工具，二是提供形式系统和形式逻辑，为学科建立可靠的理论基础。绝大多数人不必掌握全部原理，但应能在需要时理解和使用合适的工具。
- 节目的结论是，数学很重要，却不是所有数学内容对所有人都同样重要；基础逻辑和抽象能力应尽早打牢，专业数学则可以根据问题按需学习。

## 核心观点

1. 一次投票、一个奖项或一份技术演示，都不能替代用户真实体验和长期产品价值；媒体、软件项目和教育课程都需要接受实际使用的检验。
2. “公开源码”不等于严格意义上的开源，商业项目可以选择自己的许可证，但应准确描述开放程度，并承担由此带来的社区信任成本。
3. 商业竞争和创作失败不应轻易转化为对用户或社区的道德审判。真正的差异化仍然来自产品质量、用户体验和持续建设。
4. 数学很重要，但不应成为解释所有技术落后的万能答案；学习内容应由问题和专业目标决定，并与真实应用结合。
5. 高效学习不在于把所有知识全部掌握，而在于形成知识结构，知道何时调用已有工具、何时补齐缺口，以及哪些原理需要深入理解。
