# 第108期 新质生产力要更敢想

## 内容摘要

本期先从 Rust TUI 库 Ratatui 收到用户主动赞助的故事谈起，讨论开源项目背后的理想主义、商业可持续性，以及 Redis 更改许可证后社区分裂为 Valkey 的后续。节目认为，大公司可以用开源追赶封闭技术、争夺行业标准，但小公司很难仅凭开源与大公司正面竞争；开源生态仍需要理想主义者，也需要更公平的企业投入和回馈。

随后节目讨论未成年人犯罪与校园霸凌。法律下调刑事责任年龄能够处理最严重的个案，却不能替代对校园霸凌、家庭失能、心理发展和学校处置机制的提前干预。十岁到十五岁左右的孩子可能已经有很强的行动能力，却还不能充分理解行为后果，因此监护人责任、心理检测、教育和矫治体系都需要一起考虑。

节目接着解释“新质生产力”与开源的关系：开源通过降低软件供应链成本、促进技术复用和开放协作提高整体生产力，但真正符合“新”的尝试，应当是企业、高校、科研机构和基金会共同完成的工业级软件协作，并探索新的贡献分配方式。随后节目认为，百年老店可以作为企业文化中的长期主义象征，却不是企业战略目标；在技术、资本、品牌和渠道快速流动的时代，持续创新比存续年限更重要。

读书环节推荐茨威格的《昨日的世界》、Easley 与 Kleinberg 合著的《网络群体与市场》，以及埃德加·斯诺的《红星照耀中国》。三本书分别从个人记忆与时代变迁、网络结构与群体行为、现场采访与历史记录，提供了理解社会和历史的不同视角。

## 时间线

### 00:00-10:28：Ratatui、开源赞助与 Redis 社区分裂

- Rust 社区的命令行 UI 库 Ratatui 被一个重度依赖它的项目主动提出赞助；维护者原本没有建立受捐体系，收到请求后才迅速补上账户和支付渠道，第一笔捐款最终达到数万美元。
- 节目把这个故事看作开源世界中“可以做但不必须做”的事情仍有人愿意去做的例子。开源项目常由兴趣和理想主义启动，使用者的感谢和资助能够帮助这种长期投入继续存在。
- 开源参与者的绝对数量未必减少，但随着大公司和逐利者进入，理想主义者的相对比例会下降；真正持久、影响深远的项目仍常常需要这类人的长期推动。
- Redis 原始开发者退出并将项目交给公司后，公司试图通过云服务和新的授权模式应对云巨头的竞争；AWS、阿里云、腾讯云和爱立信等大企业同时增加了对 Redis 社区的贡献。

### 10:28-15:09：Valkey 与开源商业竞争的边界

- Redis 更改许可证后，社区出现分裂；来自亚马逊的开发者创建 Valkey，并计划将其捐赠给 Redis 基金会，原社区的大量开发者随后迁移过去。
- 节目提到，Valkey 开源十天左右时 OpenRank 已达到 Redis 的约一半，参与者规模达到 146 人；这显示社区迁移可能带来很快的影响力变化，但最终谁能胜出仍有不确定性。
- 对商业公司来说，开源适合强者用来追赶封闭技术、争夺标准或弥补时间差；小公司若想靠开源直接与大公司竞争，通常更现实的路径是提供技术、收取服务或专利费用，甚至被收购。
- 依赖开源生存的小团队如果错误估计竞争关系，陷入困境后可能转向闭源、制造版本差异或借舆论博取同情；企业参与开源仍应面对自己的商业边界。

### 15:09-25:22：未成年人犯罪与校园霸凌

- 近年未成年人犯罪受到更多关注，节目提到案件呈现低龄化和舆论反应增强的趋势；法律曾对未成年人设置较高的刑事责任年龄，2021 年修法后对十二岁以上、十四岁以下的极严重致人死亡案件增加了追责条件。
- 节目提醒，不能只盯着已经进入刑法程序的极端案件。校园霸凌更普遍，等到需要刑法处理时往往已经太晚，家长、老师和学校需要更早发现、制止和干预。
- 一位主播回忆自己中学时因年纪小、体格弱而长期被抢东西、殴打和排斥，反复报告老师却使霸凌升级，最后甚至曾用书包带勒住同学，幸好被及时拉开。
- 这段经历说明，持续的小规模伤害可能把被霸凌者推向危险的反击；家长和学校不能把“孩子不想上学”简单归结为厌学，也不能用一次训斥或息事宁人代替持续处理。

### 25:22-35:29：心理发育、家庭失能与提前干预

- 节目推荐一档由记者李翔主持、邀请心理学和法律从业者讨论未成年人犯罪的节目，并借此区分法律视角与心理、教育视角。
- 九岁到十五岁左右的孩子可能已经具备较强的智力、身体和行动能力，但负责理解社会后果的能力发育较晚；情绪冲动与后果意识之间的错位，使这一阶段更容易出现危险行为。
- 霸凌者家庭中常见暴力、留守、孤独和缺乏沟通等问题，但家庭背景不是犯罪的必然原因；问题一旦持续扩张，往往会同时伤害施暴者和受害者。
- 学校尝试用手环等数字化手段观察学生状态，但被观察本身会改变行为，且技术检测不能自动解决后续责任、治疗和家庭配合问题。

### 35:29-40:29：刑罚、监护人责任与社会治理

- 心理健康检测理论上可以较早发现严重问题，但学校和家长担心检测结果带来责任，部分家庭也缺乏认知或不愿配合，导致“能检测却不敢检测”。
- 继续下调刑事责任年龄会遇到心智承受能力、专门矫治场所、教育改造和回归社会等问题，不能简单把儿童送入成人监狱或以“关到十八岁”替代制度设计。
- 刑罚除了威慑和惩戒，还应包含改造与重新进入社会的安排；未来法律可能需要进一步讨论监护人的赔偿和责任，而不是只把责任压在孩子身上。
- 未成年人犯罪与校园霸凌最终牵涉家庭教育、学校经验、心理服务、社会财富和精神文明水平，不能用一句“杀人偿命”概括解决方案。

### 40:29-50:40：什么是“新质生产力”

- “新质生产力”成为高频词后，许多行业都试图把自身纳入其中；节目先引用“科技突破、生产要素创新配置、产业转型升级”等解释，再追问这个新词为什么有必要出现。
- 节目的一种理解是，这个概念不只是重复“科技是第一生产力”，而是希望把注意力聚焦到面向未来、可能产生下一轮工业革命的领域，并提高发展的力度和主动权。
- 中国已有的工业体系、资金、劳动力和技能构成了基础优势，但如果下一代技术被别人率先掌握，既有优势仍可能转化为被动局面，因此需要把现实基础变成长期竞争力。
- 开源可以降低软件供应链成本，推动代码和技术复用，也能把开放协作从写代码扩展到共同写作、研究和解决社会问题；政府不应只统计“开源产业”的产值，还应关注所有行业使用开源后带来的总体效率提升。

### 50:40-01:00:05：从开源协作到“开源 3.0”

- 如果企业、高校、科研机构和基金会共同建设面向 AI 计算的 GPU 软件栈或兼容标准，让硬件厂商、研究者和开发者都能贡献和使用，这种联盟式研发可能比单一公司的产品更接近新的生产方式。
- 这类项目的难点在于缺少明确的项目主人，资金、贡献和决策权都不容易分配；节目提出用贡献度模型建立软件研发和收益再分配方案，作为一种尚未充分实践的制度创新。
- 节目把基金会与大企业协作、战略型项目涌现和开源进入更多人的日常使用概括为“开源 2.0”，认为下一阶段要同时考虑工业化、实体经济和中国自身的组织制度条件。
- “新”不能只靠换一个名词来证明，至少要形成过去没有的研发协作模式，且有可能影响一个世代；具体方案仍需要边做边试、持续修正。

### 01:00:05-01:06:37：学校与新技术方向

- 节目认为，欧美的基金会式开源协作也并不完美，企业、高校、研究机构和基金会如何形成更有效的合作仍在探索；中国如果能做出有价值的参考实践，就可能形成自己的贡献。
- 面向央国企的开源方案可以让企业提供资金和需求，基金会负责组织，社会研发力量参与实施，从而把开源项目与工业现代化结合起来。
- 高校正在建设未来技术学院、学习中心、人工智能学院等新实体，重新整合学科与专业；“新质生产力”也成为判断教育改革抓手和数字化人才培养方向的一个尺度。
- 由于概念本身仍在形成，节目保留了对具体路径的谨慎态度，强调要在实践中试验、修正和重新判断。

### 01:06:37-01:20:40：百年老店不是战略目标

- 马云在内部信中用“过去二十五年、未来七十七年”回顾阿里，节目由此解释“百年老店”的来历，并质疑企业为什么要把存续一百年本身当成目标。
- 企业成功不以成为百年老店为充分或必要条件；评价企业和国家竞争力时，存续年限或老字号数量也不是决定性指标。
- 百年老店作为企业文化可以提醒员工重视责任、品牌和长期价值，但企业战略真正应追求持续正确、持续更新并成功执行，而不是单纯延长寿命。
- 过去资本、技术、品牌、人才和渠道难以流动，百年积累可以形成稳定壁垒；今天这些要素开放且流动更快，新能源车等新企业能够在十到二十年内迅速改变行业格局。
- 长期存续的组织还必须保持进取心并不断自我革命，这很难做到；所谓百年积累只有能说清楚具体积累了什么，才会转化为现实竞争力。

### 01:20:40-01:30:06：《昨日的世界》与两次世界观重塑

- 茨威格的《昨日的世界》是一部带有强烈感伤底色的个人回忆录。作者回顾了从十九世纪末到两次世界大战的生活，写完后不久在流亡中自杀，认为自己熟悉的时代已经结束。
- 节目把西方历史中的科学革命和 1850 至 1950 年间的第二次世界观重塑联系起来，提到达尔文、马克思、弗洛伊德和爱因斯坦等人的思想如何改变人们对世界、人类和自身的理解。
- 中国近代史在较短时间内同时承受这两次世界观重塑，因此理解这段历史不能只看事件，还要看知识、社会和世界观如何被快速传入并重新组合。
- 书中写到罗曼·罗兰、罗丹、弗洛伊德和高尔基等人的交往，既记录了一个时代的文化网络，也展现了大师投入工作和表达思想的不同方式。

### 01:30:06-01:40:37：《昨日的世界》的时代感与《网络群体与市场》

- 茨威格写巴黎不同街区的生活差异，节目由此联想到近代上海的租界和社区：交通不发达时，同一城市内的人群也可能长期生活在彼此隔离的环境中。
- 交通和旅行越来越发达后，城市与城市之间的差异会逐渐缩小；读历史的意义之一，就是同时看到时代之间巨大的差别和反复出现的相似处。
- 《网络群体与市场》是一本把计算机、网络科学、经济学和博弈论结合起来的大学教材，核心分别对应网络结构与网络上的群体行为。
- 书中用图论、网络模型和博弈分析解释六度分离、信息级联、幂律分布、市场泡沫和影响力扩散等现象，适合训练用计算方式理解原本难以计算的问题。

### 01:40:37-01:49:34：《网络群体与市场》的方法和应用

- 这本书有二十多个章节和丰富习题，内容从网络结构、均衡和策略互动延伸到搜索引擎排序、互联网拍卖、匹配市场和制度设计。
- 书中的例子不仅解释网络如何影响个体决策，也讨论如何通过规则设计鼓励有益现象扩散、减少病毒传播等有害结果。
- 配套的斯坦福、康奈尔大学课程和北大教授制作的课程资源，使它既可以作为教材，也可以作为互联网产品、数字服务和跨学科研究的入门材料。
- 节目把这本书与 OpenRank 等研究联系起来，认为网络结构、群体行为和影响力测量能够帮助理解开源社区及其他互联网系统。

### 01:49:34-02:00:27：《红星照耀中国》的写作与出版

- 埃德加·斯诺在 1936 年六月到十月访问红色根据地，随后将采访材料写成《红星照耀中国》，英文版在英国出版后迅速再版，并成为当时的国际畅销书。
- 斯诺通过现场观察和采访，让西方读者第一次较系统地了解中国共产党及其领导者；他后来在版本中补充抗日战争和游击战的内容，也持续表达对中国局势的判断。
- 胡玉芝确认书稿真实后，组织十二人团队翻译约三十万字，并通过“复社”私下印刷；为降低出版风险，中文初版使用了《西行漫记》这个名称，后来才恢复为《红星照耀中国》。
- 首版一千册很快售罄，复社在一年内出了四版；这段经历说明出版、翻译、预售和读者支持可以共同让重要材料突破当时的出版限制。

### 02:00:27-02:14:15：斯诺的客观记录与阅读价值

- 斯诺根据采访对象校订记录：与周恩来的谈话由双方直接用英语核对，毛泽东的谈话则经过口译、整理、中文审阅和重新翻译，以尽量保持原意。
- 斯诺不是共产主义者，但努力以旁观者身份记录事实；他既写下不同人对红军的矛盾看法，也记录窑洞、周恩来和少年先锋队员等日常细节，为东西方理解当时的中国提供了独特视角。
- 书中材料兼具新闻专业性、历史价值和个人观察，后来成为研究那个时代的重要原始资料；斯诺本人也因长期客观报道和对华友好，在美国受到麦卡锡主义影响，晚年将部分骨灰安葬在北京大学未名湖畔。
- 节目建议重读这本书：年轻时读到的是故事，成年后再读，可能会更能理解其中的时代变化、记录方法和人与人之间的复杂关系。

## 核心观点

1. 开源的公共价值来自长期复用和开放协作，但要持续存在，既需要“just for fun”的理想主义，也需要使用者、企业和基金会建立合理的赞助与回馈机制。
2. 未成年人犯罪的法律责任只是防止最坏结果的一道边界；校园霸凌、家庭教育、心理成长、学校处置和后续矫治必须在更早阶段共同介入。
3. “新质生产力”不能停留在给旧事物换标签。真正有意义的创新，应改变研发协作、资源配置和产业连接的方式，并能在实践中证明其长期影响。
4. 百年存续是持续做对事情后的可能结果，不是企业应直接追逐的战略指标；在变化加速的时代，持续创新和自我更新更关键。
5. 历史、网络科学和现场记录都能提供理解现实的不同工具；重读旧书的价值，不只在于获得结论，也在于获得观察时代和核对事实的方法。
