# 第94期 文科很有用但是

- 来源：`transcript-site/episodes/ep-94.html`

- SRT 条目：632
- 阅读段落：145

## 内容摘要

本期从甘肃地震救灾谈起，讨论浅层地震、山区住房、应急运输、卫星遥感、无人机和临时供餐，认为这些看似不炫目的能力体现了工业化和国家应急体系的积累。随后谈到美国实体清单、WPS 去广告、浏览器内核、鸿蒙 Next 和游戏管理办法，重点关注国产软件能否在生态、服务和迁移成本上真正形成替代能力。

节目中段回到东方甄选和董宇辉的后续安排，分析头部主播、平台治理和教师群体的商业化转型。之后讨论大模型的竞争、检索增强生成、代码模型和终端用户反馈，认为当前仍处于搭建工具和组合产品雏形的阶段；AI 进一步连接自动化设备和领域语言后，可能改变科研、制造和论文验证方式。

最后讨论中国大学之间越来越明显的差距，以及清华“丘班”“姚班”等人才培养机制为什么难以简单复制。节目以“文科很有用，但是需要有用的文科人才”收束：教育、科研政策、开源法务、知识产权、社区治理和国际话语体系，都需要人文与社会科学真正产出可验证、能落地的工作。

## 时间线

### 00:00-10:32：甘肃地震与应急体系的工业化

- 甘肃地震震级不算极高，但震源浅、发生在山区和深夜，部分居民可能仍住在较老的房屋中，因此实际灾情比单看震级更严重。
- 与汶川地震时期相比，这次救援在部队、指挥部、运输机调配，以及电力和通信恢复方面明显更快。系留无人机照明、应急通信无人机和临时食堂等设备未必有很高的技术炫耀性，却非常实用。
- 自然资源部门调度卫星，对比震前与震后影像、雷达和地质数据，可以判断地表变化、次生灾害风险和临时安置点位置。高分辨率、高轨卫星的积累让这些能力能在灾害发生后迅速投入使用。
- 救灾复盘还会反过来推动指挥、训练、交通和基础设施建设。节目把高铁网络的一部分价值理解为平时出行之外的动员能力，并指出许多空天、无人机和传感器项目具有军民两用属性。

### 10:33-15:27：实体清单与国产技术公司的机会

- 一家从 PCB 设计起步、后来拓展芯片业务并被立创收购的企业进入美国实体清单后，国内相关从业者的反应已经从早年的恐慌转为祝贺，认为这反而是一种能力认证和市场信号。
- 实体清单仍有实际威力，但国际厂商会寻找规避方式，而对本来就不依赖向美国出口的中国小型科技企业，限制措施可能无法直接达到预期效果。
- 这类企业的价值不只在当前收入，还在于为未来国内产业需求积累能力。被点名后，国内客户、政府和产业链可能更愿意关注和扶持它们。
- 节目认为，技术管制的结果并不总是单向压制，也可能促使被限制的一方加速建立自己的产品和供应链。

### 15:28-23:03：WPS、软件替代与用户价值

- WPS 个人版彻底移除广告，可能意味着厂商已经不再依赖这部分小额收入，也可能是在为教育、政府和其他大规模场景争取更好的用户体验。
- WPS 的价值不只在打开文档和制作演示文稿，还包括工资表一键生成电子工资条、模板库、论文查重等面向具体人群的功能。解决小而真实的工作问题，可以形成比广告更稳定的付费路径。
- 个人版免费、模板等增值服务和政府或企业大宗采购，共同构成办公软件的商业模式。软件是否好用，最终仍要靠细节、服务和长期积累，而不是单纯依靠口号替代。
- 在极端供应限制下，国产办公软件已经比操作系统更接近可替代状态；深度操作系统与 WPS 结合，也可能在教育办公等场景形成较完整的替换方案。

### 23:04-30:19：浏览器内核、开源与自主能力

- 一支从 WPS 出来的团队尝试做浏览器内核，并非完全重写所有组件，而是保留部分成熟的开源渲染能力，同时替换或改造关键模块。这种“吃透、改得动、用得起来”的能力比简单宣布原创更有价值。
- 浏览器内核至少包含页面渲染和 JavaScript 运行等关键部分。渲染需要遵循 W3C 标准，性能优化、本地存储、加速和用户端整合则留下了较大的工程空间。
- 浏览器内核接近一个操作系统级别的复杂工程，涉及内存、存储和输入输出管理，而且很难靠产品本身获得足够收入，因此团队需要清楚认识市场并等待合适的产业机会。
- 早期美国限制高强度加密出口时，国外版本浏览器曾被削弱加密能力；节目把后来开源社区突破限制视为开源推动技术自主的案例。

### 30:19-37:43：鸿蒙 Next、生态迁移与游戏监管

- 鸿蒙 Next 开始向关键行业合作伙伴释放原生版本，米哈游启动《原神》等鸿蒙原生版本开发，被节目视为游戏生态迁移的重要试验。迁移效果、性能和改造成本，将决定其他厂商是否跟进。
- 鸿蒙的目标是即使现有国际软件模块不可用，也能独立运行，因此需要重建类似 npm 的组件托管服务、开发语言和配套生态。当前版本更新较快、文档和服务尚不完整，外部合作伙伴需要承受较高的不便。
- 鸿蒙原生生态的难点不只是系统本身，还包括第三方组件、底层游戏和应用的迁移成本。节目预期它需要一到两年达到基本可用、两到三年逐渐成熟，并对云原生游戏方向保持期待。
- 网络游戏管理办法当时仍是征求意见稿，涉及版号、发行和运营管理的整合，绝大多数内容是对既有规则的标准化和具体化。主播认为股市反应较大，但具体影响需要等正式版本并在后续节目展开。

### 37:44-48:44：董宇辉的新职位与组织设计

- 东方甄选对董宇辉的新安排包括新东方集团董事长文化助理、东方甄选高级合伙人和东方文旅集团副总裁。节目强调，职位的真实权限仍需观察，只能根据一般组织常理推断。
- “文化助理”可能意味着俞敏洪希望把董宇辉带在身边，既利用他的文化表达能力，也减少关键阶段出现变数的风险；新设公司和“高级合伙人”机制，则可能让头部主播获得独立的收益、管理和业务试验空间。
- 主播把高级合伙人理解为从旗舰店中成长出来的独立店主：业绩仍可能并入主体公司，但经营逐步独立，成为主播从公司员工走向合作伙伴的一种过渡安排。
- 东方文旅已通过收购旅行社、服务机构和软件系统公司搭建业务版图，副总裁职位理论上更接近实际业务岗位。节目认为，这可能是新东方除带货以外的重要增长方向，但具体职责仍不能确定。

### 48:45-56:46：大模型竞争尚未出现最终范式

- 关于全球还能留下多少家大模型公司的判断，取决于“大厂”、通用模型、专业模型和产品层级如何定义。节目认为这个领域变化太快，没有人能确定最终会由哪条路线胜出。
- 检索增强生成等范式通过先检索、压缩上下文、生成答案并进行比对，尝试降低幻觉。节目把它们视为仍在探索中的工具组合，类似编程早期从汇编和 C++ 逐渐发展出面向对象、动态类型和企业架构的阶段。
- 微软开源大模型编程框架，可能是在争夺下一代编程范式和开发工具的入口，但它不太可能就是最终答案。当前更像是螺丝刀、钳子和积木等基础工具已经出现，产品形态还需要继续组合。
- 大模型能把自然语言需求拆成一组要素和令牌，再调用不同工具形成产品雏形。真正的竞争不只是单个模型能力，还包括内容库质量、工具组合、产品迭代和使用反馈。

### 56:48-01:10:44：代码模型、自我验证与终端用户循环

- 检索和生成结合的思路并不完全新鲜，AlphaGo 从依赖人类棋谱转向让两个 AI 互相对弈，体现了用结果反馈修正模型的路径。大模型应用也在尝试让系统自己搜索、比对和修正答案。
- OpenAI 的先发优势可能像早期 Google 的索引积累一样，通过更多用户、更多反馈和更高质量内容形成正循环；但一家独大对行业并不健康，竞争者仍需要提供足够好用的产品。
- 主播用“2011 是否能表示为 11 个连续素数之和”测试代码模型。多数模型无法稳定理解数学问题，ChatGPT 则能调用 Codex 生成并运行程序，再根据运行结果回答。
- 代码模型与自然语言模型各有所长；能否根据问题自动切换模型、运行代码并向用户展示分析过程，是产品体验的重要差异。执行代码需要容器和资源，但可以显著提升答案的可验证性。
- 国内模型不应急于收费和设置使用门槛，专业化的 DeepSeek Coder 之类产品即使只聚焦代码和中文编程教育，也可能通过开放使用持续迭代。终端用户提出的真实需求，才会推动模型走向成熟产品。

### 01:10:44-01:23:42：AI for Science 与可执行的科研

- 大模型开始被用于科学发现，例如从大量化学配方中筛选实验对象，再进一步设计实验方案并驱动自动化设备完成合成、加工和测试。这条路径连接了生成、检索、实验设备和结果反馈。
- 当科研设备能够被计算机驱动，每个行业都可能形成自己的领域特定语言（DSL）。研究者只需表达需求，AI 将其转换为驱动设备的一组指令，科研、工业设计和制造由此逐渐接近工业 4.0 的自动化流程。
- 数学研究也在尝试用专门的数学编程语言处理符号推理，让大模型把研究需求转成可运行的形式，并自动完成部分验证工作。关键变化是把论文中的实验和推理变得更容易复现。
- 可执行的论文类似可以直接运行的开源代码：即使读者不完全理解论文，也能通过标准化设备、配方和 DSL 重现实验并发现问题。设备、流程和标准化尚未充分成熟，因此产业应用可能早于科研全面落地。

### 01:23:42-01:33:55：大学差距与高端人才流动

- 清华本科生特等奖学金候选人的研究成果、综合素质和社会待遇，被节目用来说明顶尖大学之间的差距正在扩大。顶尖高校最优秀的硕士、博士毕业生可能获得六十万至八十万元年薪，个别人甚至得到更高报价。
- 节目担心，如果只有少数中国大学拥有足够强的生源、师资和资源，其他优秀学生就会更多地流向国外；清华培养的人才也可能因国内承载能力不足而继续去美国深造或工作。
- 中国当年约有七点五万名应届博士，美国一年约有二十万名博士毕业生。按节目引用的数据，中国已确定去高校或科研机构的比例较高，而美国进入学术岗位的比例约四成，更多博士进入社会就业，人才分布更有弹性。
- 问题不只是论文数量，还包括顶级学校数量、博士培养质量、人才去向和大学能否为高端人才提供合适的职业路径。单一头部的领先不能替代更广泛的高水平大学体系。

### 01:33:56-01:42:37：从丘班、姚班看人才培养机制

- 引进顶尖人才只是开始，能否提供足够自主权、资源和制度保障，让人才在学校真正开展工作，才决定引进是否有效。很多学校最后只能让名家挂名，原因在于行政、评价和项目体系没有同步改变。
- 清华丘班、姚班允许通过专门竞赛和自主招生渠道选拔学生，甚至不占用常规保送名额。节目认为，这种小范围的制度突破是其培养效果的重要原因，但公开扩大时容易遭遇“不公平”和“特殊化”的争议。
- 类似试点若被推广到更多学校，需要配套的教师管理、课程安排、评价机制和长期资源，而不是简单地再增加一个特色班。退休且已功成名就的学者，反而更有条件专注于本科生和高中生培养。
- 节目建议在全国选择少数学校复制已经验证的案例，先做高等教育的小规模试点。培养顶级本科生的研究习惯和兴趣，是连接后续硕士、博士阶段的关键环节。

### 01:42:37-01:53:22：文科有用，但需要有用的文科

- 节目不接受把文科简单归为“无用”。更准确的说法是，部分文科教育没有把重要性转化为可落地的成果，导致学生、家长和社会看不到学习价值。
- 教育政策、人才政策、科研政策、大学治理和工程管理本质上都需要人文与社会科学参与。中国开源生态缺的也不只是程序员，还包括法务、知识产权、社区运营、治理、政策研究和商业人才。
- 文科研究应像工程一样逐步建立评价和验证方法，例如研究如何判断教学效果、总结改革经验并形成可复用的理论，而不是停留在漂亮但无法检验的概念。
- 国际政治领域中，“unite and prosper”与“divide and conquer”的对照，被节目视为构建新话语体系的尝试。话语、翻译和表达虽然不等于完整学问，却确实具有技术含量和现实影响。
- 理工科的问题往往可以归结为如何培养更多人追赶前沿；文科更需要回答“做什么、怎样做、如何验证”，最终目标是培养真正能解决社会问题的人才。

## 核心观点

1. 工业化的价值常常体现在应急救灾、通信恢复、卫星遥感和临时供餐等不显眼但可靠的能力上，而不是单个炫目的设备或概念。
2. 国产替代的难点是完整生态。软件、浏览器和操作系统不仅要能运行，还要有组件、工具链、迁移路径、服务和足够低的使用成本。
3. 大模型仍在寻找产品和工程范式。模型能力只是基础，真实用户、工具组合、可验证的执行结果和持续反馈才会推动产品成熟。
4. AI 连接自动化设备和领域语言后，科研与制造可能从“人读论文、手动实验”走向“需求可执行、结果可复现”的流程，但这依赖标准化基础设施。
5. 文科不是没有价值，而是需要把教育、政策、治理、知识产权、社区运营和话语体系等问题做成可验证、能落地的工作。
