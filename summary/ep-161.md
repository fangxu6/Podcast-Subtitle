# 第161期 AI时代的IDE战争

- 来源：`transcript-site/episodes/ep-161.html`
- 时长：01:39:55
- SRT 条目：2049
- 阅读段落：155

## 内容摘要

本期先回顾特朗普第二任期的前 100 天，讨论关税战、中国的强硬回应、DOGE 的收缩以及马斯克逐步退出白宫的原因。随后分享杭州 2050 大会的见闻，围绕 AI 时代的家庭教育、人与 AI 的情感边界、AI 对创造力的影响，以及一个开放大会如何在自由和秩序之间取得平衡展开讨论。

节目中段分析千问 3、DeepSeek-Prover-V2 等模型。讨论重点不只是模型能力，还有混合推理模式、MoE 架构、工具调用、推理引擎适配和本地运行工具带来的生态问题。节目认为，基础模型越来越难带来巨大的惊喜，但模型接口和配套生态仍在快速变化，标准和最佳实践尚未稳定。

后半段讨论两起“董小姐”相关舆情，提醒听众区分已知事实、网络爆料和转移注意力的叙事，重点聚焦医学教育中的“4+4”培养体系及其公平、质量和监管问题。最后节目回顾从 Turbo Pascal、Delphi、Visual Studio、TextMate 到 VS Code 的 IDE 演进，并分析 Cursor、Windsurf、Cline、Aider 和 Codex 等 AI 开发工具可能引发的新一轮 IDE 战争。

## 时间线

### 00:00-10:33：特朗普任期百日与马斯克退出

- 节目用“眼花缭乱”概括特朗普第二任期前 100 天，并以加拿大、澳大利亚大选中的执政党逆转为例，说明特朗普带来的国际政治反作用。
- 关税战和科技战逐渐成为美国难以摆脱的难题。中国选择直接承受压力，像游戏中的“坦克”一样顶住冲击，也给其他国家与美国谈判留下了筹码。
- DOGE 最初提出的削减赤字目标从数万亿美元不断下调，随着特朗普任命的人开始掌握各部门，继续大幅削减就会变成削减“自己人”，因此行动逐渐收缩。
- 国家安全事务顾问 Mike Waltz 被调离核心岗位，马斯克也逐步淡出白宫。节目认为，马斯克反对关税、政治活动影响其生意，同时特斯拉又处在转型期，双方可能形成了暂时体面的退出默契。

### 10:33-18:24：AI 时代的家庭教育责任

- 2050 大会上的交流让节目重新思考一个常见观点：家长是否应该完全放手，让孩子自己寻找热爱和特长。
- 节目认为，家长不能用“让孩子自由成长”来放弃自己的责任，尤其在 AI 时代。如果家长对 AI 和技术变化一无所知，就无法为孩子做出有根据的判断。
- 家长的介入程度应随孩子年龄变化，既不是完全不管，也不是事事控制。帮助孩子纠正错误、提供正向引导，不等于剥夺孩子的自由。
- “孩子会自己找到方向”的说法可能来自家长的惰性、自我怀疑或教育商业宣传。家长首先需要学习，再根据孩子所处阶段承担选择和引导责任。

### 18:24-28:06：人与 AI 的情感边界

- 2050 大会上有人分享与 DeepSeek 对话并因此落泪，也有人主张不要向 AI 提问，而要像和朋友一样交流，通过思维散步和追随好奇心获得新的想法。
- 节目认为，对话式使用 AI 有价值，可以让 AI 扮演朋友、老师或严格批评者，帮助人从不同角度思考问题。
- 但角色扮演不等于 AI 真的是朋友。当前 AI 没有独立的社会身份、法律责任和稳定的个体连续性，把对人的感情完全投射给它，可能造成依赖和误判。
- 如果未来某种机器程序能以独立个体身份承担社会责任并得到社会承认，人与机器的边界才会真正变得难以区分；在此之前，仍应记住它是工具。

### 28:06-37:28：AI 会增强还是削弱创造力

- 2050 的一场辩论讨论 AI 时代人的创造力会衰减还是增强。反方认为 AI 能加速表达，正方则担心人因过度依赖工具而放弃思考。
- 节目把创造力拆成“创”和“造”：AI 当前尤其擅长降低实现想法的成本，让有想法的人更快完成一次表达、获得反馈并进入下一轮迭代。
- 对创造力较强的人，AI 可能提高上限；对原本缺少技术实现能力的人，AI 也可能提高下限。但如果一个人只消费 AI 生成的结果、不再产生自己的想法，依赖仍可能削弱个人能力。
- 节目还反思 2050 大会本身：自由和混沌能带来意外交流，但资源有限时必须有优先级。未来可以同时保留有秩序的论坛和较为开放的活动，调整两者比例。

### 37:28-49:43：千问 3、Prover 与混合推理

- 千问 3 一次发布多个尺寸的模型，从小模型到两百多 B 的 MoE，降低了普通用户尝试和本地运行的门槛。节目认为，基座模型已经越来越难带来压倒性的能力惊喜，评价重点正在转向“是否好玩、是否容易用于开发”。
- DeepSeek-Prover-V2 面向机器辅助证明，把自然语言数学问题翻译成 Lean 语言，再进行形式化推理。它专业性很强，普通用户关注较少，但可能对数学研究和形式验证有价值。
- 千问 3 同时支持推理和非推理模式。节目认为，与其把产品设计成一个复杂开关，不如针对不同任务分别选择推理模型、非推理模型、代码模型或数学模型。
- 混合模式改变了返回字段和 chat template，导致客户端、推理引擎、量化模型和其他外围工具需要额外适配。模型能力的升级因此会牵动整个生态，并在发布初期造成碎片化和 bug。

### 49:43-01:03:13：MoE、本地运行与模型生态

- MoE 即混合专家架构。例如 30B-A3B 模型总参数量很大，但每次只激活约 3B 参数，因此可以用较少显存获得较快速度；追求最高质量时，参数全部激活的稠密模型仍可能更好。
- 千问 3 的工具调用能力比前代更好，但编程表现未明显超过专门优化的千问 2.5 Coder。节目期待后续推出更适合代码任务的版本。
- 节目分享了从 Ollama 迁移到官方 llama.cpp，并用 llama-swap 管理不同运行参数的经历：Ollama 更方便，但自有分支和封装隐藏了细节，遇到新模型时更新速度可能跟不上活跃的上游社区。
- 当前模型、推理引擎和工具都在快速变化，标准和最佳实践还没有形成。MCP 的普及更多取决于生态推进速度，而编程工具的提示词又往往针对特定模型调试，跨模型复用并不理想。

### 01:03:13-01:09:16：两起舆情与信息分辨

- 节目区分两起“董小姐”事件：第一起是企业内部对海归员工的用人判断，第二起则因同时触及医患关系、教育公平、学术腐败和男女关系而具有更广泛的社会影响。
- 网络讨论中不断出现新的简历、家族关系和学术履历爆料，但节目提醒其中可能混有虚假信息，不能因为传播量大就当成事实。
- 把相关人物和材料无限扩展，可能稀释公众对核心问题的注意力，形成“放大—分散—分化”的舆情效果。节目认为，应该把注意力集中到更具公共影响的制度问题。
- 在这些问题中，节目将医学培养体系视为更需要追问的重点，因为它同时关系到教育机会、学术诚信和患者安全。

### 01:09:16-01:19:20：医学教育中的“4+4”争议

- 节目介绍美国医学教育：通常先完成非医学本科，再读四年 MD；毕业后还要在公立医院服务至少五年，才能取得执照独立行医。美国的 MD 是医学职业学位，并不等同于研究型 PhD。
- 中国常规医学培养被概括为“5+3+3”：五年医学本科、三年医学硕士、三年医学博士，获得医学博士学位，培养时间和训练成本都很高。
- 节目对国内某医学院校的“4+4”医学培养体系提出强烈质疑，认为不能简单借用美国名称，再用“培养医学精英”包装一条不透明、可能绕开正常训练要求的通道。
- 节目推测，全球化分裂、海外升学和就业通道收紧，以及医学职业吸引力上升，可能共同增加了对这种快捷路径的需求；这一解释只是节目提出的判断，仍需更多事实和监管调查验证。
- 医生的专业能力直接关系患者生命，后果比一般教育质量问题更难补救。因此节目认为，医患关系、教育公平和学术诚信都需要对这类培养体系进行持续审查和约束。

### 01:19:20-01:31:38：从 Turbo Pascal 到 VS Code 的 IDE 历史

- 节目回顾早期 IDE：Turbo Pascal 让程序员在同一环境中编辑、运行、断点调试和查看变量；Windows 时代，Visual Basic 以可视化拖拽和代码绑定推动快速应用开发。
- Borland 的 Delphi 在全球尤其是中国受到程序员欢迎，凭借 Pascal、VCL 和面向对象的界面继承等设计形成竞争力；微软后来借助 Windows 的平台优势和 Visual Studio 生态逐渐占据主导。
- TextMate 和 Sublime Text 代表了从 IDE 转向轻量级程序编辑器的潮流，强调语法高亮、补全、插件和与命令行工具整合，而不是把所有功能都塞进一个庞大产品。
- VS Code 吸收了轻量化、插件化和 Web 技术的优势，又通过 LSP 和成熟的插件市场整合生态，最终成为新一代开发工具的中心。Eclipse、NetBeans 和 EditPlus 也体现了不同阶段的 IDE 与编辑器需求。

### 01:31:38-01:39:55：AI IDE 战争与生态控制

- AI 开发工具正在出现新的分化：Aider、Codex 等以命令行形态存在，Cline 等作为 VS Code 插件，Cursor、Windsurf 等则基于 VS Code 分叉出相对独立的 IDE。
- 微软过去擅长把不同产品的创新整合进统一平台，但本轮 AI 编程又进入百花齐放阶段。若微软限制 VS Code 克隆使用官方插件市场，分叉项目可能被迫自建更开放的插件生态。
- AI 不只是给旧 IDE 增加一个补全按钮，也可能重构应用与用户的交互方式。例如用户只需用自然语言说出一笔消费，记账软件就能自动识别时间、分类和金额。
- 节目认为 Cursor 过度鼓励一次性 Web Coding、缺少用户确认环节，可能牺牲控制感；Aider、Cline 等也在探索不同路径。嘉宾对最终赢家看法不同，但都认为微软凭借开发工具经验和生态仍有较大优势。
- 即使微软最终胜出，AI 对编程方式、应用界面和模型适配的改变也会持续制造新的机会；开放生态能否挑战平台控制，将决定下一轮 IDE 战争的形态。

## 核心观点

1. AI 时代的自由不等于放弃责任。家长需要先理解技术，再根据孩子的年龄和处境进行适度引导；个人使用 AI 也需要保留判断力。
2. AI 可以提高创造力的实现效率，但“提出想法”和“完成作品”仍是不同能力。工具能提高上限和下限，却不能替代人的思考与选择。
3. 基础模型的竞争已经延伸到推理引擎、接口协议、工具调用和本地部署。单个模型的升级如果破坏兼容性，也可能给整个生态带来成本。
4. 涉及公共利益的舆情应区分事实、推测和未经证实的爆料，把注意力放在医患安全、教育公平和学术诚信等真正重要的问题上。
5. IDE 的竞争本质上既是产品体验之争，也是平台和生态之争。AI 可能改变用户界面与开发流程，但开放插件、用户控制和可迁移性仍然重要。
