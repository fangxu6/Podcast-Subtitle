# 第169期 “著书立说”的终结

- SRT 条目：1954
- 阅读段落：146

## 内容摘要

本期从九三阅兵的观看方式谈起，讨论正式列装装备、无人机对坦克的影响，以及东风系列导弹、潜射战略导弹和反导拦截弹等可能出现的看点。节目随后分析伊朗、以色列和美国之间的冲突，认为各方的战争动机并不相同；美国试图快速介入后抽身，却可能因为以色列和国内政治压力而陷入更难收场的局面。

节目中段讨论北约要求成员提高军费、欧洲重新武装及其经济基础，再转向龙芯 3C6000，评价其硬件和国产供应链已经达到可竞争的水平，但软件生态仍需长期积累。后半段从 Google Gemini CLI 的开源、低价和命令行定位，谈到 Gemini 对 Anthropic 的冲击，以及 A2A 与 MCP 在 Agent 体系中的不同层级。

最后围绕 Anthropic 训练版权案讨论 AI 与书籍产业的关系。节目区分了购买书籍用于模型训练、模型输出时复制原文，以及“AI 读书”服务之间的法律问题，并认为未来知识生产仍需要人类判断和同行评议；只是过去由出版物承担的认证功能，可能会被新的知识服务形式逐步改写。

## 时间线

### 00:00-19:08：九三阅兵与战略装备

- 节目认为，抗日战争和世界反法西斯战争胜利 80 周年，以及对战后国际秩序和历史虚无主义的回应，是这次阅兵受到重视的背景；德国和日本可能重新武装，也被视为需要警惕的变化。
- 非军迷可以把阅兵当作大型仪式，关注军容、方阵和军乐；军迷则更关注以前没有见过的新装备。节目指出，正式阅兵通常只展示已经列装的装备，仍处于研发阶段的原型机未必会出现。
- 陆军部分可能展示针对 FPV 无人机攻顶威胁改进过的主战坦克，以及更多无人机和无人载具。重装合成旅已经出现专门使用和防御无人机的编制，说明无人装备正在进入体系化作战。
- 节目最关注战略导弹部队，列举了可能亮相但未获确认的东风-27、巨浪-3、东风-41 改进型、东风-5 新型号和大型反导拦截弹；这些内容属于节目推测，不能等同于正式信息。
- 稀土会影响永磁体、导航和部分军工材料，但节目认为，美国军工生产迟缓并不只由稀土供应造成，F-15EX 项目交付缓慢也反映了其制造和供应链本身的问题。

### 19:08-36:04：伊朗、以色列与美国的冲突逻辑

- 节目把主要参与方分成以色列、伊朗和美国，判断以色列有更强的持续开战动机，而伊朗受国内压力和地区力量受损影响，并不希望冲突扩大；美国同样倾向于避免长期战争。
- 主播认为，内塔尼亚胡的腐败官司和执政压力，是解释以色列强烈战争动机的重要因素；以“终止伊朗核能力”等安全理由作为公开说法，并不能解释全部行动。
- 美国曾试图推动新的伊核协议，却在谈判前遭遇以色列打击。特朗普随后以高强度空袭、宣布成功和迅速退出的方式处理介入，但伊朗和美国国内的质疑使这一叙事难以稳定成立。
- 节目根据公开的穿透能力估算讨论 GBU-57 钻地弹，认为伊朗山体中的深层设施很难只靠空袭摧毁；派地面部队又可能把美国拖入规模巨大的长期战争。
- 主播担心，持续打击反而可能坚定伊朗发展核武器的决心。三方都需要向国内展示“胜利”，却可能因此互相堵住退路，让局势重新进入紧张状态。

### 36:04-47:46：北约军费与欧洲重新武装

- 北约秘书长对特朗普的奉承和白宫制作的“爸爸回家了”视频吸引了舆论，但节目认为更重要的消息是北约提出成员国未来把军事预算提高到 GDP 的 5%；这一比例接近战时投入，许多成员未必能做到。
- 西班牙等国家对提高军费持保留态度，德国和法国则更积极。德国已经快速提高军费，法国希望建立欧洲自己的武装力量；北约决议后，欧洲军工股上涨也被视为市场对新增军事预算的直接反应。
- 法国不愿完全购买美国装备，德国可能在自主生产和采购美国装备之间摇摆。节目因此更担心欧洲特别是德国的重新武装，以及美国影响力收缩后欧洲内部力量失衡的风险。
- 节目用购买力平价比较中国、北美自由贸易区和欧盟的经济规模与增长率，认为欧盟经济增长乏力却增加军费，可能形成经济衰退和军事扩张并存的危险组合。

### 47:46-58:57：龙芯 3C6000 与国产芯片生态

- 节目认为，龙芯 3C6000 的硬件水平大致达到英特尔至强三代服务器芯片的档次，意义不只在跑分，还在于国内能够依靠一条没有外部依赖的供应链制造出高水平服务器 CPU。
- 该芯片据介绍采用国产 12 纳米工艺，主频低于至强三代，但通过架构优化取得接近的测试成绩。节目借此说明，制造工艺存在差距时，也可以通过架构和系统设计弥补部分性能差异。
- 芯片硬件已经“够用”并不等于生态成熟。龙芯的指令集已经获得 BIOS、Linux 内核和 GCC 等关键软件环节的支持，但数据库、消息队列、Redis 以及普通桌面应用还需要更多真实用户来适配和验证。
- 龙芯目前更多出现在政府采购、信创和高安全要求的场景，普通用户规模仍然不足。节目认为，产业链的基础已经搭好，接下来还需要数年时间靠持续使用、软件适配和制造进步缩短差距。
- 对龙芯与“汉芯”关系的质疑被节目视为事实错误或恶意泼脏水；真正有价值的判断，应来自持续的产品进步、实际应用和可验证的产业里程碑。

### 58:57-01:14:07：Gemini CLI 的爆发与产品边界

- Google 的 Gemini CLI 在开源和低价模型的推动下迅速获得大量关注。节目认为，它本质上是 Gemini 的命令行界面，可以通过类似工具调用的方式操作本地文件、搜索、生成图片或处理视频，但不能因此被夸大为新的 AI 操作系统。
- CLI 的价值在于把自然语言目标转换为一组命令行操作，并保留 Unix 工具各自完成单一任务、再通过组合完成复杂目标的思想。它与 Gemini API、网页端和其他界面是不同的使用入口。
- 节目肯定了 Gemini CLI 的终端界面、功能集成、文档和错误提示，也认为彻底开源提示词和代码是项目快速传播的重要原因；但“AI 操作系统预演”等评价被认为超出了产品实际边界。
- Claude Code 在部分复杂编程和工具调用组合上可能仍有优势，但 Gemini CLI 结合近乎免费的模型和开源终端工具，可能迫使 OpenAI、Anthropic 等厂商重新面对开发者的价格敏感度。
- Anthropic 的产品在特定编程场景中仍有用户黏性，但节目认为，面对大厂下场、免费模型和开源生态，单靠提示词或局部体验形成的护城河并不稳固。

### 01:14:07-01:21:48：A2A、MCP 与 Agent 平台

- 节目区分了 MCP 与 Google 推出的 A2A：MCP 主要解决大模型调用外部程序和工具的问题，外部对象可以是桌面、文件、数据库或 Web 服务；A2A 关注的是 Agent 之间如何发现、调用和协作。
- A2A 所要解决的问题与企业应用集成中的服务注册、发现和动态客户端生成相似。未来 Agent 或服务可以注册到一个公共平台，由其他程序发现、调用并按使用情况计费。
- 主播认为，Google 将 A2A 捐赠给 Linux Foundation，可能是在抢占未来 Agent 互操作标准的高地。Google 不一定垄断平台，但希望 Google Cloud、AWS、阿里云等平台都围绕它提出的协议建设。
- 节目用 OCI 标准与 Docker 的历史作类比：如果 A2A 或类似协议最终成为标准，MCP 可能只是实现标准中某个环节的框架，而不是整个 Agent 生态的唯一基础；不过 A2A 当时仍处于较早阶段，结果尚未确定。

### 01:21:48-01:30:11：AI 训练版权与合理使用边界

- 节目讨论的一起美国版权判决认为，购买在线书籍或文本后用于训练 Anthropic 等大语言模型，可以属于合理使用；其中关键不是“创新”字面意义上的革命性，而是模型学习后以与原书有显著差异的形式使用内容。
- 这一判决主要针对训练过程，并不等于模型输出大段未注明出处的原文也不侵权。正常引用与直接复制需要区分，使用盗版材料训练也不在这一判断的安全范围内。
- 主播认为，AI 训练虽然不直接复制书籍文字，却可能吸收书籍的核心知识，并以不同措辞回答读者问题，从而与原书销售形成竞争。未来的“AI 读书”服务如何界定侵权，可能比训练案更困难。

### 01:30:11-01:36:20：知识生产与“著书立说”的终结

- 如果书籍越来越难以销售，知识生产者可能转向把对话和经验整理成 AI 知识库，再以问答服务的方式出售。节目认为，这种变化未必是好事，也可能让知识产权体系出现竭泽而渔的问题。
- 新知识不能只由 AI 生成和自我认证，仍需要人类判断、同行评议和时间检验。过去出版文字承担的认证功能可能被颠覆，因此“著书立说”未来也许不再依赖传统的著书形式。

## 核心观点

1. 技术和制度的公开信号都只是起点。阅兵装备、芯片跑分、AI 产品和版权判决，都需要经过实际使用、反复验证和后续闭环才能证明成熟度。
2. 复杂系统的竞争不由单一指标决定。军事能力依赖预警、数据链和组织协同，芯片依赖软件生态，Agent 则依赖协议、平台和服务发现体系。
3. 价格、开源和标准会重新分配技术竞争的优势。大厂可以用免费模型和开放协议快速扩大生态，使局部产品体验形成的护城河变得脆弱。
4. AI 版权争议不能只看文字是否逐字重复，还要区分训练、输出、引用、授权来源，以及新服务是否已经对原有内容形成直接竞争。
5. AI 可以扩大知识生产和表达的效率，却不能替代新知识的判断、认证与责任承担；出版业和知识工作者需要为这种认证功能寻找新的组织形式。
