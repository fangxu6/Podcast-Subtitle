# 第89期 基础在民间，未来在青年

## 内容摘要

本期从 OpenAI 董事会突然解除 Sam Altman 的 CEO 职务谈起，讨论公司治理、董事会与管理层的分歧，以及外部资本或管理者个人问题等可能原因。节目强调这些只是主播基于有限信息的猜测，随后转向苹果在欧盟压力下准备开放 iOS 侧载，分析封闭生态在安全、应用分发、苹果税和开发者体验之间的取舍。

节目接着讨论李开复创办 01.AI 以及其基于 LLaMA 2 的模型，认为套用开源基础模型本身不是问题，关键在于是否有真正的技术突破，或能否用领域数据和应用场景创造附加价值。大模型 benchmark 和排行榜也可能被商业化利用；LM Studio 的下载和使用数据相对更有参考意义，但仍不能完全排除刷榜和媒体驱动的影响。

中段分析中美高层互动，区分象征性信号与实质性成果：军事沟通渠道恢复、气候和芬太尼等议题有推进，但芯片限制和台湾问题没有根本变化。节目更重视面向企业和民间的交流，以及“希望在人民、基础在民间、未来在青年、活力在地方”的方向，认为地方和民间关系可能比联邦政府层面的承诺更值得长期经营。

后半段从阿里云及语雀故障谈到身份认证、白名单和鉴权 API 的单点风险，并讨论 CAP 约束、容错设计、代码评审和组织管理。最后通过一名大学生对大学课程的吐槽，讨论从实践和问题出发的教学、大学教师的激励机制，以及用开放课程、区域合作和数字素养教育补足正规课堂的可能性。

## 时间线

### 00:00-14:51：OpenAI 董事会解职 Sam Altman

- OpenAI 董事会突然决定解除 CEO、联合创始人 Sam Altman 的职务，联合创始人兼总裁 Greg Brockman 随后也宣布离开；节目认为这意味着董事会与公司核心管理层之间出现了严重冲突。
- 主播先区分已知事实与传闻：事件突然发生、由董事会决定且没有经过股东大会，但解除创始人和现任高管会损害公司稳定，一般不会轻易采取。
- 节目列出外部资本试图控制公司或推动战略转向、董事会与管理层存在重大路线分歧、Altman 个人存在严重问题等几种可能；前两种被认为概率较低，第三种只是主播的无责任猜想，原始字幕中没有证据确认。
- 讨论认为，围绕 Altman 的个人声誉和公司未来会继续发酵，但不能仅凭董事会公告推断内幕；OpenAI 的业务和技术路线也不能简单等同于某一个人的个人推动。

### 14:51-22:21：iOS 侧载与封闭生态的安全代价

- 苹果准备在 iOS 17 的后续版本中支持侧载，节目认为这主要是欧盟相关法律压力下的被动调整，初期是否只提供欧盟特供版本仍不确定。
- iOS 的封闭性不仅是垄断和苹果税问题，也曾通过限制安装渠道减少病毒和恶意软件。开放第三方分发后，老人和不熟悉手机操作的用户更容易被诱导安装危险应用。
- 侧载同时解决了数码玩家想要自由安装的问题，也减轻了开发者面对审核延迟、应用上架不确定性和较高平台抽成的压力；主播认为 30% 的苹果税对很多低利润企业过高，并提出约 10% 可能更合理，这是节目观点而非行业定论。
- 节目推测苹果可能通过应用签名、可信开发者和强警告保留一部分安全边界，类比 macOS 的签名机制及鸿蒙的“纯净模式”，说明开放分发不等于取消所有治理。

### 22:21-28:33：01.AI、LLaMA 2 与模型附加价值

- 李开复创办 01.AI 后发布的大模型被批评为 LLaMA 2 的改名或套壳；节目认为双方没有否认这一基础，争议重点因此转向这种产品到底增加了什么价值。
- 讨论提到开源合规可能存在问题，相关判断来自对项目和许可证的检查，节目没有展开具体法律结论，也不把它写成已经确定的违规事实。
- AI 创业如果没有技术突破，就需要利用成熟模型寻找真实的垂直应用，并通过独特领域数据和使用场景训练定制模型；只把基础模型换个名字，难以说明商业价值。
- 节目还质疑以宣传和媒体曝光先行的产品定位：大模型创业的核心应是模型能力或应用价值，而不是先用宣传制造“下一代模型”的印象。

### 28:33-34:33：大模型 benchmark 与排行榜生意

- benchmark 原本是评估模型能力的技术和研究问题，需要设计合理题目、指标和验证方式；随着大模型创业升温，各种榜单开始被用来为产品宣传背书。
- 节目回顾榜单长期存在商业化和运营操作空间，企业甚至可能把“拿下某个榜单”当成业务指标，因此“第一”必须连同测试方法、样本范围和利益关系一起检查。
- LM Studio 通过下载和本地使用模型的流程积累用户数据，其榜单比完全按客户需求定制的榜单更有参考价值；但下载量仍可能受媒体报道驱动，也不能完全排除刷数据。
- 节目认为真实用户使用情况是重要信号。只要尽量避免操纵，使用数据比单纯的宣传口号更能说明一个模型是否真的被采用。

### 34:33-47:34：中美高层互动的象征与实质

- 节目先区分高层互动的象征意义和实质意义，认为双方仍处于高风险竞争关系，“中美要和好”或“见面等于没有结果”都过于简单。
- 元首会面中的个人化交流和亲善信号有助于控制敌意继续上升，但节目判断高层互动本身主要是象征性的，军事沟通渠道恢复也可能随时再次中断。
- 气候、芬太尼等议题会有工作小组推进，但芯片限制没有松动，台湾问题也没有出现节目所期待的实质性变化；相关企业仍应把对美国技术和市场的依赖视为风险。
- 节目还把联合国安理会通过人道主义暂停和援助通道相关决议看作可能的间接进展，认为中美等国的弃权和沟通为这种结果提供了空间，但这不等于冲突已经解决。

### 47:34-01:00:51：民间交往与“希望在人民”

- 与总统会面相比，节目更看重面向四百多家企业和政界代表的欢迎晚宴及其三十五分钟演讲，认为企业、地方和民间交流可能比联邦政府的口头承诺更可持续。
- 主播把演讲概括为“希望在人民、基础在民间、未来在青年、活力在地方”，并将其解读为在联邦政府互信不足的情况下，把长期工作重心放到人民、民间组织、青年和地方合作上。
- 演讲采用美国听众熟悉的个人故事和具体经历展开，同时说明相互尊重、和平共处、合作共赢等原则，并介绍中国对共同发展和富裕的理解；节目认为这种完整表达本身就是重要的交流成果。
- 这并不意味着中美关系会立即缓和。节目最后将此次会面概括为“止跌”而非全面转向：实质性限制没有消失，但风向稳定和民间交往仍可能带来后续连锁反应。

### 01:00:51-01:14:55：阿里云故障、鉴权单点与组织管理

- 阿里云最近一次故障几乎影响全线业务，语雀此前也曾长时间中断；节目提到这次影响面很大，但恢复速度约为两小时级，仍低于主播对阿里云“一分钟定位、五分钟解决”的宣传预期。
- 节目根据内部反馈猜测，故障可能涉及身份认证模块中的白名单：不在白名单内的请求会在检查正常账号密码之前直接被拒绝，从而影响访问阿里云资源的各种应用和 API。
- 云服务把功能封装成大量 API，调用来源包括内部管理系统、外部客户和淘宝等大型业务，因此鉴权 API 很容易成为单点故障。鉴权同时要求高并发、强一致和高可靠，分布式冗余、负载均衡和容灾可以做，但逻辑复杂、设计成本很高。
- 更合理的容错方式应是在更新白名单失败时保留旧版本、发出告警并继续提供有限服务，而不是生成不完整的新白名单，导致大量请求被拒绝。节目认为这类核心逻辑应依靠专家代码评审和充分验证发现问题。
- 频繁故障是否与组织重构、人员变化和管理问题有关只是主播的猜测。阿里云停止整体剥离上市时给出的云与人工智能一体化解释，也被节目认为未必是全部原因，团队受到剥离过程影响的判断同样没有得到确认。

### 01:14:55-01:24:27：从大学课程吐槽到实践式学习

- 一名优秀大学生批评大学课程把“科学上网”等主题讲成定义、历史、人物、分类和宏大理论的堆叠，最后却只留下具体软件模式的考试题；节目认为这种教学花费一学期，仍可能不如短视频中的八分钟实践讲解有效。
- 节目把问题概括为“看似全面、实际上没有落地”：不少人文、理工科课程都重理论叙事、轻实践和问题解决，学生因此难以形成真正可用的能力。
- 主播不反对基础知识和学科史，大学也不应退化成只教操作的技校；更好的顺序是先用当下案例、文献、视频、新闻或实验激发兴趣，再提出问题、导入理论，最后让学生理解知识如何发展到今天。
- 嘉宾提到一所中学曾采用“材料和实验、思考题、理论”的教学改革，但据家长转述，这种改革只覆盖了孩子所在的一届，后来因投诉等原因停止，升学和考试压力被认为可能是影响因素。
- 好老师的职责不只是把教材讲完，而是设计让学生感到有趣、舒服并愿意继续学习的路径；引导学生学会自学，尤其要帮助那些愿意学习但暂时不得其法的人。

### 01:24:27-01:34:18：教师激励与开放教育

- 大学教师往往是本专业的研究高手，却未必接受过教育训练；节目进一步认为，问题的根因可能是激励机制，因为科研成果直接影响教师发展，而认真教学未必得到相应回报。
- 只照着课本或 PPT 念，甚至用文字转语音代替讲课，说明教师没有把学生当成需要服务和赋能的用户。遇到学习困难的学生时，简单说“大学生要学会自学”并不能替代教学设计。
- 节目借足球的类比提出一种体制外推进方式：不再期待整个大学教育体系自行解决所有问题，而是做好优秀、低价、易访问的课程，推广 B 站等平台上的高质量内容，让学生从好老师和真实技能中获得收益。
- 学生可以先保证及格、毕业和拿到证书，同时根据未来工作需要寻找经验和技能；开源教育联盟可以把行业内容带到学校，愿意尝试的地方学校也可以参与教师培训和课程合作。
- 网络学习资源质量不一，因此数字时代更重要的教育目标是教会学生多试多练、自己验证结果、进行事实查证并提升鉴别能力。节目最后把这种从民间、青年和地方开始的积累，视为避免优秀学生被低效课堂消磨的现实路径。

## 核心观点

1. 面对公司治理、国际关系和热门技术新闻，应把确定事实、象征性信号、主播判断和未经证实的猜测分开，不能用单一叙事填补信息空白。
2. 平台开放与用户安全并不是简单的二选一。侧载、签名、权限和警告机制需要一起设计，既让用户获得选择，也要降低普通用户被恶意应用伤害的风险。
3. AI 产品的价值不在于更换基础模型名称或赢得一个榜单，而在于技术突破、真实用户数据、领域场景和可验证的附加价值；评测结果必须结合方法和使用情况判断。
4. 高可靠系统需要在部分数据失效时保留旧状态、及时告警并限制损害范围。复杂的 CAP 权衡不能成为放弃容错设计、专家评审和组织复盘的理由。
5. 教育的有效性来自实践、问题、理论和反馈的闭环。正规机构如果受课程设计和激励机制限制，开放课程、行业社群、青年参与和地方合作可以提供补充，但也必须同步培养事实查证和数字鉴别能力。
