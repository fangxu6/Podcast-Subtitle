# 第163期 考还是不思考

- 来源：`transcript-site/episodes/ep-163.html`

- SRT 条目：2557
- 阅读段落：191

## 内容摘要

本期先追踪中美贸易接触后的阶段性结果，讨论关税对等关系、稀土管制和美国进一步收紧对华芯片限制的计划。节目认为，这不是一次谈判就能结束的短期冲突，而是围绕全球贸易、技术和金融秩序的长期博弈；中国需要继续发展自己的芯片和开源模型，同时等待美国政策和国际市场的实际反馈。

节目随后解释印巴空战中数据链、预警机、雷达、导弹和动态组网如何组成现代作战体系，并回顾中国从 1990 年代军事转型到近年军改和装备发展的过程。之后讨论协和医院“4+4”医学培养争议的阶段性调查结果，以及利用 NPM 依赖和 AI 编程工具诱导自动安装恶意软件包的新型供应链攻击。

后半段围绕“考还是不思考”讨论推理模型、思考链、Web Coding 和 AI 的过度依赖，再分析教育部发布的中小学人工智能通识教育和生成式人工智能使用指南。最后推荐《山茶文具店》《这就是 ChatGPT》和《黑客：计算机革命的英雄们》，分别从人与人之间的表达、大模型原理、开源和黑客伦理延伸到 AI 时代的教育与技术文化。

## 时间线

### 00:00-26:22：中美贸易接触与芯片限制

- 中美第一轮贸易接触后，美国把对华关税暂时退回到 4 月 2 日的状态。节目解释，新增的 10% 是双方对等保留的部分，另一部分美国关税来自此前以芬太尼为理由加征的措施，中国也针对大豆、皮卡等美国重点商品采取过对应反制，不能简单说成“10% 对 30%”。
- 稀土管制并没有取消，只是部分新增的非关税反制措施暂时暂停。中国同时召集相关部委和主要稀土产区，继续建立对战略矿产生产、流通和销售的长期管制网络。
- 节目批评“必须速胜、否则就是失败”的舆论心态，认为大国博弈更可能通过持续积累一系列小优势来完成，而不是靠一次战略赌博迅速击垮对手。
- 美国商务部下属 BIS 准备收紧芯片出口规则，甚至试图限制相关国家使用华为芯片训练 AI，或使用美国芯片训练和推理中国大模型。节目认为这体现了美国争夺第三方市场的意图，但最终效果仍取决于中国芯片和模型的性能、价格与开放程度。
- 中国的应对方向是继续发展自主芯片和开源模型。若华为芯片和国产模型在性价比上形成明显优势，其他国家可能不会长期服从单纯的政治禁令；真正的竞争仍要回到产品能力和市场选择。

### 26:22-40:31：数据链与现代超视距空战

- 数据链可以理解为战区内的局域网，把战斗机、舰艇、地面部队、指挥中心和卫星等作战节点连接起来，但它拥有独立的协议、硬件和安全体系，各国标准并不相同。
- 现代军事数据链首先要求极低延迟，因为目标和导弹高速运动；同时要在复杂电磁环境下抗干扰，并通过特殊频段、跳频、加密等方式保持通信。
- 战场网络还需要动态组网和快速重构。某个路由节点被摧毁后，其他节点应能自动寻找替代路径恢复网络，因此需要硬件、软件和设备互通的一体化能力。
- 预警机或地面雷达发现目标后，可以通过数据链把信息传给战斗机和导弹；霹雳-15等导弹在末段开启主动雷达，自主识别和攻击目标，降低最后关键距离对外部链路的依赖。
- 节目认为，印巴空战的意义不只在击落数量，而在于它提供了一个观察现代体系作战的案例：预警、雷达、数据链、算法、训练和组织协同必须同时有效，单件武器的参数不能代表完整战力。

### 40:31-45:45：协和“4+4”调查进展

- 节目回顾协和医院“4+4”医学培养争议的阶段性调查。卫健委公布的结果认为，网络上关于主要当事人家庭和履历的部分传闻存在虚假内容，但核心关系和违规问题基本得到确认，两名主要当事人受到现行体系内较严厉的处罚。
- “4+4”培养体系涉及教育部，因此卫健委的阶段性通报没有直接给出最终结论，只指出在录取资格、实习管理、学位论文答辩和学生思想教育等方面存在问题，并表示将会同教育部等部门继续调查。
- 节目认为，通报把已暴露的问题主要归到协和医院，同时提到该体系曾获教育部批准，因此后续是否取消、整改或继续保留，仍要看更完整的调查和责任认定。
- 这一事件说明，在网络舆情形成足够规模后，处理方式可能不再是象征性处罚，而会继续追查制度、管理和相关人员的责任；但节目也强调，阶段性结果不等于全部事实已经结束。

### 45:45-52:40：AI 编程工具与 NPM 供应链攻击

- 有人利用 NPM 生态上传名称自然、看似正常的恶意软件包，再利用 Cursor 等 AI 编程工具倾向于自动执行和安装依赖的特点，诱导模型把恶意包加入本地项目。
- 这种攻击同时利用两类弱点：大模型可能无法核实软件包是否真实、是否可信；NPM 对包作者和包来源的验证较宽松，复杂的多层依赖链又让恶意代码更容易隐藏和快速传播。
- Web Coding 把更多流程交给 AI 自动完成，减少了人工确认，因此一旦模型被误导，恶意依赖可能在用户没有充分意识的情况下进入项目。AI 的便利不能替代依赖审核、来源验证和运行隔离。
- 节目认为，JavaScript 和 Node.js 生态的包数量及依赖碎片化加重了风险。前端项目尤其容易追求“能跑就行”和快速引入新包，开发者仍需要补足安全、工程质量和依赖管理意识。

### 52:40-01:05:21：推理模型、思考链与 Web Coding

- DeepSeek R1 出现之前，推理模型虽然已经能在逻辑问题上表现更好，但因为更慢、更贵、消耗更多 token，市场更偏好快速回答。R1 展示了高质量思考链，也把“观看模型思考过程”变成了一种新的使用体验，推动用户和厂商拥抱 reasoning 模式。
- 千问 3 的 hybrid 模式尝试让模型根据任务在推理和非推理之间切换。节目实际采用了一个前置判断：先让模型评估问题复杂度，再决定是否开启深度思考，以降低不必要的成本。
- 推理模型适合需要长逻辑链的任务，并不适合所有场景。Claude 等工具如果让模型在工具调用失败后自动启动深度思考，可能会进一步推动完全交给 AI 的 Web Coding，而不是由人控制节奏的 AI assistance。
- 更长的思考过程也可能让模型更迎合用户，甚至把“如何不刺激用户”当成思考内容；同时，复杂系统会出现设计者未预料的用法。节目认为 Web Coding 可以作为探索，但不应在不透明的成本和风险下无限放任。
- RAG 等信息获取能力可以补足模型的知识缺陷，思考链则有助于维持长逻辑链，两者被节目视为弥补大模型固有短板的重要方向。

### 01:05:21-01:28:45：中小学 AI 指南与考试评价

- 教育部发布《中小学人工智能通识教育指南》和《中小学生成式人工智能使用指南》，分别回答学校如何教 AI、学生和教师如何使用 AI。使用指南把场景分为促进学生成长、辅助教师教学和支撑教育管理三类，节目认为其中的应用建议较具体、较可靠。
- 通识教育指南相对宏观，提出了方向，却没有充分解决师资、教材和课程实施的问题。学校、教师、家长和学生都面临 AI 对作业、教学和评价带来的冲击。
- 指南提出避免学生过度依赖生成式 AI，并明确禁止直接复制粘贴 AI 内容完成作业和考试。但目前很难可靠识别生成内容，单纯追查作弊证据可能增加教师负担，也难以得到确定结论。
- 节目的替代思路是改变作业和考试：设计允许使用 AI、但仍能评价产品创意、过程判断、实现质量和最终效果的任务。大学专业课更容易采用这种方式，中小学基础教育因为承担知识、逻辑和方法训练，难度更高。
- 个性化学习需要区分目标多样化和路径多样化。路径可以不同，但仍需达到明确的课程目标；如果课程目标本身过时，就应重新设计，而不是用个性化学习掩盖评价标准的问题。
- 教育部门现在推进 AI 是因为使用趋势已经无法阻挡。短期最重要的工作不是消除所有风险，而是提高大面积中小学教师的数字素养，给出可操作的安全边界，并通过先行案例逐步改进。

### 01:28:45-01:42:00：《山茶文具店》与代笔的情感表达

- 《山茶文具店》又名《镰仓代笔物语》，讲述镰仓一家代替他人写信的文具店，以及回乡继承这项传统的第十一代店主鸠子。
- 代笔并不是简单把别人说的话写下来，而是要理解委托人的情绪、收信人的处境和一封信应该产生的效果。书中从宠物去世的慰问信，到离婚后写给婚礼宾客的通知，都展示了人与人之间难以直接表达的心情。
- 纸张、字体、墨水、笔和信封等细节，都是为了准确传递一份心意。节目认为，这种对表达媒介的讲究体现了日本式的工匠精神，也让读者理解不同形式如何影响情感沟通。
- 节目同时推荐日剧改编版，认为电视剧通过演员表演、人物关系和真实呈现的书信文字，补足了小说中部分不够明确的情节。续作《闪闪发光的人生》围绕婚后家庭关系展开，节目认为不应简单用“恋爱脑”等标签否定其中的情感逻辑。

### 01:42:00-01:54:17：《这就是 ChatGPT》

- 《这就是 ChatGPT》的作者是 Stephen Wolfram，他还写过《一种新科学》《万物皆计算》，并创立了 Mathematica 和 Wolfram 语言相关体系。
- 书的第一部分用较短、通俗的篇幅解释概率、模型、神经网络训练、嵌入、Transformer 和 ChatGPT 的基本原理，适合没有相关基础的读者入门。
- 第二部分把 ChatGPT 与 Wolfram 过去的符号推理、Wolfram Alpha 和知识引擎联系起来，有读者认为作者存在为自己的系统“带货”的倾向；但节目认为，这也提供了理解科学家如何探索 AI 推理路线的历史视角。
- 节目认为这本书不会因为模型快速发展而立刻过时。理解模型背后的基本范式，有助于更好地使用 AI、设计领域工具，也能帮助教师思考课程、作业和评价应如何与 AI 结合。

### 01:54:17-02:06:59：《黑客：计算机革命的英雄们》

- Steven Levy 的《黑客：计算机革命的英雄们》记录了三代计算机先驱：20 世纪 50 年代的 MIT 大型机黑客、70 年代推动个人电脑诞生的硬件黑客，以及 80 年代的游戏开发者。
- 书中“黑客”指技术高超、热衷创新的人，与从事破坏和黑产的 cracker 不同。新版后记补充了开源运动和新一代技术人物，也帮助读者用更现代的视角理解早期黑客文化中技术理想与无政府主义倾向并存的复杂性。
- 黑客伦理包括信息自由流动、计算机应服务大众、反对权威和垄断、去中心化，以及通过动手实践获得真实知识。这些信念后来影响了开源、创业和 Maker 文化。
- 节目认为，理解这段历史有助于看清互联网和开源理念的来源。曾经代表信息自由和计算机普惠的美国，今天却可能把这些理念视为安全威胁；新的技术社会应记住这些价值，也不能把曾经珍视的好东西重新当成垃圾丢弃。

## 核心观点

1. 长期博弈不应被简化为速胜或速败。贸易、芯片、稀土和开源模型的竞争，需要在时间、成本、体系能力和国际关系中综合判断。
2. 现代技术竞争依赖完整系统。数据链需要协议、硬件、软件、训练和组织协同，AI 工具也需要模型、依赖生态、安全机制和人工确认共同支撑。
3. 推理模型可以弥补大模型的逻辑短板，但更长的思考并不自动带来更好的结果，使用者仍要根据任务选择模式，控制成本和依赖。
4. AI 进入教育后，单纯禁止或检测生成内容都不够可靠；更现实的方向是重做作业、考试和过程评价，同时提升教师的数字素养。
5. 开源和黑客文化不仅是技术方法，也包含信息共享、动手实践和服务大众的价值观。理解其历史，才能在 AI 时代判断哪些创新值得保留。
