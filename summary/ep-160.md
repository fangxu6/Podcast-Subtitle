## 内容摘要

本期从“对 AI 说 please 和 thank you 是否浪费资源”的网络段子开始，讨论 AI 拟人化、情感互动和长期记忆。节目认为，随着 AI 越来越像人并且能够持续记住用户，人类很难永远把它当作纯工具；电力和成本是技术发展的代价，真正值得关注的是人与 AI 形成情感关系后的新问题。

随后节目集中讨论 Agent 与 Workflow 的定义之争。OpenAI、Anthropic 将 Workflow 解释为程序员编排的流程，将 Agent 解释为模型自行选择工具和流程；LangChain 创始人 Harrison Chase 反对这种定义垄断，并用功能矩阵比较多个框架。节目认为两者确实有架构差异，但没有必要争论谁更“正宗”，软件仍应坚持模块化、高内聚、低耦合和清晰的输入输出，让 AI 负责适合它的模块。

后半段讨论一位北美华人视频对美国制度问题的批评、复旦大学的改革设想，以及京东进入外卖市场后与美团的竞争。节目分别关注爆款内容如何抽象复杂问题、大学教师评价如何落地，以及平台利润、骑手安全、客户体验和社会利益之间如何重新平衡。

## 时间线

### 00:00-12:40：AI 拟人化与情感互动

- 节目从 Sam Altman 关于用户对 OpenAI 说“please”和“thank you”的段子谈起，指出原话只是说这些请求会产生数千万美元成本，并没有说这是“浪费”。
- AI 查询会消耗电力、算力和基础设施成本，水冷系统的水通常可以循环使用；把一句谢谢渲染成奢侈浪费，是媒体对段子的标题党式扩展。
- 人类即使知道 AI 没有感情，也会因为交流方式、回答质量和拟人化表现而产生好感。随着长期记忆和用户画像成熟，AI 可能记住用户过去的对话，情感连接会更强。
- 节目认为，AI 作为工具越来越有用、越来越体贴之后，人类很难永远维持纯工具视角；这种变化有风险，但也是技术进步带来的新社会课题。

### 12:40-18:18：Agent 与 Workflow 的定义争论

- OpenAI 发布 Agent 指南后，LangChain 创始人 Harrison Chase 认为其中对 Agent 的定义会造成误导，并反对由模型厂商单方面掌握定义权。
- 一种常见区分是：Workflow 由程序员预先定义流程，流程中的部分节点可以调用大模型；Agent 则只获得工具，模型自行决定调用哪些工具和如何推进任务。
- Harrison Chase 还发布了包含多个框架和多个功能维度的 feature matrix，结果明显偏向 LangChain，引发 PydanticAI 团队创始人 Samuel Colvin 等人的反驳。
- 节目认为，这场争论既是架构术语之争，也是模型厂商、应用框架和生态参与者争夺技术主导权的竞争。

### 18:18-27:47：软件架构中的 Agent 边界

- Workflow 和 Agent 可以区分，但 Agent 的不可控性不等于它总是更先进。模型可能自己调用工具，也可能凭已有知识回答，因此不同模型执行同一任务的结果会更不稳定。
- 软件系统仍然需要模块化、分离关注点、高内聚、低耦合和清晰接口。AI 更适合被放进人类设计的软件架构中的一个模块，而不是独立构建复杂系统。
- 模块大小需要适度：既不能把 AI 的能力切得过细，也不能把超出其能力范围的复杂任务整体交给它。AI 编程工具的实际经验也是由人控制大流程，再把局部步骤交给 Agent。
- 大多数软件产品更需要稳定、可预测的结果；创意写作、绘画和游戏中不重要的支线内容，才更能容忍 Agent 带来的随机性和意外惊喜。

### 27:47-34:51：低代码编排、测试困难与工具依赖

- 面向教师和学生的 AI 应用培训，可以通过低代码 Workflow 让业务人员参与节点、提示词模板、知识库、文件处理、搜索和函数的配置。
- MCP 和不同模型让编排方式更加灵活，但也让同一个应用可能同时存在流程编排、提示词驱动和模型能力驱动等多种实现路径。
- 大模型本身具有不确定性且不断变化，当前还缺少像传统软件那样成熟的测试、评价和最佳实践体系，因此很难稳定判断一个编排方案的优劣。
- 最终用户并不在乎产品被称为 Agent 还是 Workflow，只在乎问题是否得到解决。节目还警惕 AI 编程工具鼓励用户放弃控制、无限消耗 token，并在形成依赖的同时造成技能退化。

### 34:51-45:35：美国华人视频与正确的抽象

- 一位长期生活在北美、现居加拿大的华人发布视频，认为美国人面对国内问题时不应把责任归咎于中国、全球化或外国，而应反思本国制度，因此使用了“美国需要一场革命”等强烈表达。
- 视频因“revolution”等高冲击词汇获得远超其平时粉丝规模的传播。节目认为，爆款内容常通过把复杂问题讲成简单的两三点来提供即时的理解感和情绪价值。
- 简化复杂问题本身就是抽象，关键在于是否抓住了主要因素。特朗普把关税解释为各国会迅速投降并给美国送钱，是忽略现实约束的错误抽象。
- 美国制造业衰退、贫富分化与美国自身政策选择有关，而不是外国强迫美国走上这条路；把这一底层责任讲清楚，则可能是有效的抽象。

### 45:35-52:00：美国是否会走向“革命”

- Mearsheimer 在访谈中基本赞同该华人视频对美国国内问题的批评，这一片段又推动了视频的二次传播。
- 节目区分“革命”和抗议：巴以战争引发的学生运动、军人自焚以及针对医疗保险公司的暴力事件都可以被视为激烈抗争，但并未形成持续的规模性政治行动。
- 对美国人而言，“革命”往往意味着内战和武装斗争，因此大多数人难以接受。即使特朗普试图通过亲信、代理人或宪法争议延续政治影响，真正形成革命仍面临很高门槛。
- 节目借王莽改制作类比，认为特朗普式的快速改革可能制造混乱，但现代国家机器的组织和控制能力也使大规模起义更难发生，是否会出现更深层的政治反弹仍需观察。

### 52:00-01:00:10：复旦大学的三项改革设想

- 复旦大学校长金力院士提出“大手术式改革”，内容包括学科重构、人事改革和人才培养体系调整。学科重构计划降低文科比例，使文、理、医、工、交叉学科大致均衡；这符合整体趋势，但对文科教师规模较大的复旦尤其有挑战。
- 人事改革试图改变“非升即走”和获得长聘后缺少持续激励的问题，不再把阶段性晋升与长期留任简单绑定，并探索长聘之后继续评价、晋升或调整。
- 人才培养改革强调 AI 时代不能只依靠知识记忆，而要培养思维方法、解决问题的能力和更多样的发展路径，减少单一竞争和照本宣科。
- 节目认为这些方向值得支持，但真正的难点不在提出口号，而在如何把评价、课程和组织机制落到日常运行中。

### 01:00:10-01:09:12：大学教师评价为何难以改革

- 科研评价已有论文、期刊、会议和同行评议等相对成熟的制度，虽然不能只用顶刊论文数量衡量教师，也可以通过盲评、随机评审和复现等方式缓解主观偏差。
- 大学教学缺少统一的同行评价范式。听课专家可能评价课堂风格，却未必能判断不同学科的教学内容；学生评价又可能惩罚严格认真、但真正有教学要求的教师。
- 中小学可以参考学生成绩、教材建设和名师听课，是因为义务教育目标相对明确；大学没有统一的标准化考试，专业差异、学校品牌和就业市场都会干扰教学效果的比较。
- 就业率或同专业就业竞争力可以作为间接指标，但跨专业、跨学校比较仍不公平。节目认为改革方向正确，真正效果需要一两年观察，试错本身也比只宣传不落实更有价值。

### 01:09:12-01:20:29：京东进入外卖市场与物流体验

- 京东依靠物流体系进入即时配送和外卖市场，刘强东亲自送餐、与骑手互动，显示出挑战美团和饿了么的认真程度；节目认为这是一场多年未见的大型互联网商战。
- 主持人分享的京东物流体验并不理想，包括延误、临时改约，以及包裹尚未送达却被标记为已送达。节目认为这可能反映部分基层配送节点的管理和 KPI 已经失真。
- 京东外卖早期可选商家还不够多，但实际配送暂时没有明显问题；美团则同样存在骑手赶时间、配送过快和交通风险等问题。
- 美团骑手大量采用个人承包式关系，可以降低平台的用工成本；京东以更好的待遇和模式挑战美团，是否能推动行业变化还要看实际执行。

### 01:20:29-01:24:04：平台利润、骑手安全与行业平衡

- 平台鼓励骑手在单位时间内送更多订单，算法把效率转化为公司收益，却可能把时间压力和交通风险转移给骑手；用户通常并不需要把配送时间压缩到极限。
- 节目认为，互联网平台早期获得的高利润应逐步回馈员工、客户和社会，平台不能把骑手当作可以无限压榨的效率变量。
- 一个新模式是否合理，要看骑手、客户和竞争对手是否都能长期接受。京东如果能在合理利润下挑战原有配送模式，可能推动行业改善；如果只是恶性价格和商业竞争，结果就未必正面。
- 最终应在配送服务、骑手报酬与安全、平台利润和社会就业之间形成动态平衡，节目将继续观察这场商战的后续。

## 核心观点

1. AI 越来越像人之后，人与 AI 的关系会超出纯工具关系；长期记忆和个性化会放大情感连接，社会需要正视其中的风险和责任。
2. Agent 与 Workflow 有不同的架构边界，但“更自主”不等于“更先进”。可靠的软件仍需要人类设计模块、接口和整体流程。
3. 抽象是理解复杂问题的必要能力，但抽象必须保留关键现实约束；传播力强的简单答案不一定是真正正确的答案。
4. 大学改革的方向可以明确，落地却取决于能否建立合理的教师教学评价和人才培养机制；无法量化的贡献不能因此被简单忽略。
5. 平台效率不能只按单位时间订单数衡量。骑手安全、合理报酬、客户体验和社会回报应成为互联网平台长期经营的一部分。
