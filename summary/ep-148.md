# 第148期 世界人民大团结万岁

## 内容摘要

本期从 TikTok 美国禁令的临近谈起，重点讨论大量 TikTok 用户意外涌入小红书的现象。原本主要面向中国用户的小红书，因为保留了境外手机和邮箱注册入口，突然成为跨语言、跨国交流的平台。用户分享宠物、食物、家庭和工作等日常生活，在翻译工具帮助下互相提问、开玩笑和提供帮助，节目认为这种具体而平等的交流很像互联网早期的开放氛围。

节目把这次交流称为“新时代的厨房辩论”：人们不再需要政治人物在精心布置的场景里争论制度优劣，而是直接展示自己的生活，让彼此在真实接触中形成判断。讨论也延伸到互联网主权、实名认证、内容治理、平台商业模式和国际化运营。节目对小红书能否长期保留这批用户保持谨慎乐观，认为即使热潮退去，留下的经验、关系和开放方向仍然有价值。

后半段转向大模型应用开发。节目反对把“把一篇文章塞进模型后问答”都称为智能体，严格区分由人预先编排的 workflow 与能自主决定工具调用顺序的 agent，并讨论函数调用、结构化输出和 reasoning 如何让模型从人机界面变成程序之间的接口。最后总结当前应用开发仍处在从玩具走向产品的阶段，标准化不足、推理性能、接口安全和模型对前提假设的稳定处理，都是需要继续解决的问题。

## 时间线

### 00:00-03:20：TikTok 禁令与小红书事件的起点

- 节目先介绍美国 TikTok 禁令可能在 1 月 19 日生效、特朗普将在 1 月 20 日就职的时间背景，并推测拜登政府可能把后续决定留给下一任总统。
- 真正的主话题是大量 TikTok 用户转向小红书。节目把它称为 2025 年初难以预料的“黑天鹅事件”，因为连长期使用互联网的人也没有想到小红书仍然开放境外手机号和邮箱注册。
- 讨论从一开始就把这件事视为一次平台和互联网史上的特殊事件，而不只是短期流量变化。

### 03:20-16:27：跨国用户涌入与小红书的日常交流

- 节目回顾小红书从留学生带货和生活分享社区发展为内容质量较高、信息更新及时的综合平台；TikTok 用户涌入后，原有用户的时间线出现了大量外国用户。
- 让主持人印象最深的是交流氛围：用户尽量友善、守礼、有分寸，并带着对彼此生活的好奇心，像回到了互联网早期的 BBS 和论坛。
- “交猫税”成为跨文化玩笑：美国用户发布宠物照片证明自己已经交税，中国用户则继续分享猫、狗、农场动物和日常生活，幽默降低了交流门槛。
- 交流并不只有轻松内容，也有人寻求法律、政治或身份认同方面的帮助。复杂专业的问题未必能得到回应，但这种主动寻找陌生社会同道的行为本身已经很少见。
- 一些在中国生活多年的外国人因为新用户获得关注而产生失落，也有人用模仿外国人的口吻参与流量，这些现象被节目看作社区互动中的自然玩笑和身份游戏。

### 16:27-25:52：普通人的生活与“天涯共此时”

- 节目不同意把新用户简单理解为来小红书赚钱的 TikTok 网红，认为目前看到的更多是普通人交流生活，而不是成熟网红搬运流量。
- 一位美国单亲母亲分享月亮，中国用户贴出夜空和“但愿人长久，千里共婵娟”等诗句。双方在不同时间区间里实时回应，形成“天涯共此时”的具体体验。
- 主持人认为，过去的互联网常常是中国人聚在中文平台、外国人聚在外国平台，或只能单向阅读国外内容；这次则让不同国家的普通用户真正进入同一个社区互动。
- 机器翻译降低了语言门槛，使这种互动不再依赖熟练掌握外语。节目把它看作互联网早期国际主义理想的一次意外回返。

### 25:52-39:53：从“交猫税”到新时代的厨房辩论

- “交猫税”最初是美国用户对“中国间谍”说法的反讽：既然政客说中国软件会收集数据，就用发布猫照片的方式开玩笑说自己已经交了使用平台的税。
- 小红书上的中美用户还会互相做题、分享食物、讨论工作和收入，围绕小众游戏、宠物、农场动物和职业生活展开具体交流。话题不宏大，却因此更接近真实的人际接触。
- 节目将此与冷战时期尼克松和赫鲁晓夫的“厨房辩论”比较：当年的政治人物在样板房里展示各自的生活制度，如今普通人可以直接把自己的生活发到网上，不必由政治人物代为表演。
- 节目认为，新时代不必执着于争论谁赢过谁。只要人们能看到对方真实的生活，发现同一个世界存在多种合理的生活方式，就已经是有价值的交流。

### 39:54-49:42：互联网主权与平台国际化

- 节目从小红书面对外国用户的实名认证问题出发，讨论中国平台原有的手机号码、身份证和网证等用户追踪机制如何适用于境外用户。
- 节目转述《人民日报》评论部文章“国之交在于民相亲”的表述，认为它释放的信号不是短暂欢迎外国人做客，而是把交流理解为不同国家人民可以共同生活、长期互动的可能性。
- 主持人借自由女神像及其欢迎移民的诗句，讨论美国早期以开放和制度自信吸引全球人才的形象，并认为今天的小红书事件也让中国有机会展示一种开放的国际平台形态。
- 与其把国际用户分割到一个专门的海外版本，节目更希望小红书把这次机会作为试验田，在解决认证、监管和商业模式后，逐步发展为真正的国际化社交网络。

### 49:43-58:22：短期热潮、长期痕迹与平台利益

- 对“这件事长不了”的判断，节目区分了用户热度和历史影响：外国用户可能在新鲜感过去后减少使用，但不代表他们会删除账号，也不代表这次交流不会留下关系和记忆。
- 节目认为小红书获得的流量未必能直接转化为商业收益。原有的内容、用户和变现路径主要面向中国市场，如何服务新用户并形成新的商业模式仍需要设计。
- 与其他中国互联网公司先为海外市场另做产品不同，小红书原本是为中国用户设计的平台，却意外具备了国际化潜力，并因此开始补充翻译等功能。
- 节目不把“讲好中国故事”理解为必须由中国人单向讲述，而是认为外国用户也可以根据自己的经历讲述中国平台和中国社会；即使事件短暂，也可能留下真实的口碑和传播。

### 58:22-01:09:58：监管边界、开放治理与“网络护照”

- 节目反驳“外国人能访问小红书、中国人却不能自由访问某些美国平台，所以这是双标”的说法，认为两者应放在各自的互联网主权和监管要求下比较，尤其要与 TikTok 在美国的待遇对照。
- 讨论承认中国网络空间存在明确禁区，例如违法内容和部分政治表达，但认为未来的治理可以把允许与禁止的边界说得更具体、更清晰，而不是只依靠笼统封闭。
- 节目担心有人故意发布有害内容来制造“看，中国什么都不能说”的叙事，同时也认为不能因为存在风险就拒绝所有开放。更可行的方向是提高自我保护和治理能力，再逐步扩大交流。
- 主持人设想以网证、网号或类似签证的方式，为外国用户提供有期限、可延续的跨平台身份。这个设想需要处理违规、间谍和安全风险，但与单方面免签一样，不能因为存在风险就完全不尝试。
- 节目总体判断，这次事件的方向值得持续观察，平台和监管部门真正需要解决的是如何服务正常用户、管好恶意行为，以及把偶然开放变成可复用的制度能力。

### 01:09:58-01:16:44：从“智能体”滥用到 workflow 与 agent

- 节目宣布后续会持续关注大语言模型应用开发，认为模型本身短期内会稳定提升，真正值得观察的是围绕模型构建的应用、工具和工作方式。
- 目前“智能体”一词被严重滥用。把一篇文章放进模型后进行针对性问答，本质上只是给模型增加上下文，不等于具备自主行动能力的 agent。
- 节目采用 Anthropic 文章中的区分：workflow 是由人预先决定子任务和调用顺序的工作流或自动化；agent 则拥有多个工具，并由模型自己决定如何调用和串联这些工具来完成任务。
- agent 的重要变化在于，模型不再只是人与机器交互的自然语言界面，还要成为程序之间可以调用的接口，并能够与其他程序互相协作。

### 01:16:44-01:25:13：Agent 框架、Phidata 与 Smart Agent

- 节目介绍 Phidata 这类开源 agent 开发框架，强调平台中立、支持本地模型、社区响应快、设计相对简洁等特点，并以一次 issue 在约 48 小时内得到修复为例说明活跃社区的价值。
- 讨论中的 Smart Prompt 目标是用同一套可编程、带参数的提示词调用不同本地或远程模型；下一层 Smart Agent 则要把模型与数据库、互联网、本地文件和特定文件格式连接起来。
- 理想的 agent 不只是串行调用输入输出，还应能并行执行、自己优化流程，并进行质量检查和评估。主持人因为反复琢磨接口是否顺手，宁愿慢慢设计，也不愿直接照搬不满意的抽象。
- 节目认为，模型应用从聊天机器人走向 agent，核心是支持程序间交互。好的接口应让开发者能够自然地把各种输入输出能力组合起来。

### 01:25:13-01:34:57：工具调用、结构化输出与应用开发难点

- 函数调用（tool/function calling）让模型能够选择天气、搜索、金融数据等外部工具，并根据工具名称、用途和参数说明决定是否调用；这要求模型具备一定的程序员式规划能力。
- 结构化输出让模型返回 JSON 或其他对象，而不只是自然语言。对象可以直接交给下一个模型或程序使用，是建立程序间接口的重要基础。
- Reasoning 可以把开放问题拆成多个子任务，结合工具调用、数据模型和搜索，形成可执行的推理流程。节目以查询股票信息、搜索新闻并输出建议的任务说明这种组合方式。
- 当前的主要障碍包括厂商之间缺乏标准化、不同模型接口故意保持差异、复杂任务导致推理时间和调用成本快速上升，以及 MCP 等扩展接口连接本地数据库和外部数据后产生的权限与安全问题。
- 节目认为，未来可能需要让较小的专用模型负责规划和推理，让工具调用更高效，再由成熟模型完成摘要；但这仍处于早期探索阶段。

### 01:34:57-01:42:35：稳定世界观与大模型应用的下一步

- 讨论提出一种“先暴露模型前提假设，再由人纠正”的提示词方式：模型先说明已知事实和假设，人确认或修正后，模型再继续任务。
- 这种做法暂时无法完全交给 agent 自动完成，因为模型对同一个问题的假设可能不稳定，人为纠正的权重和持续效果也不确定，更接近模型微调或使用技巧，而不是普通 agent 编排。
- 节目把更深层的问题称为让模型形成“稳定的世界观”：在小领域中可以通过规则、检索或微调建立相对稳定的公理体系，但领域一旦扩大，人类自己也没有一套覆盖所有问题的稳定世界观。
- 本集总结认为，大模型应用的方向已经比较清晰，包括更好的内容整合、工具调用、结构化输出和自动推理，但标准化、性能、小型化和安全仍是产品化的主要障碍。
- 目前这个领域正处于从“玩一玩”走向商品化之间，感兴趣的人可以开始使用和构建框架，在实践中理解问题，而不必等到技术完全成熟后才入场。

## 核心观点

1. 跨国交流最有力量的部分往往不是正式的制度辩论，而是普通人展示自己的生活，并在具体互动中发现彼此的相似与差异。
2. 开放平台并不等于没有治理。真正可持续的国际化，需要同时解决用户认证、内容边界、数据安全、违规处置和商业模式。
3. “智能体”不能成为所有大模型应用的营销标签。由人固定编排的 workflow 与由模型自主选择工具和路径的 agent，在能力和架构上是不同的东西。
4. 大模型应用要从聊天走向程序协作，函数调用、结构化输出和推理能力是基础，但跨厂商标准、性能效率与接口安全仍未成熟。
5. 面对技术变化，尽早通过真实项目试用和构建，比等待一个完全稳定的标准更能帮助开发者形成判断；同时必须保留人工校验和对前提假设的审查。
