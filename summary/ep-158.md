# 第158期 美元霸权与世界未来

## 内容摘要

本期前半段从 Llama 4 的发布和开源模型竞争谈起，讨论模型规模、性能、许可证和社区期待；随后介绍 Google Cloud Next 2025 发布的 Agent Development Kit、Agent2Agent 协议和 Firebase Studio，并讨论 Agent 之间的发现、描述、连接和互操作为何比 Agent 内部实现更值得标准化。

节目还介绍了 2050 大会中关于 AI 时代家庭教育的团聚活动，并回顾甲亢哥的中国行，重点讨论城市接待外国游客时如何在商业推广与真实待客之间取得平衡。后半段回到特朗普关税政策，节目将其放到全球化、美国优先和美元霸权的长期竞争中分析。

节目认为，美国试图通过关税、制造业回流和超长期国债同时解决贸易逆差、财政债务与产业衰退，但这些方案都受到现实约束。围绕布雷顿森林体系、特里芬两难、美元输出和美国国债的讨论，节目把关税战解释为国际格局和美元体系变化的表象，并进一步讨论中美脱钩、中欧贸易、中日韩合作和美国制造业回流的可能性。

## 时间线

### 00:00-12:56：Llama 4 与开源模型竞争

- Llama 4 发布后，社区反馈并不热烈。模型采用大规模 MoE 架构，整体参数量很大，但实际测试中的性能没有明显超越 DeepSeek、千问等更小的模型。
- 发布初期还出现了推理引擎兼容问题，导致部分测试结果异常；关于刷榜、内部团队和科研方向的传闻很多，但节目区分了可验证的模型表现与未经证实的内部消息。
- 节目认为，开源模型社区真正期待的是更小的模型、更高的本地运行效率、更强的实际能力，或者公开具有说服力的新技术，而不是单纯堆大参数。
- Llama 4 的许可证仍不够开放，在性能没有形成明显优势时，限制较多的许可证会削弱开发者使用和再创作的意愿。节目期待千问 3 以更好的性能或开放程度形成差异化。

### 12:56-41:23：Agent Development Kit、A2A 与 AI 标准

- Google Cloud Next 2025 发布了 Agent Development Kit（ADK）、Agent2Agent（A2A）协议和 Firebase Studio。ADK 是用于开发 Agent 的 Python 框架，但初期实现较多依赖 Google 自己的模型和环境。
- A2A 的核心是让不同网络节点上的 Agent 能够发现彼此、读取 Agent Card、了解服务能力和调用端点，再完成连接、数据交换和协作。Agent Card 可以描述 Agent 的用途、能力和调用方式，未来还可能发展出 Agent 目录或 Hub。
- 节目认为，A2A 所解决的是跨节点 Agent 互操作问题，重要性可能高于 Agent 内部如何调用模型和工具。传统的软件服务也不要求调用方关心服务内部使用哪种语言或框架，只要接口稳定、协议兼容即可。
- 大模型与传统软件模块之间的互操作，关键在于结构化输出、类型检查和标准化 Function Calling。模型具有概率性和不确定的理解能力，因此必须用清晰的数据格式和容错机制约束它。
- 节目批评 MCP 等协议在 Agent 内部调用层面过于复杂，认为不同抽象层需要不同程度的约束：函数调用应严格，Agent 之间的协作可以更宽松，Agent Card 甚至可以只是自然语言形式的能力说明。
- 国内 AI 标准建设需要形成标准族，并同时提供开源参考实现；但标准要获得生态影响力，通常需要有大厂牵头或至少提供足够的号召力。节目认为，未来真正有商业价值的方向可能是 Agent 商店、Agent Hub 和可复用的 Agent 服务。

### 41:23-49:08：2050 大会与 AI 时代的家庭教育

- 节目介绍 2050 大会中关于 AI 时代家庭教育的团聚活动，参与者包括教育从业者、AI 工作者、儿童心理与成长领域人士以及普通家长。
- 讨论重点不是简单增加新的培训班，而是思考 AI 时代孩子需要什么能力、哪些教育可以延后、哪些旧有能力可能不再重要，以及家庭如何理解和应对这些变化。
- 节目提到相关教育机构长期重视儿童通识教育和体育活动，例如登山、露营和橄榄球，认为身体活动和全面成长也是教育的重要部分。
- 2050 大会的价值不在于预设好的嘉宾待遇或确定结果，而在于开放、混杂的交流中可能出现意外的想法和连接。节目也提醒参与者降低期待，把它当作探索性的聚会。

### 49:08-01:00:42：甲亢哥中国行与城市待客

- 节目回顾甲亢哥在中国多个城市的直播旅行，认为上海、北京、成都、重庆、深圳以及少林寺附近的经历，各自呈现了不同的城市气质和社会生活。
- 节目重点批评长沙接待甲亢哥时过度把游客当作流量工具，安排路线、制造场景和进行宣传，却缺少真实交流和自然的待客感，因此损害了城市形象。
- 香港街头追星式围观让节目感到不适，但一位绍兴女孩在船上的自然交流成为香港行程中最好的片段。节目认为，平等、随意且不带剧本的互动，反而更容易产生真实的文化交流。
- 商业推广本身并不一定有问题。深圳的企业参访、民间美食推广等活动，只要明确说明目的并保留真诚交流，就可以同时完成宣传和待客；问题在于把人完全当成工具。
- 节目把待客理解为展示一个地方更好的那一面，而不是只追求眼前的流量收益。地方文化和城市自豪感如果被短期商业化消耗，反而会丢掉最值得展示的内容。

### 01:00:42-01:12:22：全球化体系与美国“朝贡体系”

- 节目把关税战提升到国际格局层面，比较两种未来：一种是资本、人才和生产资料跨国流动、通过 WTO 等机制协调的全球化体系；另一种是美国优先、其他国家需要帮助美国解决财政、产业和科技问题的美国中心体系。
- 节目将后者称作“美国的朝贡体系”，认为它要求其他国家不能在科技和财富上超越美国，同时要为美国的内部问题承担成本，因此对多数国家并不友好。
- 节目认为，很多国家并不是愿意接受美国体系，而是缺乏公开对抗美国的实力和空间。欧洲、日本、英国、西班牙、韩国和东南亚国家仍在寻求与中国保持沟通，不能简单地把它们都看成美国阵营。
- 节目判断特朗普的策略不是明确的长期计划或短期计划，而是先制造巨大的威胁和恐慌，再根据各国反应随机施压、谈判和获利。中国迅速反制超出其预期，说明这种虚张声势并不能保证结果按照美方设想发展。

### 01:12:22-01:19:35：制造业回流、关税收入与超长期国债

- 节目把特朗普政府想解决的问题概括为财政和贸易逆差、制造业萎缩以及国内分配不均带来的政治不满，其中多个问题都与“缺钱”有关。
- 一种设想是用关税威胁企业把工厂迁回美国，同时把关税收入用于产业政策和国内支出。但节目认为，关税收入从数百亿美元快速增加到数千亿美元，需要极高税率和持续进口，现实中会受到供应中断、价格上涨和需求下降的限制。
- 另一种设想是迫使其他国家把到期的美国国债换成 50 年或 100 年期的超长期债券。节目认为，这种债券在历史上依靠领主与本地利益共同体之间的强制关系才能销售，很难要求外国债权人接受。
- 通过关税吸引制造业回流也可能只是把过去的经验机械套用到今天。现代供应链包含大量跨国中间产品，即使把最终组装厂搬到美国，也无法立刻摆脱对海外零部件和材料的依赖。

### 01:19:35-01:33:44：美元霸权、布雷顿森林体系与特里芬两难

- 美元同时是美国的主权货币、全球储备货币和国际贸易结算货币，这种“三合一”的地位使美国必须向世界提供足够多的美元流动性。
- 二战后的布雷顿森林体系选择了美元与黄金挂钩的方案，而不是英国提出的超主权国际结算货币方案。美国的经济和军事优势是美元方案被接受的重要原因。
- 特里芬两难指出，世界贸易增长需要美国通过贸易逆差把美元输出到各国，但美元数量最终会超过美国黄金储备；若美国减少美元输出，全球流动性和贸易又会受到冲击，因此体系存在内生矛盾。
- 尼克松宣布美元与黄金脱钩后，黄金约束被取消，但节目认为美元霸权依然需要美国通过赤字、债务和贸易逆差向世界输出美元。美国国债因此承担了类似过去黄金资产的吸纳作用。
- 美国国债持续增加会带来利息、本金到期和信用问题。量化宽松又进一步扩大了资产负债表和债务规模，使美元体系的结构性矛盾没有消失，只是从黄金兑换问题转化为国债与信用问题。

### 01:33:44-01:42:57：WTO 规则、产能过剩与贸易保护

- 针对“中国没有遵守 WTO 承诺”的说法，节目认为相关承诺曾被 WTO 工作组多次审查，核心争议在于中国作为发展中国家的义务范围，以及中国整体经济实力和人均发展水平之间的不均衡。
- 节目区分“产能过剩”和“倾销”：产能超过国内消费并不等于过剩，只要产品能以有利润的价格出口，就不等于以低于成本的价格抢占市场。真正的倾销是以低于成本的价格进行不正当竞争。
- 节目认为，中国的先进产能如果产品质量好、价格低且能够持续盈利，就属于竞争力，而不是自动构成倾销；但也承认各国在产业路线判断失误时，有阶段性保护本国行业的现实需求。
- 相比高额关税，节目认为最低销售价格等贸易安排更有谈判空间：既能给进口国的本土企业留出调整时间，也不会把关税收入全部交给对方政府。
- 关于 WTO 规则，节目指出争端解决机制因美国拒绝补足法官而运转受阻；中国仍继续提出申诉并进行对等反制，保留了规则框架下的程序路径。

### 01:42:57-01:51:45：脱钩、制造业回流与世界未来

- 美国制造业理论上可以通过长期的国家动员、教育投入、工程师培养和国家实验室建设重新建立，但节目认为现实中很难让社会接受多年成本更高、质量更低的过渡期。
- 节目判断，中美之间的高关税和脱钩可能持续很长时间，企业会通过墨西哥、越南、加拿大等第三地重组供应链，贸易不会简单消失，而会改变路径。
- 节目提醒中国留学生和赴美旅行者关注政策风险，认为人员交流收缩也会成为中美关系恶化的一部分。与此同时，中国可能加强与欧洲、东亚和其他地区的贸易、投资和产业合作。
- 欧洲开始重新讨论中国电动车的最低价格方案，并计划推进中欧峰会；节目认为欧洲虽然受美国影响，但仍希望在中美之间保持一定平衡。中日韩贸易合作的可能性，则取决于日本和韩国能否更现实地处理与中美双方的关系。
- 节目的最终判断是，关税只是表面，背后是美元霸权、产业能力和国际秩序的长期竞争；美国若想同时维持美元霸权、消除逆差、扩大制造业并降低债务，几个目标之间存在难以调和的矛盾。

## 核心观点

1. Agent 生态真正需要优先解决的是跨节点发现、描述、复用和互操作；协议越靠近模型内部越需要严格，越靠近 Agent 间协作越应保持足够宽松。
2. 新技术标准要形成生态，既需要清晰的抽象层次和开源参考实现，也需要有足够号召力的组织或厂商牵头推动。
3. 城市和机构接待外部来访者时，真实交流比把人当作流量工具更能形成长期的文化传播效果。
4. 关税、制造业回流和债务安排并不是相互独立的政策工具，它们都受美元体系、全球供应链、财政能力和国内政治约束。
5. 国际货币体系的优势同时也是结构性负担：美元要作为全球货币流通，就必须不断向外输出美元，而输出美元又会积累美国的逆差和债务。
