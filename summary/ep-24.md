# 第 24 期 要不学点国际法吧

- 来源：`transcript-site/episodes/ep-24.html`
- 时长：01:38:48
- SRT 条目：706
- 阅读段落：131

## 内容摘要

节目从佩洛西访台引发的台海和中美关系紧张谈起，说明为什么历史、心理学、群体行为和国际法等社会科学知识，会影响普通人理解国际新闻。主播先用历史周期和历史类比提醒听众：只看表面相似性，容易把一个国家过去的行为机械套到另一个国家身上。随后以国家的构成、政府的代表性、主权和九二共识为例，解释国际法中的概念为何比网络讨论里的口号复杂。

节目中段转向 Oracle 的大规模裁员传闻，讨论传统企业数据库为何曾经拥有强大优势，又为何在互联网、大数据、开源数据库和云服务兴起后受到冲击。主播认为，Oracle 的问题不只是某个产品落后，而是企业软件的购买逻辑、技术生态和交付方式都发生了变化；微软能够同时维护传统企业方案并拥抱开放技术，是少数成功完成转型的案例。

最后是三本书的推荐。《故事》讨论编剧结构、人物、情节和打动人心的能力；《挑战知识产权》从历史和经济学角度反思过度保护知识产权，讨论自由软件、copyleft 和 Creative Commons；《后真相时代》则用案例解释故事、数据和论证如何影响判断，并给出减少信息输入、主动求证、积累常识和向不同领域专家求教的防骗方法。

## 时间线

### 00:00-10:00：从台海新闻谈历史与国际法

- 节目以佩洛西访台及其引发的台海局势和中美关系紧张为背景，提出理工科与人文社会科学正在共同影响现实生活，普通人也需要一些社会科学常识来理解国际新闻。
- 主播认为历史学习不能停留在事件表面，而应寻找推动历史变化的内因；只根据过去的结果进行简单类比，容易产生“你强大以后一定会和我一样”的错误判断。
- 国际法被介绍为一种很实用的知识：它能帮助人们理解“国家”“政府”“主权”等日常新闻中经常出现、但含义并不直观的概念。
- 节目把国家的基本构成概括为确定的领土、常住人口、政府，以及与其他国家建立关系的能力；领土争议或多个政府竞争代表权，会使国家地位和对外关系变得复杂。

### 10:00-20:39：主权国家、政府代表与九二共识

- 国际法不同于国内法，世界上没有一个拥有普遍强制力的“世界政府”；国家之间主要通过条约、协议和相互承认建立规则与义务。
- 节目强调，一个国家对外需要有能够代表国家并履行国际承诺的政府，不能因为国内存在权力分立，就对外宣称政府可以被切割成互不负责的部分。
- 关于九二共识，节目区分了共识本身与“一个中国、各自表述”的解释：前者被概括为“海峡两岸同属一个中国、共同努力谋求国家统一”，后者是台湾方面后来提出的表述方式。
- 节目指出，两岸内部协商得到的共识，与中国作为一个主体对外表达主权立场的表述，并不是同一层次的问题。

### 20:39-30:34：台湾问题的主权、治权与国际秩序

- 节目把对外表述概括为世界上只有一个中国、台湾是中国的一部分、中华人民共和国政府是代表中国的唯一合法政府，并区分主权归属和现实治理范围。
- 台湾护照可以在一些国家获得免签或旅行便利，并不自动等于这些国家在官方层面承认台湾是一个独立国家；现实中的旅行安排可能通过双边协议保留弹性。
- 对民用飞机进入争议空域的处理，也显示国际法原则与现实执行之间存在距离。非法进入领空并不意味着可以不经考量地击落民用飞机，军事护航、拦截、迫降和是否引发战争都需要区分。
- 节目认为，国际法本质上与实力政治和国际格局密切相关。美国强调“基于规则的国际秩序”，中国强调“基于联合国的国际秩序”，两种秩序观的差异会影响未来的国际规则。
- 即使现有 WTO、联合国等机制受到冲击，了解它们仍然重要，因为国际秩序通常是渐进变化，而不是一夜之间完全重建。

### 30:34-40:43：Oracle 的衰落与数据库形态变化

- 节目转向 Oracle 的裁员传闻。Oracle 曾长期在企业级关系型数据库市场占据优势，但互联网和大数据的发展带来了分布式、文档型、列式、内存型等新的数据库和存储形态。
- Oracle 的传统强项是高可靠的企业级关系数据库和数据库集群，适合政府、银行、电信、保险等对事务、稳定性和责任归属要求很高的场景。
- 互联网应用的需求不同：电商需要极高吞吐量，在线教育需要记录大量用户行为日志，很多场景并不需要一套昂贵而沉重的传统企业数据库。
- 开源数据库、日志系统、分布式计算框架和云服务逐渐形成完整生态，使企业可以按场景组合技术，不必再把所有系统都建立在 Oracle 的单一产品上。

### 40:43-50:00：开源、云服务与 Oracle 的生态困境

- Oracle 收购 Sun Microsystems 后获得了 MySQL 等资产，也扩张到更完整的企业软件解决方案，但节目认为它在核心技术创新、社区经营和开放生态方面投入不足。
- 大数据和云原生系统不是一个孤立软件，而是由分布式存储、计算框架、日志、监控和云服务共同组成的技术体系；传统厂商只在原有数据库上增加接口，未必能真正融入新生态。
- 微软被认为是转型较成功的案例：它既保留 Windows 和企业服务体系，也基于开放技术搭建新的平台，能够同时服务传统企业和互联网开发者。
- 技术公司的竞争不能只靠过去的品牌和市场地位。真正的创新、服务质量和生态适配，最终会取代只依赖历史优势的产品。

### 50:00-57:07：企业采购逻辑与软件商业模式转型

- 传统企业选择 Oracle，除了技术指标，也因为“出了问题由供应商负责”：采购知名厂商能够降低决策者的个人责任和组织风险。
- 云服务普及后，企业可以从阿里云等平台购买基础设施和配套服务，云厂商的稳定性与责任承诺削弱了传统企业软件的安全神话和采购壁垒。
- 节目把软件相关公司分为传统软件授权公司、软件服务公司和互联网公司，认为三类公司的产品、交付和商业模式不能混为一谈。
- 传统授权软件逐渐转向订阅制和服务捆绑；软件服务公司必须云化、拥抱开放技术并降低迁移成本，才能适应互联网经济。
- 软件行业进入新阶段后，少数非常垂直、与特定工业流程绑定的软件仍可能长期存在，但大多数企业软件都需要重新面对云和开放生态。

### 57:07-69:05：《故事》与打动人心的表达

- 节目推荐 Robert McKee 的《故事：材质、结构、风格和银幕剧作的原理》。主播认为，讲故事的能力不仅用于小说和电影，也影响工作沟通、说服团队和表达真实经历。
- 好的故事不依赖华丽的外在包装，而要先提出受众真正关心的问题和痛点，再给出能够回应这些问题的解决方案；演示文稿也应遵循这一逻辑。
- 书中把剧本规律总结为若干可学习的结构，但这些是原型和模型，不是不可违背的规则。人物与情节谁更重要，也不能简单二选一，书中的观点是“结构就是人物，人物就是结构”。
- 一个常见故事结构是：先建立人物的日常状态，再用激励事件把人物推入陌生领域，逐步增加压力，最后迫使人物作出选择并发生改变。
- 节目特别区分“喜欢角色”的同情与“觉得角色像自己”的移情，认为后者更容易让观众把自己的情感投射进故事，从而真正被人物和叙事打动。

### 69:05-80:10：《挑战知识产权》与自由传播

- 节目推荐复旦大学周义的《挑战知识产权》，作者从经济学和知识产权史出发，反思现行知识产权体系是否总能产生预期的社会效益。
- 书中区分“知识产权”和“与知识有关的权利”：知识工作者对成果的精神权利，以及社会公众分享和继续发展知识的权利，都不应被单一的经济排他权完全覆盖。
- 自由软件被作为不同于传统知识产权的实践案例，节目还讨论了 `copyleft` 的中文翻译和它所包含的许可、允许与鼓励使用的含义。
- 软件具有非竞争性和非排他性，复制成本很低；在这种属性下，过度保护可能限制传播、研究和再创作，开放模式反而可能产生更大的社会价值。
- 节目强调，书中的论证主要聚焦软件领域，读者应结合具体作品、商业模式和创作者权利来理解，不能把结论机械推广到所有知识产品。

### 80:10-84:31：《挑战知识产权》的开放方案

- 节目认为，`copyleft`、自由软件和 Creative Commons 可以把创作者的署名等精神权利，与作品的自由使用、复制、再发行和再创作结合起来。
- 对文字、艺术作品和其他数字内容，保留作者身份与署名，同时允许合法用户在明确规则下使用、研究和传播，可能比全面禁止复制更有利于知识流动。
- 创作者也可以通过个人品牌、广告、出版和其他服务获得收益，作品本身的开放传播不必等同于放弃全部回报。
- 主播把这本书与节目过去讨论的开源、数字版权和内容传播问题联系起来，认为它提供了一个值得继续讨论的理论框架，而不是一套已经解决所有问题的答案。

### 84:31-98:48：《后真相时代》与信息防身

- 节目再次推荐《后真相时代》，用皇家植物园申请公共预算的案例说明，同一组事实可以通过重新组织故事，被表达为“拥有悠久历史的园林”，也可以被表达为“解决全球植物、能源和食品问题的重要科学数据库”。
- 书中讨论故事、数据、语言和逻辑如何影响人们判断，并同时提供两种视角：如何使用这些表达方法，以及如何防止自己被这些方法影响。
- 在信息过多、时间有限、专业知识快速增长的环境里，只要求别人“拿证据来”还不够；还需要了解常见叙事套路，知道哪些事实被突出、哪些事实被省略，以及不同立场如何形成竞争性叙事。
- 节目给出的日常方法是减少不必要的信息输入；真正关心的内容要主动求证；长期积累语言、逻辑、数学、统计和常识；遇到专业问题时向不同领域的专家请教。
- 主播也保留了伦理疑问：理解标题党、选择性叙述和说服技巧，并不意味着自己就应该用它们操纵别人。事实选择与弄虚作假之间的边界，仍需要个人持续判断。

## 核心观点

1. 历史和国际法不是抽象知识，它们帮助人们区分国家、政府、主权、治权和条约责任，避免被国际热点中的口号和情绪牵着走。
2. 国际规则既有法律文本，也受国家力量、执行能力和现实政治影响；理解规则与现实之间的落差，才能判断一项行动的法律可能性和政治后果。
3. Oracle 的变化说明，技术领先不等于生态领先；开源、云服务和新的应用需求会一起改变企业软件的采购逻辑与竞争边界。
4. 故事的价值不只是娱乐。通过问题、冲突、人物选择和移情，复杂事实才能被人理解并产生行动；但故事结构也可能被用来选择性地影响判断。
5. 知识传播需要在创作者权利与公众使用之间取得平衡。自由软件、`copyleft` 和 Creative Commons 提供了不同于全面排他的制度想象，但仍需要具体规则和长期实践。
