# 第 47 期 给大家拜个早年

## 内容摘要

本期是春节前的最后一期节目，三位主播先约定停更一期，提醒听众利用春节陪伴家人、拜访亲友，或者阅读、看动漫和玩游戏，让自己暂时清空大脑、切换上下文。随后从 Creative 创始人去世谈起，回顾 Sound Blaster 声卡、MIDI 音色和早期个人电脑硬件，并讨论专用设备如何在通用 CPU、主板和集成能力变强后逐渐失去市场。

节目接着讨论飞书。主播认可它在会议、文档、任务、多维表格和 API 等方面的完整性与使用体验，但也认为“什么都能做”会造成定位和收费上的困难。To B 产品真正的购买者往往是老板而非普通用户，飞书需要针对个人、中小企业、学校和公益组织做更清晰的产品分层与价格策略；团队规模、研发成本和平台身份体系的复杂度，也会反过来影响商业竞争力。

中段先讨论国产动画《中国奇谭》：传统文化和古代志怪文学被重新组织成现代故事，短篇合集让不同创作者展示风格，而 B 站与上海美术电影制片厂的合作也提供了从选题、制作到二次传播的产业化可能。随后节目批评一篇把“中文编程”包装成民族主义话题的文章，区分了中国人或中国公司主导的编程语言，与仅仅把关键字替换成中文的方案，认为语言的价值应由学习成本、表达能力、维护成本、用户和生态来检验。

最后是春节闲聊：主播分享回家吃饭、见朋友、接种加强针、继续写开源知识图谱，以及构想可在浏览器中执行代码或操作棋谱的互动式文档。节目也谈到文言文编程作为兴趣和教育项目的意义、同时阅读多本书与切换上下文的关系，并建议大家在春节多进行线下活动，与真实的人和世界互动。

## 时间线

### 00:00-10:00：春节停更、声卡与专用硬件

- 节目宣布春节期间停更一期，建议听众陪伴家人、拜访亲友；如果独处，也可以补读想看的书、动漫和游戏，把假期当作清空大脑、切换上下文的时间。
- 三位主播从 Creative 创始人去世谈起，回忆 Sound Blaster 16 等声卡在个人电脑时代的地位。高端声卡内置较真实的乐器采样，能够让 MIDI 音乐和早期游戏的音效明显区别于普通设备。
- 九十年代声卡价格不低，曾经是装机时的奢侈品；但后来声卡功能逐步被 Intel 等厂商集成进 CPU 和主板，独立声卡主要剩下专业市场。
- 汉卡、游戏机扩展卡等例子说明，在硬件能力有限的年代，专用设备可以补足通用设备的短板；当通用硬件性能溢出后，专用工具往往会失去普及市场。

### 10:00-20:04：飞书的体验与平台复杂度

- 飞书原本是字节内部使用的协同办公系统，后来对外提供服务，整合了视频会议、文档、日历、任务、多维表格和其他办公功能；主播团队也长期用它录制节目和管理工作。
- 主播认可飞书的会议质量、录制效果、设备兼容性和相对干净的使用体验，并实际使用其多维表格和 API 构建申请、管理等系统。
- 飞书的问题在于功能过于完整，用户很难用一句话说清它到底是什么；企业如果没有用到大部分功能，就容易觉得价格与价值不匹配。主播以一百多人团队每年可能需要支付十几万元为例说明成本压力。
- 学校和其他组织常常还被迫同时使用腾讯会议、钉钉等平台；飞书在个人、组织和不同企业身份之间切换时也有一定复杂度，身份认证逻辑会增加用户负担。

### 20:04-30:59：To B 产品的购买者与商业策略

- 节目引用关于飞书的报道指出，办公软件通常由老板决策，普通用户的使用体验并不直接决定采购。主播结合自己做企业和政府软件的经历，说明面对决策者时，产品细节往往不如投入产出、国产化、服务能力和组织可靠性重要。
- 华为内部工具对外销售时，“内部和外部使用同一套系统”可以成为说服客户的理由；支付宝和华为早期为学校提供免费服务，则通过真实使用积累用户、数据和品牌影响力。
- 飞书如果要扩大市场，需要针对个人、中小企业、学校和公益组织做产品分层、模块化收费，并提供教育版或公益折扣。单纯把业务拓展到海外，未必能解决产品定位和收费策略的根本问题。
- 关于传闻中的八千名员工，主播认为这一规模可能带来很重的成本压力；研发和组织成本越高，产品越可能被迫提高价格或采取不利于竞争的商业策略，但具体数字仍未经证实。

### 30:59-40:29：《中国奇谭》的创作与平台合作

- 主播认可《中国奇谭》前三集的表现：第一集把《西游记》式的故事与现代职场经验结合，第二集《鹅鹅鹅》借用古代志怪文学并采用更独特的表现形式，第三集则更集中展示动画技术能力。
- 作品中的古典文学、上海美术电影制片厂和早期国产动画记忆，对九零后观众有很强的文化触发；主播也讨论了零零后是否拥有同样的背景积累。
- 节目把《中国奇谭》与《爱，死亡和机器人》对比，认为短篇动画合集的成本和风险更可控，能够让创作者大胆执行创意，也能给此前缺少机会的团队展示自己的风格。
- B 站出资、上海美术电影制片厂参与制片和团队选择，不只是简单地提供资金，还结合数据选择播放顺序，并利用二次创作和传播扩大作品影响力。

### 40:29-47:20：国产动画的产业化可能

- 《中国奇谭》让观众重新发现中国古代志怪小说和传统想象力。作品不必只传递固定道理，也可以保留多种解读，让古老素材在新的形式中重新获得生命。
- 节目认为，单部动画或个别爆款还不能证明国产动画已经具备批量生产能力；真正的产业土壤需要人才和商业价值同时成立，让创作者能够从短片走向更大的商业项目。
- 八集作品如果取得成功，可能带动更多平台和投资者持续制作类似的短篇合集，为年轻导演和动画团队提供试错、成长和获得订单的机会。
- 数据驱动的选集顺序、风格各异的创作团队和二次传播，构成了一种平台与传统制作机构合作的模式；主播希望这种合作能延续，而不是止步于这一季。

### 47:20-01:00:25：中文编程争议与语言评价标准

- 节目讨论文章《中文编程不如英文？》，先区分“国产编程语言”和“中文编程”：中国人或中国公司开发有技术目标的语言值得关注，但把关键字换成汉字并不会自动产生新的编程思想。
- 编程语言最终要被编译器解析为结构和机器可执行的形式，使用中文、英文或其他字符，首先影响的是学习曲线和表达习惯，而不是编译原理本身。
- 主播认为，评价一门新语言更应关注它要解决什么问题、面向哪些用户、表达效率和安全性如何、工程维护成本多高，以及是否有足够资源和生态支撑，而不是争论它是否“够中国”。
- 文章介绍的语言中既有公司主导、目标相对明确的项目，也有个人兴趣项目。后者可以作为学习编译原理和探索表达方式的练习，不必被迫证明自己能够商业化或工业化。

### 01:00:25-01:10:14：文言文编程、ChatGPT 与 DSL

- 文言文编程可以让人从不同角度理解编程语言：它背后仍然包含编译器、解释器和运行时等完整链条，适合作为个人兴趣、开源实践或教育材料，但不适合被包装成普遍的教学方案。
- 主播借 ChatGPT 讨论，机器处理中文、英文和编程语言时，表层字符并不是决定性障碍；只要有足够好的语料和规则，模型就可能学习不同语言之间的转换。不过生成语法流畅不等于事实可靠，也不等于解决了工程问题。
- 对程序员来说，编程语言的重要价值还在于全球开发者之间的协作，以及学习、表达和维护的综合成本。英文成为主流与近代工业和软件生态的历史积累有关，并不只是偶然选择。
- DSL 已经提供了按领域定制表达方式的路径，LLVM 等工具也降低了实现语言前端和编译转换的门槛。因此，真正的创新应落在约束、模型和问题解决方式上，而不只是替换关键字。

### 01:10:14-01:14:34：语言设计与 Go+

- 主播把框架和语言概括为“框架是一种弱语言，语言是一种强框架”：设计编程语言，本质上是在设计一组约束，让人更有效地表达编程目标。
- 语言设计的乐趣在于探索不同约束如何改变表达和实现；如果只是把现有语言的关键字替换成中文，既没有解决新问题，也没有形成真正的技术创新。
- 节目建议对编程语言感兴趣的人先理解编译原理，再尝试设计具有独特目标和约束的语言；做项目之前也要区分自己是在解决工程问题，还是把它当作学习和实验。
- 主播以 Go+ 为例，认可其创作者对编程语言的深入理解、明确而现实的目标和持续投入，同时指出项目能否实现目标，与是否有大量用户认同这个目标是两件不同的事。

### 01:14:34-01:22:53：回家过年、朋友聚会与健康安排

- 主播分享春节计划：回武汉后以吃本地菜、见老朋友和陪伴家人为主，也有人会利用假期补书、玩游戏，或用一顿饭替代过去连续多天的走亲访友。
- 节目比较了不同年代的春节生活：有人选择待在家里使用互联网内容，有人和朋友出门旅行或短住；长假提供了平时不容易获得的集中相处时间。
- 一位主播分享自己准备在上海接种第二剂加强针，也就是第四针，并建议有需要的听众通过当地系统查询预约信息和可接种的疫苗；这属于节目当时的个人经验和建议。
- 主播认为春节不必安排得过满，适当放空、回顾过去一年并想想接下来要做的事，本身就是假期的重要价值。

### 01:22:53-01:27:34：开源项目与互动式文档

- 主播计划继续开发一个基于 Markdown 的开源知识图谱项目，把完成小功能、持续提交代码视为一种重新获得的创造乐趣，并考虑如何向更多人介绍它。
- 另一个构想是在线互动式文档：棋谱可以在页面中实际走动，编程书中的示例可以在浏览器里真实执行，读者还可以填写留白并立即看到结果。
- 这种文档希望采用简单、可扩展的 Markdown 类格式，让文字、棋谱、代码和交互内容共存，并为未来的编程书和知识工具提供基础。
- 主播也谈到同时阅读多本书的问题：专项研究需要集中注意力，但拓展知识面、刺激思考和寻找灵感时，适度切换上下文未必是坏事，前提是能够管理好自己的阅读顺序。

### 01:27:34-01:33:02：烟火、安全与线下春节

- 节目谈到城市长期禁放烟花爆竹后，一些年轻人缺少相关经验；如果未来适度恢复，安全教育和基本常识必须同步补上，不能把危险行为当成节日仪式感。
- 主播把年轻人的春节方式概括为两类：在家依靠互联网度过假期，或与朋友出门游玩、短途旅行。相比过去，今天的出行和聚会条件更丰富，但每个人都可以按自己的兴趣选择。
- 节目最后建议，不论年龄，春节有条件时都应多进行线下活动，与真实的人和世界互动；线上工具随时都能使用，现实中的集中相处机会却并不常有。
- 三位主播提前向听众拜年，希望大家身体健康，能够完成想做的事情或开始新的尝试，并约定节后初八恢复更新。

## 核心观点

1. 专用工具会在通用硬件和平台能力增强后失去普及市场，但专业场景仍可能保留对高质量专用能力的需求。
2. To B 产品既要让实际使用者觉得好用，也要让决策者看见价值；清晰的产品分层、价格策略和组织成本控制，和功能本身同样重要。
3. 传统文化素材只有经过有个性的创作、平台传播和持续商业验证，才可能从单部作品走向可复制的动画产业。
4. 编程语言的价值不由关键字使用哪种文字决定，而要看它提供了什么约束、解决了什么问题，以及学习、协作、维护和生态成本是否可接受。
5. 工具和项目可以持续提升效率，但春节这样的时间也应留给真实的人际关系、身体健康和主动休息。
