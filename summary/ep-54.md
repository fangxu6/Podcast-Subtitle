# 第 54 期 预测未来还是创造未来

- 来源：`transcript-site/episodes/ep-54.html`
- 时长：01:17:45
- SRT 条目：583
- 阅读段落：104

## 内容摘要

节目开场先预告第一期节目一周年的线上互动活动，随后简要讨论硅谷银行暴雷和常温超导。硅谷银行的问题被归因于储户和资产过度集中、加息导致债券资产缩水以及挤兑风险；常温超导则仍处在等待重复验证的阶段，不能因为数据惊人就直接视为技术已经成熟。

节目接着介绍 ChatGPT API 开放后出现的早期应用，包括把电子书自动翻译成中英双语、用 ChatPDF 阅读论文、给小爱同学接入 ChatGPT，以及为视频和开源项目文档生成摘要或问答。这些工具降低了语言和信息处理的门槛，但领域知识问答仍会胡说，知识整理和结论验证不能完全交给模型。

本期主体讨论“如何避免错过未来”，从企业战略研究、开源数据和《三体》的技术爆炸谈到新技术评价模型。主播认为预测只能建立在数据、历史共性和持续迭代上，更重要的是长期投入、亲自做研究并筛选有希望的方向，把未来从等待的对象变成可以参与创造的结果。结尾推荐《江湖丛谈》《中国的知识重建》和《成为人类学家》，分别延伸到消失的民间社会、知识体系自主性，以及职业身份如何在实践中形成。

## 时间线

### 00:00-02:33：周年活动与节目开场

- 节目提到近期有外交突破和硅谷银行等新闻，但本期只会简要谈后者，其他话题留待以后展开。
- 第一期开播于 2022 年 2 月 28 日，节目已经满一周年，几位主播计划在当月通过线上会议举办一次简单的听友互动活动。
- 听友可以通过视频中的二维码或播客平台提供的链接填写问卷，提交想问的问题和想分享的内容，具体时间与参与方式之后公布。

### 02:33-08:52：硅谷银行暴雷的背景与风险

- 硅谷银行虽然是地区性银行，却服务于创业公司和创投资金高度集中的硅谷，储户数量和资金规模都远超一般地区银行。
- 银行把大量资金配置在美国国债上；持续加息会压低存量债券的估值，资产缩水后，银行需要补充资本，却没能顺利完成融资。
- 储户集中且大量存款超过美国存款保险的 25 万美元上限，使恐慌迅速转化为挤兑。监管机构在很短时间内接管银行，其他几家相似银行可能受到连锁影响，但主播判断这件事本身尚不足以构成系统性危机。

### 08:52-17:08：常温超导与 AI 辅助材料筛选

- 常规超导通常需要低温或高压，常温超导的意义在于如果能在接近日常环境下稳定实现零电阻，输电、计算和能源利用都可能发生重大变化。
- 迪亚斯团队过去曾报告过高压下的超导成果，但此前的结果没有被稳定重复，相关论文也曾被撤稿；这次声称在约 1 GPa、接近 20 摄氏度的条件下实现超导，数据比过去推进了两个数量级，因此既值得期待又需要谨慎。
- 关键问题不只是材料在高压下是否超导，还包括卸压后能否保持性能。节目建议继续观察半年到一年，看能否获得独立确认。
- 材料实验可以借助 `AI for Science`，用机器学习从海量材料组合中排除大部分低可能性方案，把原本可能需要多年的筛选压缩到更短时间。

### 17:08-25:43：ChatGPT API 的早期应用

- ChatGPT API 开放后，GitHub 上迅速出现大量开源项目；其中有脚本可以把 EPUB 电子书自动翻译成中英双语版本，一本书运行数小时即可得到可阅读的结果。
- ChatPDF 等服务可以先分析上传的英文论文，再回答主要观点、证据、章节论证和引用材料等问题，把“读完全文”与“只看摘要”之间的阅读需求压缩到较短时间。
- 通过 API 给小爱同学接入语言模型、给 YouTube 或 B 站视频生成摘要，也展示了模型如何降低语言理解和信息筛选的成本。
- 这些工具可能改变外语学习和使用的时间分配，但并不意味着学校可以取消英语；在开源文档、游戏攻略等特定领域做问答时，模型仍需要领域资料和专项增强，并且会在细节问题上产生幻觉。

### 25:43-34:35：企业战略研究与趋势预测

- 企业和高校都担心错过 ChatGPT 一类的技术机会，于是希望通过开源数据、论文和项目活跃度，提前发现可能成长的方向。
- 公司规模越大，错误战略造成的人员、时间和资金沉没成本越高，因此需要战略研究；但战略部门更主要的职责是搜集、整理和验证信息，最终方向仍由决策层选择。
- 大型资本并不是准确预测哪些项目必然成功，而是更早发现有吸引力的萌芽方向，再投入资源把它做大。中小企业和个人只能尽量更早理解这些信号，避免跟在所有人后面行动。
- 趋势分析可以从历史上已经成功的项目提取共同指标，进行预测、观察和迭代；数据采集与初步整理很可能被 AI 接管，但真正的预测不会因此变成确定答案。

### 34:35-43:41：技术爆炸、长期投入与创造未来

- 节目借《三体》的“技术爆炸”讨论技术发展是否完全不可预测：即使做不到百分之百准确，也可以像天气预报一样逐步扩大预测窗口，而开源领域丰富的公开数据尤其适合观察趋势。
- 对行业战略而言，六七成左右的预测准确率可能已经足够；但企业能否长期投入，往往取决于资源实力。中小企业需要短期回报，大企业才有条件把更多资金放到长期项目上。
- 长期研究不能全部由企业承担，学校和科研机构应承担更长周期的探索，并改善科研成果与产业需求之间的脱节，让产学研转换更顺畅。
- 真正的强者不是等风口出现后追赶，而是在别人尚未看好时持续投入，把新的机会做出来；战略研究的价值也应从“不要错过”转向“主动创造”。

### 43:41-53:11：评价新技术的实用框架

- 判断一项新技术是否值得关注，可以先看三个维度：是否明显提高效率，是否降低使用门槛，以及是否增加了新的做事选择。
- Docker 的例子说明，技术不一定凭空创造一个全新行业，也可能在原有行业上催生新的工种和工作方式；“创造工种”和“创造行业”是不同量级的影响。
- 还要看技术的冲击性，即它对既有秩序和人的认知造成多大影响。ChatGPT 已经催生新职业，也暴露出潜在风险，因此比单纯提高效率的工具更值得警惕。
- 学术界通常通过阅读文献、综述论文和参加会议来理解方向，但信息爆炸让人难以穷尽材料。ChatGPT 可以帮助收集、整理和归纳文献，却还不能替代真正有启发性的思考；分析开源项目时，也应把关键人物和社交关系纳入观察。

### 53:11-54:20：从避免错过到亲手创造

- 面对大公司“能否预测下一批 ChatGPT”的咨询，主播认为准确预测非常困难，但可以筛选有希望的项目，提前关注并投入资源。
- 把未来当成等待被发现的机会，容易滑向投机；更可靠的把握方式是进入一线实践，用长期投入把看好的方向做成现实。

### 54:20-01:00:30：《江湖丛谈》与消失的民间社会

- 《江湖丛谈》由评书艺人连阔如整理，最初来自 1930 年代报纸上的连载，记录了京津一带江湖人物、行当、切口和规矩。
- 书中按主题写到算卦相面、挑方卖药、杂技、保镖、卖艺、评书以及骗子等行业，呈现出一种已经消失、但仍影响中国文化的民间社会形态。
- 主播认为，江湖生活包含黑暗甚至违法的一面，但其中许多来自社会底层的人仍重视规矩和脸面；书中亲身观察与评书式语言，使这些故事既有社会史价值也有可读性。
- 推荐中华书局 2019 年再版、带注音注释和插图的版本，因为书中大量北方方言和特殊读音需要解释，电子书平台也能找到该版本。

### 01:00:30-01:02:30：延伸书目

- 节目补充提到《地师》和《相声大师》，前者借风水题材写到江湖八大门，后者则以更理想化的方式重新讲述相声艺人的故事。
- 这两本属于临时补充，并非本期正式推荐书目，但都被认为适合对江湖行当或相声文化感兴趣的读者。

### 01:02:30-01:10:25：《中国的知识重建》

- 郑永年的《中国的知识重建》讨论知识分子和知识体系如何从中国经验出发重新构建，而不是始终借用西方的概念和框架解释中国。
- 主播把这种处境类比为国际知识链：国内研究常常在国外已经定义好的主干问题上补充细节，形成追随式创造，难以产生原创性的解释体系。
- 一个国家不仅需要产业能力，也需要能够解释自身文化、发展道路和制度经验的知识体系与话语体系；中国国力增强与国际知识话语权之间仍存在落差。
- 书中进一步批评高校教育、院士机制和文凭体系等问题，呼吁知识分子和高校承担知识重建的责任，但真正落地还需要制度调整和长期积累。

### 01:10:25-01:17:45：《成为人类学家》与开源身份

- 《成为人类学家》的封面用 `Hello World` 和 `printf` 代码吸引了主播，书中收录了约 50 篇青年人类学家的经历，讲述他们如何进入这个专业并逐渐形成职业认同。
- 相比履历和名校背景，主播更看重其中关于困惑、迷茫、田野调查和自我剖析的文章。研究者通过学习当地语言、与不同文化中的人建立关系，也重新理解“我是谁”。
- 这本书易于分篇阅读，也让主播想到收集国内开源参与者的经历，写一本《成为开源人》，记录一个人如何从程序员逐渐把自己认同为开源人。
- 节目最后再次提醒听友填写周年活动问卷，并为线上周年互动活动提供意见。

## 核心观点

1. 预测未来只能建立在数据、历史规律和持续迭代上，不能把一次惊人的实验、一个热门项目或一份战略报告当成确定答案。
2. 评价新技术要同时看效率提升、门槛降低、新选择，以及它对既有秩序和认知的冲击。
3. 真正的战略优势来自长期投入和一线实践。发现趋势可以帮助选择方向，但只有持续把资源投进去，才可能把未来创造出来。
4. AI 可以显著降低翻译、阅读和信息整理成本，却不能自动保证知识正确、论证可靠或领域答案有效；人的验证和判断仍不可省略。
5. 无论是国家的知识体系，还是个人的职业身份，都不是靠套用现成标签形成的，而是在长期实践、交流和自我反思中逐渐建立。
